# 旧版 PowerShell 资料

此目录归档早期 Veyon 部署脚本及配套视频，供查阅和维护历史资料。它们不属于当前 0.4.x 桌面 App 的安装流程。

- `teacher_v3.txt`、`student_v3.txt`：旧教师端与学生端脚本。
- `add_computer_v1.txt`：旧版批量添加计算机脚本。
- [视频教程](视频教程/README.md)：四段旧流程操作录像及校验清单。
- [归档脚本指南](../../docs/archive/legacy/脚本使用指南.md)：旧脚本的适用范围与操作说明。

旧学生脚本会修改计算机名、Veyon 配置和本地账户设置；其中部分操作不可自动回滚。请勿将这些脚本直接用于正式电脑。
