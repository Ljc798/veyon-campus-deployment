## 调研：禁止学生开关 WiFi / 断网（用户问"有没有办法"）

背景：学生关 WiFi/断网可绕过网站管控；用户想知道能否禁止。

### 关键事实（查证 MS Learn + gporais + 社区）
- 学生若是**标准用户**：netsh / PowerShell / 设备管理器禁用网卡都需管理员，本来就做不了。
- **真正漏洞**：Windows 设置页、快速设置（任务栏网络图标）里的 WiFi 开关**不需要管理员**，普通用户就能关/开。
- **没有原生"保留 WiFi 但禁止用户关闭"的干净策略**。`HKLM\...\PolicyManager\default\WiFi\AllowWiFi=0` 是**彻底禁用 WiFi**（且 default 只是 MDM 默认值缓存，直改未必生效），不适用。

### 可用手段（按可靠性）
1. **设备对象 ACL**（社区方案，最接近需求）：设备管理器→WiFi 网卡→属性→安全→Users 组勾"拒绝-完全控制"（Administrators 保留允许）。原理=设备 DACL，阻止普通用户启用/禁用。
   - 未实测点：**快速设置的 WiFi radio 开关走 WLAN/Radio API，是否受设备 DACL 约束不确定**，必须实机验证。
2. **组策略（HKCU，仅 GUI，不管 netsh）**：
   - `HKCU\Software\Policies\Microsoft\Windows\Network Connections` → `NC_LanConnect=1`（禁止启用/禁用 LAN 连接）
   - 同键 `NC_LanChangeProperties=1`、`NC_Stat=1`（禁止改属性/看状态页）
   - 注意：administrators 默认不受管，需先开"为管理员启用 Windows 2000 网络连接设置"；且官方文档只说 LAN connections，**WiFi 是否受管需实测**。
   - `NC_LanConnect` 只挡 GUI，**挡不住 `netsh interface set interface admin=disable`**（需管理员，标准用户天然挡住）。
3. **彻底禁用 WiFi**（不推荐给需要 WiFi 的教室）：`AllowWiFi=0` / 停 WlanSvc / 设备管理器禁用。
4. **软件禁不掉**：笔记本物理 WiFi 开关、飞行模式 Fn 快捷键、拔网线、手机热点、USB 网卡。

### 与项目架构的结合建议
- 我们已有 SYSTEM Agent：可做**兜底监视+强制恢复**（轮询 WiFi 适配器/radio 状态，被关则 re-enable + 写 agent-runtime.log + 教师端告警）。对抗式、有秒级延迟，但能覆盖 GUI 开关。
- **根本思路**：不如"断网也逃不掉"。现有网站策略（DNS 锁、地址黑洞路由、TCP reset）是**本地生效**的，断网后策略仍在、重连仍生效；学生关 WiFi 只是自己没网，达不到"绕过管控上网"。真正缺口是**换网络**（热点/网线/USB 网卡），这才是策略覆盖不到处，应优先考虑而非纠结"禁止关 WiFi"。
- 待确认前提：学生账户是否管理员？学生机笔记本还是台式？目标是"防断网逃避"还是"防换网络"？

## 防断网逃课：落地实现（学生端）

### 用户实况
- 学生账户 `user` = 标准用户；一体机（无网线），**联网只走无线 WiFi**。
- 目标：**防断网逃避**（断网后无法下发新策略，学生玩离线小游戏）。
- 需求：关掉普通 user 的网络开关权限；断网就锁鼠标也行（问"什么时候揭开"）。

### 关键结论（源码核实）
- 已有策略**断网不失效**：策略存 `HKLM\...\AgentKey\PolicyDocumentJson`，Agent 启动 `RefreshNetworkBlock()`（WebsitePolicyRuntime:4825），运行中每 10 分钟重装一次（:4923）。压制 watcher 每 1.5s 扫，断网照压。
- 真实缺口只有两个：① 断网后下发了新策略；② 断网后玩**本地游戏**（原压制名单只有短视频/直播，无游戏）。
- **重大发现**：`StudentInputGuardServer.ExecuteAsync` **不验签**（只校验 epoch + 防重放），签名只在外层 HTTP `Verify`。所以 **SYSTEM Agent 可直接构造 `StudentInputGuardCommand` 调 `ExecuteAsync` 锁键鼠**，不需要教师端签名、不需要改 Guard。
- 一体机无网线 → 学生唯一断网手段是任务栏 WiFi 磁贴/飞行模式（`netsh`、设备管理器对标准用户本来就要 UAC）。所以"禁入口"+"断网锁"够用，无需 P/Invoke 强制开 radio（会和用户操作打架）。
