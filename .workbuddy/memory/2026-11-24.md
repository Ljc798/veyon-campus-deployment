## 课堂页 UI 修复 + 白名单新增（08:10）

用户反馈 1.1.117 截图问题：数字与文字未对齐、屏幕墙上方筛选区无法完整展示。

- **筛选区溢出根因**：`TeacherClassroomView` Row=1 是一整条横向 `ScrollViewer` + `StackPanel`，控件自然宽度约 1000px；窗口 `MinWidth=1024`、左侧导航 224，内容区最窄只有约 752px，必然被裁切并出现横向滚动。
  修复：去掉 ScrollViewer，改为固定列 Grid（分段按钮 / 搜索框 236 / 间隔 * / 状态 100 / 排序 108 / 视图按钮）。把"列数、缩略图大小、紧凑模式"收进"视图"按钮的 Flyout，避免挤占主行。
- **数字对齐根因**：横向 `StackPanel` 里小号标签与大号数字都没设垂直对齐，交叉轴拉伸后小字贴顶、大数字撑满，基线错开。
  修复：顶部统计条（学生电脑/已选设备/任务待核验/控制已回执）与底部任务状态栏（执行中/成功/失败/待核验）全部补 `VerticalAlignment="Center"`；数字统一 12–15 号 SemiBold，标签 11–12 号，间距 5–6。
- **白名单**：`WebsitePolicyPresetStore.DefaultAllowedDomains` 追加 `super-zxt-student.chuangke100.com`（与 smartedu.cn 等同列表）。注意该列表只在 `%LOCALAPPDATA%\VeyonCampus\MobileControl\website-policy-presets.json` 不存在时生效，已有该文件的老机器不会自动追加。本机该文件当时不存在，安装后即可看到。
