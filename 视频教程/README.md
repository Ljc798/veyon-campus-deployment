# 视频教程

**使用前请先观看视频教程；有疑问时查阅相关文档；如果文档仍无法解决，请咨询作者。**

成片直接放在本仓库，点击文件下载观看，也可以随仓库 ZIP 一起下载。建议按以下顺序学习：

1. [教师端部署](01_教师端部署_说明与鼠标提示.mp4)
2. [学生端部署](02_学生端部署_说明与鼠标提示.mp4)
3. [电脑连接](03_电脑连接_说明与鼠标提示.mp4)
4. [一键添加计算机 · 剪辑说明版](04_一键添加计算机_剪辑说明版.mp4)

第 04 段用于补充第 03 段逐台添加电脑的操作。对应 [add_computer_v1.txt](../add_computer_v1.txt)，完整参数和限制见 [批量添加计算机说明](../批量添加计算机.md)。

**第 04 段勘误：原录像改完显示名称后漏点了底部“应用”。成片在此处插入 8 秒定格并标出按钮。实际操作请点击“应用”保存，核对结果后再打开 Veyon Master。**

视频已嵌入步骤说明，无需外挂字幕。前三段的青色鼠标表示左键，橙色表示右键，×2 表示双击；第 04 段使用文字操作提示与保存按钮标注。

录像中的 v3 是内部迭代名称，对应 `teacher_v3.txt` 和 `student_v3.txt`。成片校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，第 04 段剪辑说明见 [一键添加计算机 · 剪辑说明版](04_一键添加计算机_剪辑说明版.mp4)。
