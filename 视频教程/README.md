# 视频教程

视频作为 [GitHub Releases](https://github.com/Ljc798/veyon-campus-deployment/releases) 附件提供，不包含在源码 ZIP 中。若当前没有附件，表示维护者尚未上传，请先阅读 [文字教程](../README.md)。

按以下顺序下载并观看：

1. `01_教师端部署_说明与鼠标提示.mp4`
2. `02_学生端部署_说明与鼠标提示.mp4`
3. `03_电脑连接_说明与鼠标提示.mp4`

视频已嵌入步骤说明和鼠标操作提示，无需外挂字幕。青色鼠标表示左键，橙色表示右键，×2 表示双击；键盘图标表示输入或快捷键。

录像中的 v3 是内部迭代名称，对应仓库的 `teacher_v3.txt` 和 `student_v3.txt`。原始视频校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。
