# Veyon Campus Deployment

用于教室电脑的 Veyon 部署脚本与中文操作指南。

**App 当前进展：**C# + Avalonia App 版本为 0.4.5 实验版。Veyon 安装／导入公钥、改名、学生账户、管理员密码均已接入独立及组合执行路径；学生账户密码可留空，管理员名默认 `Administrator`。教师端网站黑白名单为免费自研功能。当前构建和 34 项自动检查通过，Windows 实机验收仍未完成。测试包及当前进度见 [App 文档入口](docs/README.md)，使用步骤见 [开发与部署指南](docs/开发与部署指南.md)。以下公开版本和操作步骤仍针对 PowerShell 原脚本 v1.0。

**完整开发规划：**[开发路线与任务清单](docs/开发路线与任务清单.md) · [架构与实现约束](docs/架构与实现约束.md) · [测试验收与发布清单](docs/测试验收与发布清单.md)。已确定目标为 Windows 10／11、每机房最多 150 台，Veyon 部署、电脑改名、创建学生账户、修改管理员密码可分别操作。当前仅 Veyon 单项具备实验性执行代码，实际 Windows 端到端闭环仍待验收。

**公开版本：v1.0 · Windows / PowerShell · 学习交流版**

[部署步骤](#1-部署前准备) · [常见问题](QnA.md) · [视频教程](视频教程/README.md) · [更新说明](发布说明.md) · [参与改进](CONTRIBUTING.md)

这是本工具的**首个公开学习版本**，用于管理员为教室电脑配置 Veyon。当前提供**教师端生成部署包、学生端交互式配置、教师端批量添加计算机**，尚不是安装、配置、连接全部自动完成的“一键部署”。请先在一台教师机和一台学生机上完成试装，再批量使用。

> **运行前必读：学生脚本会覆盖运行脚本的本地管理员账户密码，并修改计算机名和 Veyon 配置。中途失败不会自动撤销已经完成的操作。**
>
> 本工具用于已获授权的教室设备管理。实际校区部署包中的 `admin.txt` 是明文密码，不要随公开演示材料分发。

## 先了解这个版本

**公开版本为 v1.0。**此前的“监控脚本 v3.0”是内部迭代名称，不代表已经发布过三个公开版本。为方便跟随原视频操作，本包保留 `teacher_v3.txt` 和 `student_v3.txt` 文件名；脚本头部的 0.4 / 0.7 是历史组件版本。它们均属于本次 v1.0 学习包，无需另找 v1 脚本，也不用自行改名。

### 目前可以解决的问题

- 教师端统一生成校区密钥及学生部署包，减少逐机准备配置文件的工作。
- 学生端按编号改名，统一指定管理员密码并初始化普通学生账户。
- 学生端自动设置 Veyon 密钥认证、导入公钥并重启服务。
- 新增 `add_computer_v1.txt`：输入地点、数量和显示名称前缀，批量导入以 `PC-` 命名的电脑列表。
- 配合操作文档、Q&A 和四段说明视频，学习从部署到连接的完整流程。

### 当前仍需手动完成

安装 Veyon、运行脚本并填写参数、配置教师端认证与私钥权限、核对批量导入的学生机列表，以及完成重启后的实际连接验收。当前没有自动回滚、完整日志或跨环境兼容性保证。

原 PowerShell 脚本后续改进方向见 [当前能力与未来计划](当前能力与未来计划.md)；它与上面的 App 任务状态分开维护。

## 1. 部署前准备

1. 准备 Windows 64 位电脑，使用 **64 位 Windows PowerShell（管理员）**；按 Win+X 后选择对应管理员入口，也可在开始菜单搜索 Windows PowerShell 并选择“以管理员身份运行”。本次未完成 Windows 实机兼容性验证。
2. 学生机使用明确的本地管理员账户运行。域账户、Microsoft 账户和已有复杂账户策略的电脑暂不直接批量部署；当前脚本的账户身份检查还不够严格。
3. 记录原计算机名、原 Veyon 配置和账户情况，确认有可用的恢复管理员账户。保存工作，运行末尾可以选择重启。
4. 规划每台电脑的唯一名称。默认是 `PC-01` 至 `PC-99`；多个机房共用网络时不能各自重复编号，可在部署前为不同机房设置不同 `computerPrefix`。
5. 教师机与学生机之间应当网络可达；同一 Wi-Fi 名称不代表一定可互访。
6. 先检查学生机是否已存在 `User` 账户。如果它是管理员、已禁用或正在被使用，先由管理员确认处理方式，不要直接运行。

## 2. 教师端：生成部署包

1. 安装 Veyon，教师机保留 **Veyon Master** 组件。
2. 用记事本打开 `teacher_v3.txt`，全选复制，粘贴到管理员 Windows PowerShell 并回车。当前交付方式是复制脚本，不能直接双击 TXT 执行。
3. 按提示输入校区 ID，例如 `JJ-CHAISANG`，再输入两遍学生机管理员密码。当前学生脚本会去掉密码首尾空白，请不要设置含首尾空格的密码；密码还需符合目标电脑策略。
4. 成功后，桌面出现 `Veyon-Student-Deployment-校区ID` 文件夹，包含：
   - `校区ID-public.pem`：学生机使用的公钥。
   - `campus.json`：校区、计算机名前缀和公钥文件名。
   - `admin.txt`：学生机管理员明文密码。
   - `README.md`：部署包说明。
5. 私钥留在教师机。教师脚本未完成教师端认证方式、私钥访问权限及电脑列表配置，这些仍需在第 4 节完成。
6. 把完整部署包和 `student_v3.txt` 放到受控 U 盘。已有同名部署目录时脚本会停止；不要为了重试直接删除目录或重新生成密钥，先查清现有密钥及已部署设备情况。

## 3. 学生端：逐台配置

1. 安装 Veyon，学生机不需要 Veyon Master，保留服务组件。
2. 使用准备好的本地管理员账户打开管理员 Windows PowerShell。
3. 用记事本打开 `student_v3.txt`，全选复制粘贴运行。
4. 输入部署文件夹路径，例如 `E:\Veyon-Student-Deployment-JJ-CHAISANG`，不是 `campus.json` 的路径。
5. 输入 1–99 的编号，例如 `3` 会转换为 `03`。检查目标电脑名、校区和管理员账户后，输入大写 `YES` 开始。
6. 脚本将依次执行：
   - 修改计算机名。
   - 将运行脚本的本地管理员账户密码设置为 `admin.txt` 中的密码，**已有密码也会覆盖**。
   - 不存在 `User` 时创建无密码普通账户；已有 `User` 时保留原密码，不重新创建。
   - 检查 `User` 的组成员关系，并设置不允许修改密码、密码永不过期。
   - 切换 Veyon 为密钥认证，导入本校区公钥，重启 Veyon 服务。
7. 完成后输入 `YES` 会强制重启电脑，请先保存工作；也可稍后手动重启。脚本不设置自动登录。

如果显示失败，先记录错误和最后成功的步骤，再检查本机状态。失败不等于没有发生修改，详见 [Q&A](QnA.md)。

## 4. 教师端：配置连接

1. 打开教师机的 Veyon Configurator，确认使用密钥文件认证。
2. 检查校区密钥和访问权限：日常运行 Veyon Master 的教师账户必须能读取对应私钥。不要把私钥放进学生部署包。
3. 在“位置和计算机”中添加机房及学生机，填写可解析的主机名或实际 IP 地址。也可运行新增的 `add_computer_v1.txt` 批量创建地点并导入电脑列表，步骤见下文。此脚本不会自动发现电脑；按 IP 配置时需考虑地址变化。
4. 检查学生机 Veyon 服务和防火墙规则。Veyon 服务默认使用 TCP 11100；若修改过端口，应以实际配置为准。
5. 使用日常教师账户启动 Veyon Master，连接试装学生机。

上述认证、私钥访问及电脑目录要求参考 [Veyon 官方配置说明](https://docs.veyon.io/en/latest/admin/reference.html)。界面名称可能随版本或语言变化。

### 批量添加计算机（新增）

1. 在教师机备份已有 Veyon 配置，关闭已打开的配置器，使用管理员 Windows PowerShell。
2. 用记事本打开 `add_computer_v1.txt`，全选复制、粘贴运行。
3. 依次输入校区 / 地点名称、电脑数量、显示名称前缀。例如 `演示机房`、`20`、`学生`。
4. 核对预览：`学生01 → PC-01`，直到 `学生20 → PC-20`。输入 `Y` 或 `y` 后回车确认，其他输入取消。
5. 完成后重新打开配置器，在“地点及计算机”中核对条目数量和地址。若手动修改显示名称，**点击底部“应用”保存更改**。
6. 使用日常教师账户打开 Veyon Master，核对列表并完成实际连接验收。

> **视频勘误：第 04 段原录像修改显示名称后漏点了“应用”。成片已用定格、按钮标注和文字纠正；请实际点击“应用”保存，再打开 Master。**
>
> “电脑名称前缀”只影响显示名称，连接主机名固定为 `PC-01` 起。如果学生机使用 `A-PC-` 等前缀，必须另行修改对应连接地址。导入脚本接受 1–999 台，但现有学生部署脚本仍只接受 1–99；添加条目不会创建或重命名实际电脑。

详细限制与错误处理见 [批量添加计算机](批量添加计算机.md)，操作演示见 [第 04 段视频](视频教程/04_一键添加计算机_剪辑说明版.mp4)。

## 5. 试装验收

- [ ] 重启后，计算机名与规划一致且无重名。
- [ ] 管理员可使用新密码登录。
- [ ] `User` 可登录且是普通用户；已有账户的密码与预期一致。
- [ ] Veyon 服务运行，学生机使用正确校区公钥。
- [ ] 批量导入的地点、数量和主机地址正确；手动改名后已点“应用”，重新打开配置器仍保留修改。
- [ ] 日常教师账户能在 Veyon Master 中查看目标学生机；按实际需求测试远程控制。
- [ ] 双方重启后仍能连接。
- [ ] 部署包和密码已由管理员收回，未遗留在学生可访问的位置。

完成单机验收后再逐批推广，并记录每台机器的名称、地址、部署结果和异常。

## 6. 适用范围与恢复

当前脚本只查找默认 Veyon 安装路径；学生部署编号支持 1–99，新增导入脚本支持 1–999 个列表条目。尚未实现配置备份、自动回滚或完整日志。卸载 Veyon 不会自动还原脚本修改的账户密码和计算机名。

需恢复时，由管理员依据部署前记录分别恢复计算机名、Veyon 配置和账户设置；密码只能重新设置，不能由脚本找回旧密码。删除 `User` 前应先确认其文件和用途。

更多问题见 [QnA.md](QnA.md)，后续计划见 [当前能力与未来计划.md](当前能力与未来计划.md)。
