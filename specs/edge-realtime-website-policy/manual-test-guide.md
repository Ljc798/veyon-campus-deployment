# Edge 实时网站策略手动试用

此试用包用于单台测试电脑的 Edge 验证，不是正式分发包。它不会强制安装商店扩展，也不会重启浏览器。

## 学生电脑

1. 安装 GitHub Release 中的 `VeyonCampus-Student-Setup-1.0.15-win-x64.exe`。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择：

   `C:\Program Files\Veyon Campus\Student\EdgeExtension`

3. 扩展 ID 应为 `{EXTENSION_ID}`。保持扩展启用并让对应 Edge 用户配置文件至少打开一次 Edge。

## 教师电脑

1. 安装并打开 Edge 实时试用教师包。
2. 选择这台学生电脑，先推送一条网站策略。
3. 点击“读取逐台状态”，等待 Edge Profile 显示当前策略为“已读回应用”。该电脑每个实际使用的 Edge 用户配置文件都需要回执。
4. 点击“启用 Edge 实时同步（试用）”，核对目标电脑和 Profile 后确认。
5. 更改网站策略并重新推送。扩展通常会在约两秒内收到新规则；用新标签页打开或重新加载目标网站验证。已打开的标签页不会被自动关闭。
6. 测试结束后点击“恢复 Edge 注册表策略”，核对学生名单并确认。教师端会把最近已签收的 Edge 规则写回注册表；扩展保持同一份动态规则。不会自动重启浏览器。重新加载网页并从教师端重新读取逐台状态。

## 试用范围

- 只验证 Edge 的顶层 HTTP/HTTPS 导航；Chrome、Firefox、子资源和已打开页面不在本次试用范围。
- 启用时会清除 Veyon Campus 自己管理的 Edge URLBlocklist/URLAllowlist；扩展随后负责 Edge 实时规则。
- 试用模式的学生安装包需要手动加载解压扩展。恢复旧模式后，扩展可以继续同步同一份规则；卸载扩展也不会删除已恢复的注册表规则。
- 恢复注册表策略不会自动重启 Edge；运行中的浏览器何时读取机器策略由 Edge 决定，网页需要重新加载。
