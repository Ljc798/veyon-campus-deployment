# 手机课堂屏幕巡视：需求

## 目标

教师用已配对手机查看本堂课已登记学生座位对应的 Veyon 画面。手机按座位号/学生姓名展示缩略图；教师可选择画质和刷新间隔，随时暂停。采集使用 Veyon 已有认证通道，截图只在教师机和手机当前会话中短暂传输。

## 验收条件

1. 只有已配对手机、教师 HTTPS 服务、当前活动课堂和当前配置座位映射中的目标可以请求画面；不能通过更改 URL 查询任意主机。
2. 使用 Veyon 已有认证的单帧截图能力，不开放 WebAPI 端口、不改变学生机防火墙、不在学生机安装新服务。页面把自动刷新明确称为“巡视画面”，不声称是视频流。
3. 教师明确开启巡视后才采集画面；手机页面展示本堂课全部已关联座位，最多覆盖系统支持的 150 个课堂目标。页面按座位顺序滚动显示，采用懒加载、可见区域调度和有界并发；页面不可见、暂停或课堂结束时停止请求。教师无需分成最多 5 台一批反复选择。
4. 手机提供易懂的画质预设（省流/标准/清晰）和刷新间隔（至少 3 秒，最高 60 秒）；默认省流画质和 10 秒刷新。后端对每台设备和全局请求设安全的速率、并发、图片尺寸和缓存上限，不因客户端扩大目标范围而放大资源消耗。
5. 画质与刷新设置只影响当前手机会话，可即时调整；失败卡片显示简单中文状态，不阻断其他学生画面。单座实时画面从对应学生卡片开启，并且一次只查看一台。
6. 图片请求只限本堂课授权目标；服务端进行限流、限并发、大小校验、取消处理和 `Cache-Control: no-store`，Service Worker 不缓存画面。
7. 原始截图只短暂经过教师机 Veyon 目录并在精确识别后删除；缩略图只存内存，不写磁盘、不进入审计 JSON、不上传 CloudBase、不保存录像。
8. 结束巡视、切换课堂、手机进入后台或教师服务关闭时，停止轮询、取消请求并清除对象 URL 和内存画面缓存。
9. 操作和审计不记录图片内容、屏幕文字、浏览历史或云端学生身份。手机布局使用简明中文和触屏大按钮。

## 非目标

- 首期不做鼠标键盘远控、录像、云端传图或持续高清视频流。
- 不让普通手机用户直接调整 Veyon CLI 参数、并发数、截图目录或网络地址。
