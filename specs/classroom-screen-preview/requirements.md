# 课堂屏幕预览 PoC：需求

路线图对应项：P2“屏幕预览 PoC”。本里程碑验证现有 Veyon 远程画面能力能否在已配对手机上安全查看，不实现录像、云端传输或持续高清视频。

## 目标

教师在手机主动打开“屏幕巡视”后，查看当前课堂最多 5 台学生电脑的低分辨率画面概览。界面只展示本堂课目标电脑；手机停止巡视、切到后台或课堂结束后停止继续请求画面。

## 验收条件

1. 仅限已配对手机、教师控制服务 HTTPS、当前活动课堂和本堂课目标电脑；不能通过修改 URL 读取其他主机。
2. 通过 Veyon 4.11.2 内置 `Screenshot` 功能和现有 Veyon 认证通道取单帧，不启用或暴露 Veyon WebAPI 监听端口。
3. 手机端默认不取画面；教师明确点“屏幕巡视”后才开始。概览最多 5 台，尺寸不超过 320 像素宽；不提供帧率、分辨率、并发等设置。
4. 每台电脑至少间隔 2 秒才重新采集；教师端同时最多处理 2 台。只更新手机当前可见的缩略图。
5. 截图只在教师机内存和 Veyon 默认个人截图目录短暂经过；采集后缩放并立即删除本次生成的原始 PNG。手机响应使用 `Cache-Control: no-store`，Service Worker 不缓存 API。
6. 采集尝试写入教师机现有手机控制审计记录；不上传画面或审计到 CloudBase，不保存录像或历史缩略图。
7. 课堂 session 变化、用户关闭巡视、请求取消或采集失败时，取消/终止相应工作并释放图片缓存。若无法确定本次截图文件，不返回画面且不删除任何已有截图。
8. 自动检查覆盖配对授权、目标/课堂边界、请求限频、内存缓存、并发上限、取消、session 清理和缩略图尺寸边界。Veyon CLI 文件匹配、原图清理、真实图片缩放及 Windows/手机线路和性能仍需在实机验收；自动检查不替代实机结论。

## 非目标

- 不做单机 720p Focus、视频流、录像、回放、远程控制鼠标键盘或桌面广播。
- 不安装新的学生端服务或更改 Veyon WebAPI / 防火墙 / 证书配置。
- 不声称通过模拟检查即可证明 Veyon CLI 在教师 Windows 机上的真实输出速度与格式。

## 初始预算

- 最多 5 台；画面按 320 像素宽生成 PNG 概览。
- 每目标最多每 2 秒采集一次，教师端最多 2 个并行 Veyon CLI 进程。
- 预算是 PoC 的保护上限，实际可用性、等待时间和 LAN 带宽须经 Windows 实机测量后决定是否扩展。
