# 低敏运维汇总：需求

## 目标

Teacher 可在不影响课堂的情况下，选择上传按日聚合的更新结果和课堂次数；owner/admin 可在现有趋势分析页查看真实汇总和错误类别趋势。

## 交互原则

- Teacher 只出现一个“匿名运维汇总”总开关；默认关闭。打开后固定上传本规格列出的全部字段，不提供字段、周期或重试策略配置。
- 数据仅从用户明确打开开关之后开始累计。关闭时停止后续发送并删除本机待发队列；此前已上传数据按 400 天留存策略清理。
- 不新增管理员导航项、筛选器或单独的运维设置页；管理员趋势复用 `/admin/analytics` 当前日期范围。

## 上报字段

- 香港日期、由已发布配置包解析的校区身份、按日发布者摘要。Teacher 在本机从随机安装标识派生每日令牌；运维汇总请求不包含原始标识。
- 更新诊断终态计数：成功、部分完成、失败、取消；`Started` 不计入，避免把更新助手启动和完成结果重复当成两次尝试。
- StudentRollout 中已汇总的目标成功、需核对、失败计数；不提供目标逐台结果。
- 稳定错误码计数及当日课堂会话次数。

## 隐私与可靠性

- 禁止上传姓名、账号、电脑名、主机/IP、学生身份、消息或日志正文、文件路径、逐台状态、原始发布者标识或会话/机房 ID。
- 上报只在 HTTPS 下进行；服务端校验包状态、日期、字段范围和错误码，再用日 HMAC 摘要，幂等写入。
- Teacher 本机最多保留最近 14 日待发聚合。离线失败进入队列，应用启动或现有每小时后台检查时重试；成功后移除。网络请求有界且异步，失败不阻塞更新或课堂操作。
- 服务端按香港日期自动清理 400 天前汇总；报告只允许 owner/admin 读取。普通教师、viewer、editor 不得读取其他校区运维数据。
- 汇总代表主动上报的 Teacher 实例，不是逐台在线清单或独立设备数；管理员界面必须标注该边界。无数据时显示空状态，不造演示值。
- 写入 API 为匿名接口，校验字段和已发布配置包但无法证明教师机真实性；汇总只作趋势参考，不用于审计、告警或设备在线判断。

## 验收

1. 默认关闭，不生成或发送任何云端报告；打开后只汇总授权时间之后的数据。
2. 关闭时清空待发队列；断网时保留有界队列，恢复网络后幂等重试。
3. 后端拒绝未知字段/错误码、超界计数、非已发布配置包和超期/未来日期；绝不持久化原始发布者标识。
4. owner/admin 可读取 7/30/90 天范围；其他角色被服务端拒绝。页面复用现有分析范围和路径。
5. 数据库迁移在一次性 PostgreSQL 测试库验证权限、幂等性、日期边界和自动清理。
