# 低敏运维汇总：设计

## 组件边界

- `VeyonCampus.Core` 从现有本机更新诊断和本地课堂会话中构造每日摘要；不改变诊断原始记录，也不复用学生端匿名心跳。
- Teacher 在更新页面底部提供唯一总开关。偏好和最多 14 天的摘要队列保存在当前用户 LocalAppData；关闭时队列原子清空。
- Teacher 以已发布配置包 ID 和本机派生的按日发布者令牌调用 `/v1/telemetry/teacher/operations`；该请求不包含原始随机发布者标识。云函数验证配置包并派生日 HMAC，客户端不能自报正式校区 ID。
- PostgreSQL 使用 `campus_daily_operations_reports` 保存每个校区身份/Teacher 安装/日期的一行终态汇总；唯一键支持重试覆盖而不重复累加。服务端 RPC 校验数据、写入并按日清理 400 天前的数据。
- `/v1/admin/operations/daily` 强制 owner/admin，经服务端 RPC 返回全站每日聚合。网站只在已有 `/admin/analytics` 页加载并呈现该数据；日期范围沿用现有控件。

## 汇总算法

- 日期固定按 `Asia/Hong_Kong` 计算；只生成最近 14 日中已结束日期的报告。
- 只读取启用时间之后的本地事件和课堂会话。按 `UpdateDiagnosticOutcome` 计数；忽略 `Started`。StudentRollout 目标计数按现有 150 台上限累加并以 20,000 封顶。
- 只统计 Partial/Failed 事件的固定错误码。错误消息、目标版本明细、路径和设备标签不进入云端摘要。
- 无更新结果和无课堂会话的日期不上传。上传成功后移除本机对应日期；失败保留，并在应用启动或现有每小时后台检查时重试。

## 服务端与权限

- 上传 API 限制 32 KiB 请求、严格字段白名单、20,000 日累计数、固定错误码和最多 14 天的历史范围。
- 公开上报端点只允许调用服务端 `SECURITY DEFINER` 写入 RPC；表对 anon/authenticated 无 grants。校区只能从已发布且未停用配置包推导。
- 客户端对本机随机发布者标识按报告日期派生令牌；同日重试稳定，跨日不可关联。数据表仅存再次由服务端派生的日 HMAC，不存原始标识或客户端令牌；管理员读 API 只调用聚合 RPC。
- 该隐私边界适用于新运维汇总请求；既有 Teacher 心跳协议保持不变，仍单独向服务端提供随机发布者标识以计算日摘要。
- 匿名上报无法证明教师机真实性，服务端白名单校验不等同于来源认证；页面需提示数值仅用于趋势参考。
- 400 天清理与现有 HKT 遥测清理状态分开记日，避免被旧心跳清理时间提前更新时间造成跳过。

## 页面

- 不增加导航；在趋势分析页现有图表下显示一张每日表，字段为上报校区数、成功/部分/失败、学生目标结果、课堂次数与固定错误类别。
- 不展示单 Teacher、机房、配置包、身份摘要或学生级数据。只有 owner/admin 加载 API；其他角色不发请求。
- 图表继续使用现有简约卡片、表格和区间控件；零数据使用明确空状态。

## 验证

- Core 检查覆盖默认关闭、启用时间、HKT 跨日、14 日边界、隐私字段、汇总算法、有界队列、原子清空与幂等移除。
- API contract test 覆盖写入字段/日 HMAC/未知错误码拒绝/日期及计数范围/管理员角色与读取范围。
- PostgreSQL 脚本覆盖迁移、权限、错误输入、重试幂等及 400 天清理。
- 网站构建与本地管理员路由检查验证渲染；受保护角色的线上 Auth/E2E 与 Windows 实机网络行为仍须实测。
