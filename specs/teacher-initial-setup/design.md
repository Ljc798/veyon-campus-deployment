# 教师端首次设置向导：设计

## 流程与状态

- 复用教师控制台现有三步 UI 和 `TeacherViewModel`，不新建导航框架。
- 步骤 1 使用 `VeyonFacts.Probe()` 只读检查本机状态。首次打开向导时检查；教师可手动重新检查。只有确认已安装且版本符合当前配置包流程要求才标记完成；未安装、版本未知/不受支持、读取失败和非 Windows 状态分别说明。
- 步骤 2 完成条件为本地座位图存在、至少一个座位、所有座位均有学生姓名。是否已有 Veyon 目标绑定单独显示，不影响完成状态。教师可显式跳过。
- 步骤 3 使用现有配置包生成流程；只有现有成功回执出现时标记完成。CloudBase 发布继续是可选后续操作。
- 步骤导航允许返回；前进必须按顺序完成，或显式跳过步骤 2。步骤状态由已读本机数据和当前操作回执计算，不再保存第二份进度文件。

## 界面

- 使用现有教师端品牌色和卡片组件，步骤标题显示待完成、已完成或稍后处理状态。
- 步骤 1 显示 Veyon 检查结果、重新检查和现有安装/修复操作。
- 步骤 2 显示桌位数、已填写姓名数和已关联电脑数，并说明目标电脑关联可以稍后完成。
- 步骤 3 显示生成状态、错误和输出路径。生成成功后提供明确的结果提示；云端目录发布仍作为单独可选操作。

## 验证

- 教师端 Release 构建验证 Avalonia XAML 绑定与 ViewModel 编译。
- Windows 实机仍需核实 Veyon 状态读回、步骤禁用/恢复、跨页面回到向导后的状态更新及配置包实际生成。
