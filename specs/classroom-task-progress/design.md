# 课堂任务进度：设计

## 组件边界

- Core 提供严格有界的 session 任务清单模型与本机存储；最多 20 条、每条最多 120 字，文件最多 16 KiB。
- TeacherViewModel 提供一个简短输入框、添加按钮和可勾选列表。点击标题行切换完成状态，删除动作只影响当前一条；已完成计数自动计算。
- TeacherMobileControlService 通过现有配对认证的 `GET /api/session` 只读读取当前活动 SessionId 对应清单。读取失败时返回 `null`，不影响其它 session 字段。
- MobileWeb 在现有课堂模式卡片中只读呈现完成数和任务列表，不增加导航、轮询请求或策略动作；已有课堂状态刷新时同步更新。
- 活动课堂启动时为空；结束时按 SessionId 清理。Teacher 重启后，活动 session 与清单从本机文件恢复。

## 数据与安全

- 单文件只保存 schema version、SessionId、任务 ID、标题、完成布尔值和更新时间；不包含校区网络地址、电脑名或学生身份。
- JSON 严格拒绝重复/未知字段和越界数据；更新前读回并校验现有文件。用文件锁、同目录临时文件、flush 和原子替换写入。
- 不同 SessionId 的数据不对外暴露。结束 session 仅删除对应清单；不做历史归档。
- 文件损坏时保留原文件并在 Teacher UI 显示简短错误；任务读取失败不得使 `/api/session` 或策略 API 失败。

## 界面原则

- 清单只有一种任务类型和一个完成动作；标题过长/输入空白时不写入。
- 未添加任务时隐藏进度卡片内容，只保留一行输入提示。
- 手机显示为简洁完成比例与列表，完成项用较淡颜色和删除线区分；手机不出现编辑入口。
