# 手机端长期系统策略控制需求

## 问题与用户

在已实现的手机教师控制基础上，教师需要在校园 LAN 内查看学生机系统基线，并对已选学生电脑启用或解除桌面预先保存的长期策略组合。系统策略手机端范围已确认，细项归本规格维护。

## 用户故事

- 作为已配对的教师，我可以在手机上检查各学生电脑的六项系统策略、版本及待复核状态。
- 作为已配对的教师，我可以选择桌面端保存的系统策略预设，确认影响范围后对选中电脑启用或解除。
- 作为教师，我可以从桌面读取完整逐台结果和本机审计记录；手机命令不能绕过教师签名、学生 Agent 身份固定、校园 LAN、当前 Veyon 目标目录或学生机的既有策略冲突保护。

## 范围

六项现有长期系统策略：锁定 Windows 默认壁纸；禁止学生修改日期、时间和时区；限制网络连接设置；限制软件安装；禁止账户管理及本人修改登录密码；限制 Control Panel/Settings（该项按桌面当前设置，默认关闭）。系统策略不自动到期，解除必须由教师再次发送解除命令。

手机只选择桌面保存的预设和电脑，不编辑 SID、规则或签名内容。预设随教师本机校区隔离。启用软件安装限制仍需桌面端阅读影响说明并确认，手机启用时再次显示具体设置并确认。

## 验收条件

1. 当教师保存系统策略预设时，系统须保留当前六个开关、校区、学生 SID 和更新时间，且标记为无自动到期；无开关、无学生 SID、错误 SID 或未确认的软件安装限制不得保存。
2. 当配对手机读取已验证 Agent 状态时，系统须展示六项当前值、策略版本和待复核/未知状态；不得把缺少策略、离线或不支持的学生包显示成已关闭/已生效。
3. 当教师在手机确认启用系统预设时，教师电脑须使用该校区独立系统策略签名密钥和递增版本，通过现有学生 Agent 接口推送；每台结果须核验 Agent 签名与固定身份。
4. 当教师在手机确认解除系统策略时，教师电脑须发送六项关闭的长期系统策略；学生端仅恢复本工具仍拥有且未被外部改动的资源。
5. 当手机更换预设、目标或校园时，原有审核确认不得被复用；命令仅允许经配对凭据、请求防重放、同源保护及校园 LAN 检查的请求到达。
6. 当任一设备未确认或需复核时，界面须逐台标记结果，且审计记录写入教师电脑本机；结果不得宣称已完成 Windows 实机效果验证。

## 非目标

- 手机端创建账户、编辑学生 SID、上传壁纸或编辑任意注册表值。
- 公网中继、CloudBase 转发或校园 LAN 之外的远程控制。
- 以 Agent 接受回执替代 Windows 权限、策略读回、壁纸显示、安装拦截或账户操作实机验收。
