# 本地课堂会话：实施任务

- [x] 1. 定义本机 Profile/Room 快照、课堂状态和 session-scoped Target ID
  - 从既有机房目录读取电脑编号，不引入学生姓名或第二套目录。
  - 固定 150 台上限、UTC 时间及 `Active → Ended` 单向生命周期。
  - _需求：1、2、4、6_
- [x] 2. 实现本机有界会话存储
  - 最近 30 条已结束记录与最多一条活动记录；1 MiB 上限。
  - 严格 JSON、重解析点拒绝、原子写入、跨实例互斥及损坏时保留原件。
  - _需求：3、5、7_
- [x] 3. 设计课堂事件与授权边界
  - 定义版本化事件信封、事件 allowlist、目标范围、去重/时效和负载上限。
  - 明确目标 ID 不认证身份；教师与学生身份须由现有教师配对/Agent 信任边界验证。
  - _需求：8、9_
- [x] 4. 增加自动化检查并更新架构/实施记录
  - 覆盖生命周期、范围、隐私、保留、损坏恢复、锁互斥及序列化边界。
  - 记录精确命令与实机未验收项；单独提交此功能。
  - _需求：1–9_
- [ ] 5. 在 Windows 教师机验收本机数据目录 ACL、进程中断后的文件完整性和双实例写入互斥；此项不代表课堂消息服务已经验收。
