# 课堂即时测验：需求

> 状态：尚未具备用户可用流程。教师进程内存状态机、独立签名消息契约、教师服务 API 和 Session/目标变化清理已有首段代码。Student Agent/Companion 接入、教师界面、手机可视化及实机验收仍待完成。仅在 develop 派生的独立开发分支推进，不并入稳定发布候选。

## 目标

教师在活动课堂中发起一道简短单选题，学生通过 Student Companion 作答；教师看到汇总结果，用于课堂理解度检查。第一版复用本机课堂会话与校园网，不依赖 CloudBase。

## 范围

- 仅允许在活动课堂中创建测验；目标范围固定为当前 Session 的学生电脑，最多 150 台。
- 每个 Session 同时只有一道开放题。教师从 Teacher Console 创建、关闭并选择是否揭晓结果。
- 题目最多 200 个字符，包含 2–5 个选项，每个选项最多 80 个字符；不支持自由文本。
- Student Companion 显示题目和当前学生已选的选项。开放期间允许更改答案；关闭后不可更改。
- 开放期间 Teacher 只看已提交数量；关闭并揭晓后，教师桌面和已配对手机只看各选项总数及总提交数。
- 每个已授权目标最多贡献一票；同一答案重试不会重复计数。重复提交不同选项时，只保留该目标最后一次有效选择。
- 不显示学生姓名、电脑编号与个人选择的对应关系。学生只看到自己的提交状态，不看到班级答案分布。
- 课堂结束、教师进程重启或教师取消题目时，测验立即失效并清除答题映射；不恢复旧题。

## 隐私与非目标

- 题目、选项、单机答题映射和统计均只存在教师进程内存，不写文件、不上传 CloudBase。
- 服务只在开放期间短暂按目标保存当前选项，以去重和计算改选汇总；只向 Teacher UI 返回汇总数字。
- 第一版不含成绩、排名、答题历史、导出、题库、自由文本、定时考试或课后云端汇总。
- 课堂互动只走教师机局域网；互联网中断不得影响已建立的课堂控制链路。

## 验收条件

1. 无活动 Session、目标为空或配置不完整时，Teacher 不能发起题目。
2. 问题和选项按大小与数量上限校验；未知字段、其他 Session、过期题目及未授权目标均被拒绝。
3. 一个目标重复提交同一选择只计一次；开放期间改选只更新汇总；关闭后任何新提交均被拒绝。
4. 教师界面和只读手机 API 只收到提交总数及汇总选项数；学生接口只返回自己的选择；接口、日志和持久化文件中没有个人答题记录。
5. 教师重启、Session 结束或题目取消后，旧题、答案映射和未送达的答题提交不能复活或计入下一堂课。
6. 学生端断线时明确显示未确认状态；恢复连接后只读取当前活动题，不将过期题目或离开课堂后的提交显示为成功。
7. 真实局域网、教师/学生重启和 10/24 台并发需单独现场验收；协议检查不代替设备验收。
