# 学生机网站限制需求

## 目标

教师能对选定学生电脑签发课堂网站黑名单或白名单；学生机上的 SYSTEM Agent 验证策略后，将机器级浏览器规则应用到 Microsoft Edge、Google Chrome 和 Mozilla Firefox。策略应可签名撤销、限时恢复，并在教师离线时继续由学生机本地执行到期处理。

此能力按域名管理浏览器访问，不是全机网络过滤，也不提供对抗本机管理员的安全边界。

## 用户故事

- 作为教师，我能选择机房电脑、输入要限制的域名、选择黑名单或白名单，并按课堂时长推送或立即解除。
- 作为教师，我能看到每台电脑已应用、已解除、离线、失败、冲突或待核对状态，并只对需要处理的目标再次发起新操作。
- 作为学生机管理员，我能在 Teacher 离线时保留已确认的网站策略；到期或撤销时只恢复本工具仍拥有且未被外部修改的浏览器设置。
- 作为学生机维护者，我能在确认移除 Agent 时清除本工具拥有的浏览器规则和防火墙/任务资源，同时保留 Veyon、StudentSetup 和学校/管理员策略。

## 验收条件

1. 支持黑名单、白名单和停用三种模式。黑/白名单至少包含一个域名，停用模式不带域名且不设置到期时间；白名单启用时，浏览器策略先阻止普通网页，再只放行列表中的域名。
2. 输入只允许域名或不带路径的 HTTP/HTTPS 地址。规范化结果为小写 IDNA 主机名；拒绝通配符、IP、端口、凭据、路径、查询或片段。去重后每份名单最多 1000 个域名，策略正文不超过规定大小。
3. 同一份策略按浏览器语法编译：Edge URL filter、Chrome `[*.]domain` pattern、Firefox Enterprise WebsiteFilter。黑名单匹配根域和子域；不把浏览器策略描述为 URL 路径过滤或所有浏览器统一过滤。
4. Teacher 对策略使用校区网站策略密钥签署 RSA-PSS 信封；Agent 验证签名、校区、递增 revision、严格 JSON、签发时间、策略模式和期限，拒绝错误校区、重复/旧版本、篡改、重放和无效/过期输入。网站密钥与应用、系统和 Developer Release 密钥用途隔离。
5. 非自动到期策略使用 schema v1；设到期时间的策略使用 schema v2，期限不超过签发后 24 小时。Teacher UI 提供已批准的 45/60/90/120 分钟或不自动到期选择；实际期限、模式和 revision 在逐台结果中可见。
6. Agent 以受保护的 SYSTEM 开机任务运行，不能依赖 Teacher 或互联网在线来维持和到期清理已应用策略。服务/任务启动、配置包校区公钥、签名策略状态和策略能力须分别验证。
7. Agent 只修改本工具明确管理的 Edge、Chrome、Firefox 策略值，并记录原值和工具值。遇到既有学校策略、未知任务、损坏/缺失所有权记录或外部修改时停止覆盖，保留现场并报告冲突；回滚不能误删其他软件的策略。
8. Agent 在启动时及定期检查到期策略。到期、教师停用或卸载时，只清理与状态记录一致且当前值仍等于工具写入值的注册表数据；每项写入和恢复都需读回，部分失败须显示待核对。
9. Teacher 将请求通过校园 LAN 直接推给 Student Agent，不经 CloudBase。逐台成功须由已固定的 Agent 身份密钥签名，并绑定校区、目标指纹、nonce、请求摘要和策略版本；首次信任或换钥需教师明确审批，未验签/未固定的结果不得标为成功。
10. Teacher 保存有界的逐台推送历史，当前最多保留最近 50 次目标/结果；超时标记为待核对，不自动重试。不得保存策略签名正文、域名清单、浏览历史、访问页面内容或学生文件作为运行遥测。
11. 手机只能操作 Teacher 桌面预先保存的网站策略预设，复用相同目标选择、签名、身份固定、逐台状态和审计流程。手机不能持有策略私钥，也不能直连学生 Agent 或 CloudBase 转发操作。
12. 移除网站 Agent 必须显式确认；只删除本工具拥有且无外部改写的浏览器值、SYSTEM 任务和对应防火墙规则，不移除 Veyon/StudentSetup。学生之后须按浏览器提示手动重启，且卸载/恢复结果不能虚报成功。
13. 可移植检查与 Windows 实机验收分开记录。策略编译、注册表预期值或 Agent 回执不能证明真实浏览器已拦截网站；目标 Windows/浏览器版本、HTTPS、策略页读回、刷新/重启、离线/恢复和 ACL 必须现场验证。

## 范围与边界

- 当前首版限 Edge、Chrome、Firefox 正式安装的机器级策略和域名匹配；不支持页面路径、便携浏览器、其他浏览器、非浏览器应用、DNS 拦截或全机网络流量过滤。
- 应用阻止规则、学生长期系统基线和 CloudBase 校区包发布是不同控制域；网站策略不能代替它们。
- 详细实现见[网站访问限制设计](../../docs/网站访问限制设计.md)；项目级状态和 P12 验收结论以[开发路线与任务清单](../../docs/开发路线与任务清单.md)为准。
