# 课堂模式实施任务

- [x] 1. 定义模式模型和有界本机状态
  - 记录当前模式、活动 session、逐个随机 target ID 的策略拥有 revision 和未完成恢复项。
  - 不保存网络地址、学生身份、策略正文或系统策略拥有权。
  - _Requirements: 固定规则 1、6、7、9_
- [x] 2. 扩展课堂签名状态与 Student Companion 显示
  - 为 active 状态增加 v2 固定模式字段，同时保持旧 v1 状态可读取。
  - 新会话默认为正常课堂；下课清理 Companion 的课堂状态。
  - _Requirements: 验收 1_
- [x] 3. 实现练习模式策略执行与逐台拥有记录
  - 使用当前校区最新的网站和应用预设以及活动课堂固定目标。
  - 读回 Agent 签名状态；当前策略不是 Disabled 或本课堂 revision 时不覆盖。
  - AppLocker Enforce 保留 Audit → 教师确认 → 新鲜回读校验流程。
  - _Requirements: 固定规则 2–5、验收 2–4_
- [x] 4. 实现恢复正常/下课的按拥有版本恢复
  - 逐台比较签名读回 revision 与本课堂记录，只恢复匹配策略。
  - 离线/未知状态保留有界待恢复项；外部版本变化保留外部状态。
  - Session end 时清理课堂事件/授权并保留待恢复项。
  - _Requirements: 固定规则 6–7、验收 5–6_
- [x] 5. 接入 Teacher 桌面与手机控制界面
  - 课堂卡片提供“开始练习 / 恢复正常”切换及一个独立下课动作；显示预设和逐台结果。
  - 手机由服务端从活动 session 和本校最新 preset 决策，不提交任意 target/profile。
  - _Requirements: 用户故事 1–2、固定规则 1–3_
- [x] 6. 增加协议/状态/审核/恢复检查并维护指南与记录
  - 覆盖审计确认失效、外部策略接管、课堂结束残留和系统策略不被修改。
  - 运行开发指南中的完整 Release 检查；记录真实 Windows/手机验收待办。
  - _Requirements: 验收 1–9_
- [ ] 7. 增加结束课堂后的待恢复记录查看与重试
  - 只根据原 session 的稳定目标标签匹配当前房间条目；重新读取签名状态后才尝试恢复，不持久化旧网络地址。
  - _Requirements: 固定规则 7、验收 6_
- [ ] 8. 完成 Windows 与真实手机验收
  - 验证桌面/手机单按钮模式、Agent 签名状态兼容、网站/AppLocker 命中和逐台恢复。
  - _Requirements: 验收 1–9_
