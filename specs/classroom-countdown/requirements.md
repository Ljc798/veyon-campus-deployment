# 课堂倒计时：需求

## 目标

教师在当前课堂开始一个简单倒计时，教师电脑持续显示剩余时间；已配对手机可只读查看。倒计时属于本机活动课堂，不创建学生任务或云端记录。

## 验收条件

1. 教师只能在活动课堂中启动计时；默认 15 分钟，可调整为 1–180 分钟。
2. 教师启动后看到本机计算的剩余时间，时间到显示“时间到”；结束课堂后该计时不再显示。
3. 计时只保存 `SessionId`、开始时间和截止时间；使用 UTC 截止时间，Teacher 重启后仍能恢复当前活动 session 的计时。
4. 活动课堂配对手机只读显示剩余时间，不提供启动、调整或停止入口。
5. 缺失计时文件等同于未启动；损坏/越界数据不得静默覆盖，也不得影响课堂、手机配对或策略 API。
6. 不依赖 CloudBase，不保存学生身份、设备目标、任务内容或消息正文。
7. UI 复用现有课堂页面和品牌样式；只提供时长控件、开始动作、剩余时间和结束动作，不增加导航或暂停/预设选择。

## 非目标

- 不将倒计时作为 Windows 强制策略，也不在到时自动解除/启用任何限制。
- 不实现任务进度、共享链接或学生端通知。
- 不保证本机时钟被手动改动时的精确单调计时；显示以 UTC 截止时间和系统时钟为准。
