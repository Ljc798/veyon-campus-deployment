# 自定义教室座位网格与换座：实施任务

- [x] 1. 新增本地座位网格模型和严格存储
  - 默认 15×15、编辑上限 30×30；支持行优先座位号、空格区域、桌位、学生姓名和可选的目标映射。
  - 增加有界解析、原子保存、重复/损坏拒绝及现有文件安全迁移。
- [x] 2. 简化座位添加和姓名编辑
  - 使用一个“添加座位”模式开关；点击空格或按住鼠标拖动可连续添加桌位；拖动只会新增，不会删除已有座位。
  - 删除已有桌位必须单击并确认；取消编辑可恢复本次编辑前的座位、姓名、编号和行列。
  - 点击已有桌位只编辑姓名；空姓名保留为实体桌位，不生成电脑。
  - 删除手动读取本机电脑和手动绑定电脑的座位编辑流程。
- [x] 3. 按已填写姓名的桌位创建 Veyon 学生电脑
  - 电脑清单数量只按有姓名桌位生成。
  - 写入 Veyon 后自动读回并在唯一匹配时一次性关联；空姓名桌位不生成电脑。
  - 移除本机桌位时不自动删除 Veyon 电脑对象。
- [x] 4. 实现换座模式与 Veyon 名称更新计划
  - 可视化交换两名学生的座位归属；每台设备按原 IP 保持绑定。
  - 生成仅修改 Veyon Computer `name` 的计划，包含备份、确认、逐台读回和部分失败恢复。
- [x] 5. 将学生/座位信息接入教师和已配对手机课堂视图
  - 手机只读取地址命中本堂活动目标且带稳定 ID 的关联座位号、姓名和电脑名；课堂会话和预览租约限制目标范围。
- [ ] 6. 完成 Windows Veyon 目录操作、手机/LAN 与 150 台容量实测并记录
  - 本地构建与代码检查不能代替真实教师机、学生机和手机验收。
