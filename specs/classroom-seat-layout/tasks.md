# 自定义教室座位网格与换座：实施任务

- [x] 1. 新增本地座位网格模型和严格存储
- 默认 15×15、编辑上限 30×30；支持行优先座位号、空格过道、学生姓名和稳定目标映射。
  - 增加有界解析、原子保存、重复/损坏拒绝及现有文件安全迁移。
- [x] 2. 重做教师地点/机房座位编辑流程
  - 删除常用校区/地点预设入口；只输入校区和地点名即可打开空白网格，逐格添加座位、输入姓名和直接编辑。
  - 电脑命名前缀/起始编号与主机/IP 覆盖为选填，电脑数按已选座位数生成；零台电脑地点不能开始课堂。
  - 新增地点操作合并只读冲突检查、Veyon 写入和读回；发现冲突即停止，不写入。
  - 桌面和触屏可操作，不要求教师手工编号。
- [x] 3. 实现换座模式与 Veyon 名称更新计划
  - 可视化交换两名学生的座位归属；每台设备按原 IP 保持绑定。
  - 生成仅修改 Veyon Computer `name` 的计划，包含备份、确认、逐台读回和部分失败恢复。
  - 通过受限 Worker 导入计划；备份使用当前用户 DPAPI，并在读回发现安全差异时自动恢复。
- [x] 4. 将学生/座位信息接入教师和已配对手机课堂视图
  - 新网格只向手机返回地址命中本堂活动目标且带稳定 ID 的关联座位号、学生姓名和 Veyon 电脑名；旧布局暂只兼容行列。课堂会话与预览租约限制目标，不接受任意主机/IP 查询。
  - 新建电脑经 Veyon 读回后按座位号自动关联；仅在名称、地址和地点稳定 ID 全部唯一匹配时一次性保存，异常时不产生部分关联。
- [x] 5. 完成座位驱动的屏幕巡视接入、文档与代码检查
  - `/api/session` 只为当前课堂已绑定的座位提供稳定目标 ID、座位号、学生名和电脑名；手机画面请求不提交 IP。屏幕巡视租约保存完整座位绑定快照，座位或学生资料变化后拒绝旧画面、撤销租约并取消采集；手机刷新课堂状态时清除旧卡片和图像。
  - 用户指南与[屏幕巡视 API 契约](../classroom-screen-preview/api.md)已覆盖座位卡片、画质/刷新和授权范围。
- [ ] 6. 完成 Windows Veyon 目录操作、手机/LAN 与 150 台容量实测并记录
  - 与[屏幕巡视任务 7](../classroom-screen-preview/tasks.md)共用现场验收证据；实测前不标记通过。
- [x] 7. 在教师座位图和打印座位表中以颜色和文字图例区分过道、未关联 Veyon 目标的桌位和已关联电脑的桌位；悬停提示展示桌位绑定状态，打印件只显示读回的电脑名，不生成推测的电脑名。
  - 实现由现有座位/目标数据推导显示状态；未运行 Windows UI 或打印实机验收。
