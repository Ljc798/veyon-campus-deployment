# 机房座位图：需求

## 目标

教师可把已有电脑编号排到对应的实体座位位置，并在桌面及已配对手机的课堂求助卡片中快速定位。座位图只保存在教师电脑，使用校区/机房稳定 ID 绑定，不记录学生姓名。

## 用户故事

- 作为教师，我希望选中一个本机机房档案后立即看到由电脑编号生成的初始座位图，不必重新录入电脑清单。
- 作为教师，我希望交换座位卡片并调整每排座位数，使显示顺序符合真实教室。
- 作为教师，我希望桌面与手机上的求助消息同时显示该电脑所在排和座位号。
- 作为校区管理员，我希望新增/移除电脑或改名前缀后，既有可匹配的位置得到保留，新增电脑按默认编号顺序加入。

## 验收条件

1. 当教师打开已保存的机房档案时，系统应从配置的电脑范围生成一张默认座位图，并按数字顺序排列。
2. 当教师交换两个座位时，系统应立即在教师机本地原子保存；重启应用后顺序和每排座位数仍保持。
3. 当教师调整每排座位数时，系统应保留电脑顺序，仅重新计算行列位置；列数固定在 1 到当前电脑数之间。
4. 当机房电脑范围改变时，系统应保留仍存在的电脑顺序，并按编号顺序追加新电脑；不匹配的旧电脑不得显示为当前座位。
5. 当活动课堂中的学生发出求助时，Teacher 桌面和已配对手机应显示当前活动机房计算出的“第 N 排 · 第 M 位”；若该目标无法映射，则仍显示电脑编号且不伪造位置。
6. 当座位图文件缺失、损坏、超限或存在重复/越界位置时，系统不得静默覆盖旧文件或向移动 API 返回部分错误映射，并应给出本机可理解的状态。
7. 座位图不得包含学生姓名、IP 地址、消息正文或云端身份；本功能不得修改 Veyon 目录、课堂策略、AppLocker 或系统设置。
8. 桌面布局编辑只在已有“地点与学生名单”页中出现，不新增导航入口；默认座位顺序无需教师逐台确认。

## 非目标

- 不上传 CloudBase，不做学生身份管理、座位考勤或学生画像。
- 首版以规则矩形网格表示机房，不提供自由画布、图片底图、桌椅图标或多层楼层。
- 不在手机上编辑座位；手机只读显示当前课堂的座位位置。
