# 自定义教室座位网格与换座：需求

## 目标

用桌位图表示教室布局。空白格是通道等空区域；有桌位但没填姓名时，只记录实体桌子；填写姓名后，该桌位才进入学生电脑清单。座位图和姓名只保存在教师机本地。

## 用户故事

- 作为教师，我希望在一个添加模式中点击格子就能添加桌位，再点击已有桌位就能移除，不必对每格重复操作或确认。
- 作为教师，我希望点击已有桌位后只编辑学生姓名，不需要绑定一个 Veyon 电脑；姓名留空的桌位不创建学生电脑。
- 作为教师，我希望创建 Veyon 地点时，电脑清单只包含已填写姓名的桌位，并在写入后自动核对，不需要手动读取本地电脑或逐台绑定。
- 作为教师，我希望座位号按从上到下、每行从左到右自动排列，并能用换座模式交换两位学生。
- 作为教师，我希望桌面和已配对手机按当前学生座位找到对应的学生机屏幕与课堂目标。

## 验收条件

1. 默认网格为 15×15；教师可编辑到最多 30×30。添加模式是单一开关：点按格子可增删桌位；按住鼠标左键拖过多个格子时，按起始格子的相反状态连续绘制，可一次添加或移除一排/一片桌位；关闭后点击已有桌位打开姓名编辑。
2. 修改姓名不改变格子位置。姓名可以留空；空姓名桌位只保留为本地桌位，不生成学生电脑。创建 Veyon 地点和电脑时，电脑数量等于已填写姓名的桌位数。
3. 座位号按从上到下、每行从左到右连续编号；空格不编号。增删桌位后编号自动更新，界面显示所在行列。
4. 座位图编辑不显示手动读取本机电脑或手动绑定 Veyon 目标的流程。创建学生电脑后，教师端自动读取写入结果，并且只有在名称、地址和地点身份唯一匹配时才保存关联。
5. 教师可在换座模式中选择两个有学生姓名的座位并交换学生归属。换座保留物理电脑 IP/hostAddress 与 Veyon 身份。
6. 换座确认计划只更改对应 Veyon Computer 对象的 `name` 显示字段；不得更改 IP/hostAddress、Windows 计算机名、MAC、认证公钥、组或防火墙规则。执行前保存可核对备份。
7. Veyon 名称更新后必须读回名称和 IP：两项均匹配计划才报成功；失败或部分结果逐台显示，可安全重试或核对。
8. 座位、姓名和目标映射保存在教师机本地；不进入学生部署配置包、不上传 CloudBase、不进入匿名遥测。配对手机只读取当前课堂授权范围内的信息。
9. 布局和姓名文件损坏、重复、超限或无法原子保存时停止写入并保留旧文件；不得影响既有 Veyon 目录或课堂策略。
10. 手机课堂页面使用简明中文；默认显示学生/座位标签与图像，不出现技术协议、主机配置或密钥术语。
11. 新地点可先保存为空布局；创建学生电脑时至少需要一个有姓名的桌位。没有学生电脑的地点不得开始课堂会话。
12. 只有已填写姓名的桌位参与电脑清单生成和自动关联。空姓名桌位不生成推测的电脑名或地址。移除桌位仅移除本机桌位记录及关联，不自动删除 Veyon 中的电脑对象。

## 非目标

- 首版只支持单层平面网格，不提供自由画布、照片底图、楼层管理或云端同步。
- 换座不改 Windows 主机本身的 IP，也不重装 Veyon；它只更新教师端本地座位记录和明确列出的 Veyon Computer 名称字段。
- 不做考勤、学生画像、自动识别屏幕内容或录像。
