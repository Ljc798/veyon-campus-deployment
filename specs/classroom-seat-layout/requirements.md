# 自定义教室座位网格与换座：需求

## 目标

教师用一个可自定义的平面格子表示教室。空格可用于过道或讲台；教师选择有座位的格子并填写学生姓名。系统按从上到下、每行从左到右的顺序给已选座位编号。换座时交换学生归属，并把 Veyon 中对应目标的显示名称更新到新座位；原电脑 IP 地址保持不变。

## 用户故事

- 作为教师，我希望只填写校区和地点名称就能打开默认 15×15 的空白网格，并可扩到 30×30，按教室平面点亮座位格并留空做过道。
- 作为教师，我希望点中有座位的格子后填写或修改学生姓名；座位号由选中的格子自动生成，不必手工编号。
- 作为教师，我希望在换座模式中选两名学生交换座位，座位和电脑 IP 不被重建或互换。
- 作为教师，我希望旧的“常用校区/地点”快捷模板入口移除，日常建教室只从这张自定义网格开始；有明确需求时再加回模板。
- 作为教师，我希望桌面和已配对手机按当前座位号找到学生机屏幕与课堂目标。

## 验收条件

1. 默认网格为 15×15；教师可编辑到最多 30×30，并能将任意格子留空作为过道。
2. 点击空格可设置为座位并录入学生姓名；再次编辑姓名不改变格子位置。移除座位时需明确处理其电脑/IP 映射，不能静默把电脑分配给另一个学生。
3. 有座位的格子按从上到下、每行从左到右编号；过道不占号。增删座位后编号自动连续，UI 同时显示所在行列。
4. 每个座位最多绑定一台 Veyon 目标及一个学生姓名；每台目标最多属于一个座位。未绑定、重名或含糊目标显示待处理，不得伪造 IP 或重复绑定。
5. 教师可启用“换座模式”，选择两个有学生的座位并交换学生归属。交换保留格子、座位号、电脑 IP/hostAddress 与 Veyon 认证身份。
6. 换座确认计划只更改 Veyon Computer 对象的 `name` 显示字段，使其对应新座位/学生；不得更改 IP/hostAddress、Windows 计算机名、MAC、认证公钥、组或 Veyon 防火墙。执行前展示逐台旧/新名称与保留的 IP，并保存可核对备份。
7. Veyon 名称更新后必须读回名称和 IP：两项都匹配计划才报成功；失败或部分结果显示逐台状态，可安全重试或核对，不能伪报整体成功。
8. 座位和姓名保存在教师机本地；不进入学生部署配置包、不上传 CloudBase、不进入匿名遥测。配对手机只通过已有教师局域网会话读取当前课堂所需的信息。
9. 布局和姓名文件损坏、重复、超限或无法原子保存时停止写入并保留旧文件；不得影响既有 Veyon 目录或课堂策略。
10. 手机课堂页面使用简明中文；默认显示学生/座位标签与图像，不出现技术协议、主机配置或密钥术语。
11. 新地点可先以零台电脑的状态保存座位图；电脑编号前缀和起始编号为选填项，写入 Veyon 时电脑数量自动等于已选座位数。没有配置电脑的地点不得开始课堂会话。
12. 添加电脑成功后，教师端以 Veyon 读回的电脑名、地址和地点 ID 将全部目标按座位顺序关联；任何目标无法唯一核实时，整批自动关联不写入，教师仍可手动逐台关联。

## 非目标

- 首版只支持单层平面网格，不提供自由画布、照片底图、楼层管理或云端同步。
- 换座不改 Windows 主机本身的 IP，也不重装 Veyon；它只更新教师端本地座位记录和明确列出的 Veyon Computer 名称字段。
- 不做考勤、学生画像、自动识别屏幕内容或录像。
