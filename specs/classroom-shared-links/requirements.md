# 课堂共享链接：需求

路线图对应项：P2“共享链接快捷入口”。本规格将链接能力复用到现有全班通知，不增加配置页或额外输入框。

## 目标

教师在现有全班通知中附带一个课堂网页地址，学生可以从 Student Companion 主动打开；已配对手机显示的同一通知也能直接访问该地址。

## 验收条件

1. 教师继续使用现有全班通知输入框发送消息，不新增接收对象、链接类型或策略选项。
2. 仅当通知中恰好包含一个有效 HTTP 或 HTTPS URL 时，才显示打开入口；多个链接、无效地址或其他 scheme 保留原文，不显示快捷入口。
3. Student Companion 只在学生主动点击“打开课堂网址”后通过操作系统默认浏览器打开地址，不自动启动程序或导航。
4. 拒绝带用户名或密码的 URL；链接长度不超过 2048 字符。通知继续由教师签名、绑定当前课堂并遵守现有两分钟有效期。
5. 通知到期或课堂 session 变化后，消息和打开入口同步清除；窗口收起到托盘期间也按时清除。
6. 手机控制页将唯一有效 HTTP(S) URL 显示为安全的新标签链接，使用 `noopener noreferrer`；普通文本按文本节点呈现，不解析为 HTML。
7. 不新增云端历史、目标选择、链接预览或自动执行行为。

## 非目标

- 不在 Student Companion 内嵌网页浏览器。
- 不对教师提供的网页内容背书，也不自动下载文件。
- 不支持 `file:`、自定义协议或多个链接的快捷打开。
