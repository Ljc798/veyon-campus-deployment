# 课堂共享链接：设计

## 组件边界

- Teacher 继续通过既有 `ClassroomNotice` 发送通知；签名事件、session 绑定、全班目标与两分钟 TTL 均不变。
- Core 的 `ClassroomNoticeLinkParser` 从通知正文提取唯一 HTTP(S) URL。它拒绝无效地址、userinfo、多链接及超长地址，并去除常见句末标点。
- Student Companion 保存当前通知正文、URL 和原始 `ExpiresUtc`。到期或 session 改变时清除；窗口用一个到期计时器更新界面，即使窗口在托盘中也生效。
- 打开动作在点击时再次检查有效期，并调用操作系统默认浏览器。启动失败时在原通知区域显示简短提示。
- 手机控制页使用同样的单链接规则，只通过 DOM 文本节点和 `<a>` 元素绘制；外部标签设置 `rel="noopener noreferrer"`。

## 信任与失败处理

- `http` 和 `https` 是唯一可打开协议；不接受用户名/密码、空主机或超过 2048 字符的地址。
- 零个、多个或无效链接都按普通通知文本显示。现有签名验证、Agent 授权和课堂目标过滤仍是内容来源的信任边界。
- 点击前以 UTC 重新判断到期时间；下课清除当前课堂通知。浏览器无法启动时保留通知，允许学生再次尝试或手动复制。
- 不保存点击记录，不在服务端新增数据，不引入 Veyon WebAPI、额外证书或密钥。

## 状态

```text
有效通知收到 ── 唯一安全链接 ──> 显示“打开课堂网址”
      │                                  │ 学生点击且未过期
      │                                  └──> 系统默认浏览器
      ├── 无链接 / 多链接 ──> 只显示原文
      └── TTL 到期或 session 变化 ──> 清除通知与打开入口
```
