# P1-01 Edge 浏览器版本与会话诊断

日期：2026-10-18
目标版本：1.1.2
状态：执行器改为直接以匹配的普通用户令牌启动固定 Edge 参数；构建后仍需校区学生实机验收

## 实现范围

- Agent 为教师端提供签名的状态协议 v3；旧版 Agent 不支持 v3 时，教师端依次回退到 v2、v1。
- Agent 只读盘点机器级和已登记用户配置目录中的 Edge Stable、Beta、Dev、Canary 安装版本，并收集当前 `msedge.exe` 的路径、文件产品版本、PE 架构、进程 PID、SessionId、用户 SID、完整性级别、启动时间和磁盘映像修改时间。
- 对照已安装文件与运行进程文件的版本/修改时间。文件被更新不等于既有 Edge 进程已切换到新代码；此差异在教师端明确显示。
- 查询 `edgeupdate`、`edgeupdatem` 和 `MicrosoftEdgeElevationService` 的安装、运行与启动状态。
- 汇总 Agent 当前读回的策略 Revision、最新刷新队列 Revision，以及各用户会话的执行器本地状态与错误码。
- 教师端“读取逐台状态”展示设备诊断，并按当前进程与刷新回执给出“浏览器未运行”“需要升级或验证兼容性”“请求已发出但未核验”或“待人工检查”等判断。

## 状态解释

- Agent 状态中的网站策略 Revision 表示 Agent 读回的策略状态，不代表 Edge 已应用。
- `DispatchedUnverified` 只表示会话执行器已发出刷新请求，不代表 Edge 已读取策略。
- `VerifiedApplied` 仅作为执行器本地报告字段显示；该报告本身不能替代 `edge://policy` 读回及新导航验证。
- 将版本不低于 `142.0.0.0` 且位于标准机器级 Stable 路径的安装标记为支持平台策略刷新。Edge 118 等更早版本会显示需要升级或验证兼容性，不运行该参数。
- 无 Edge 进程时不启动浏览器；保留“浏览器未运行”状态。

## 隐私与读取限制

- 教师端仅显示部分脱敏 SID；用户配置目录路径统一替换为 `%USERPROFILE%`。
- 不采集浏览器 URL、历史记录、学生姓名或认证材料。
- 进程、安装和服务读取分别隔离异常；单个不可读条目以错误码或警告返回，不阻断整台设备状态读取。
- 单份执行器状态最多读取 32 KB，执行器日志最多读取 256 KB；执行器日志沿用 256 KB 单文件轮转。
- 执行器报告来自用户态本地文件，教师端将其标作诊断信息，不把它当作 Agent 认证的浏览器应用证明。
