# 官网帮助文档写作与发布规则

## 发布边界

- 官网是唯一文档来源；教师端只打开官网，不打包或缓存文档。
- 只从 `website/content/docs/` 发布文章。`docs/maintenance/`、`specs/`、测试、CI、CloudBase、发布和密钥材料默认不公开。
- 每篇文章必须有来源、受众、分类、检视版本、审阅日期和发布状态。只有 `published` 进入静态 HTML、站点地图和 Pagefind 索引。
- `keywords` 填简短检索词；可选 `aliases` 填老师可能实际输入的完整说法，可选 `errorCodes` 按原样登记界面中的错误码。别名只帮助搜索定位文章，错误码不得被写成唯一原因。
- 源码核对不等于现场验收。没有 Windows 或学校网络实测的步骤要显示“现场环境可能不同”或“尚待现场验证”，不写成稳定承诺。

## 用语

- 先用老师的任务或看到的提示作为标题，再说明原因。
- 每篇先给一句结论，随后列前提、编号步骤、如何判断、失败时下一步和相关文章。
- 专业词第一次出现时用一句白话解释；不要求读者先了解 UUID、Agent、Schema 或签名。
- 精确按钮名称来自当前界面源码。无法确认按钮名时写“打开对应页面”，不要编造控件文字。
- HTTP 状态码不能被写成唯一原因；显示多种可核对的可能情况。

## 隐私与安全

- 不写真实学校、机房、学生、设备指纹、IP、手机号、账户、令牌、私钥、证书、配置包内容或可绕过验证的步骤。
- 不嵌入第三方脚本、iframe、外部图片或原始 HTML。链接只允许 HTTPS、已知站内页面和文章内锚点。
- 构建时扫描公开源、生成 HTML、目录和静态索引；敏感扫描或链接检查失败即构建失败。
- 搜索只在浏览器本地静态索引中进行，不上传查询、不记录原始搜索词、不接入第三方统计。

## 分类

`getting-started` 快速开始；`teacher` 教师端；`student` 学生端；`classroom` 课堂控制；`devices` 设备与座位；`maintenance` 维护与更新；`faq` 常见问题；`troubleshooting` 故障排查。

## 复核

每次用户可见按钮、软件流程或最低支持版本变更时，先核对文章及搜索用例。内容维护独立于 Windows 软件版本发布。若文章需要未实现或未验收功能才能成立，应删除文章或把功能边界写清楚。
