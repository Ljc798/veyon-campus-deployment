# 机房座位图

## 新建教室与首次导入

1. 打开“地点与学生名单”并选择地点。座位图为空时，教师端会自动只读读取同名 Veyon 地点；如果该地点已有电脑，会把设备和学生姓名导入本机座位图。导入按 UUID、Host 和地点身份保留现有设备，不要求 Host 一定是 `PC-编号`，也不会写入或改动 Veyon。
2. 导入后可以拖动座位到实际位置。拖动只移动座位记录及学生绑定，原电脑 UUID、Host 和地点保持不变。
3. 点击“编辑座位”进入编辑模式。移动到网格右边缘或底边，悬浮 `+` 可增加一列或一行；网格大小和实际座位数互相独立。
4. 编辑模式下点击空白格添加座位，点击已有座位修改学生姓名或电脑编号。新增座位会建议下一个可用编号，例如 `PC-09`；新座位可以先留空姓名。
5. 保存时先保存本机座位，再自动核对 Veyon。已绑定设备按原 UUID/Host 保留并同步姓名；只有未绑定且已编号的新增座位会写入 Veyon。写入后会读回核对并刷新策略、设备维护和课堂控制名单；这些页面按当前 Veyon 目录显示电脑，不把本机计划数量当成实际设备。

## 编辑、删除与打印

- 编辑模式下，鼠标移到行号或列号会显示 `−`。点击后确认删除空行或空列；如果仍有座位，系统会阻止删除并提示先移动或移除座位。预览模式不显示行列操作控件。
- 编辑模式下右键座位，可选择“删除此座位”或“解除本机电脑关联”。删除会移除本机座位及其本地关系；解除关联保留学生姓名和固定电脑编号，只清除本机 UUID/Host 对应。两种操作均不会删除 Veyon 中的电脑对象，保存前都可用 Ctrl+Z 撤销。
- 如果自动导入提示设备已绑定到另一份本机地点档案，使用“打开已有的冲突座位图”查看原资料；不要重复导入同一批电脑。
- 建立本机座位与现有电脑的对应关系只保存本机；点击“保存”后才会写入或更新 Veyon 并进行读回验证。页面会分别报告本机保存和 Veyon 同步状态。若 Veyon 写入、读回或权限检查失败，本机资料仍保留，并提供原因和重试入口；策略、维护和课堂名单不会继续显示过期本机电脑。
- “打印座位表”仍可导出并打印当前座位布局。

## 编辑与换座

- “编辑座位图”用于修改桌位和姓名；“添加座位”是一个模式开关，开启后点格子即可增删桌位。
- 点击已有桌位（添加模式关闭时）只编辑学生姓名，不要求选择或绑定 Veyon 电脑。
- “换座模式”仍用于交换已有学生的座位归属。教师端按已绑定 UUID 核对设备身份，执行改名后检查结果并保留原 Host。
- 座位、学生姓名和电脑关联保存在教师机本地；它们不会进入学生部署包或上传 CloudBase。手机课堂页面只读取当前活动课堂所需的座位信息。

当前网格文件位于 `%LOCALAPPDATA%\VeyonCampus\Teacher\classroom-seat-grid.json`。文件损坏或无法保存时，教师端保留原文件并停止应用不完整布局。

真实 Veyon 目录写入、Windows 桌面操作和手机/LAN 画面仍需在目标设备验收；本地构建不能代替现场验证。
