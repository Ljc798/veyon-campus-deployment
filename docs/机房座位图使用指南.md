# 机房座位图

## 新建教室

1. 打开“地点与学生名单”，填写校区名称和 Veyon 地点名称。
2. 点“创建地点并编辑座位”。教师端会保存本机地点档案并打开默认 **25 行 × 25 列**的空白网格，不需要先配置电脑数量。
3. 点空格添加座位并填写学生姓名；空格可留作过道。座位号按从上到下、每行从左到右自动排列，最多添加 150 个座位。调整行列数不会移动已有座位。
4. 需要新建 Veyon 电脑时，展开“电脑命名与 Veyon 连接”，设置电脑名前缀和起始编号。前缀也用于生成学生配置包，默认是 `PC-`。电脑数量自动等于已添加的座位数；可按座位号顺序填写主机名或 IP，留空时使用生成的电脑名连接。
5. 点“检查电脑清单”确认名称、地址和现有目录冲突，再点“添加到 Veyon”。写入并读回成功后，教师端会再次核对电脑名和地址，并把整份清单按座位号一次性关联；若任何一台无法唯一匹配，就不会自动关联其中一部分，可在“读取此地点电脑”后手动逐台关联。本机档案只在 Veyon 写入成功后记录电脑范围。

## 已有 Veyon 地点

在“教室座位表”点“从 Veyon 读取地点”，选择要使用的地点。点“读取此地点电脑”后，可把已读回的电脑逐台关联到座位。座位卡片显示学生姓名和电脑名；主机地址用于连接和身份匹配，不作为卡片标题。换座时系统保留座位上的电脑地址和 Veyon 身份，只更新对应 Veyon 电脑对象的显示名称。

座位、学生姓名和已绑定电脑的地址保存在教师机本地；教师端机房档案还会保存可选的主机名/IP 覆盖。它们不会进入学生部署包或上传 CloudBase。手机课堂页面只读取当前活动课堂所需的座位信息。

当前网格文件位于 `%LOCALAPPDATA%\VeyonCampus\Teacher\classroom-seat-grid.json`，旧座位布局会在读取时迁移。文件损坏或无法保存时，教师端保留原文件并停止应用不完整布局。

电脑目录写入、Windows 桌面操作和手机/LAN 画面仍需在真实设备上验收；跨平台构建不能代替这些现场检查。
