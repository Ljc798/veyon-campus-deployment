# 机房座位图

座位图使用 TeacherConsole 中已有的本机校区和机房档案，不需要重新录入电脑清单。

1. 打开“地点与学生名单”，选择校区和机房。
2. 座位图会按电脑编号自动排列。按实际教室宽度调整“每排”电脑数。
3. 依次点击两台电脑即可交换位置；每次改动都会自动保存在教师电脑。
4. 活动课堂的学生求助卡片会显示对应行和座位号。教师桌面和已配对手机显示同一位置；手机端只读。

座位图按校区和机房的本机稳定 ID 分开保存，不含学生姓名或 IP 地址，也不会上传 CloudBase。机房电脑范围变化时，仍存在的电脑位置会保留，新电脑按编号顺序加入。

座位图文件位于当前 Windows 用户的 `%LOCALAPPDATA%\VeyonCampus\Teacher\classroom-seat-layouts.json`。文件缺失时使用电脑编号生成默认布局；如果文件损坏，教师端不会覆盖原文件，也不会显示不完整的位置。

自动检查和 TeacherConsole Release 构建已通过；Windows 座位图交互、手机实机显示及活动课堂端到端流程仍需在可恢复测试设备上验收。
