## 本轮增量：网站访问方式与常用名单

- 网站策略页增加清晰的四步流程：选择学生电脑、选择访问方式、核对名单、应用限制。访问方式可选阻止指定网站、只允许名单内网站、阻止并放行例外；名单外网站在白名单模式下会被阻止。
- 当前模式按校区保存在独立版本文件中，避免改变旧名单文件格式；课堂快捷管控也使用所选模式。手机控制页同步读取和保存模式与两份名单，并显示随名单、域名格式、截止时间、所选电脑和进行中操作变化的下一步提示及对应应用按钮。
- 桌面和手机会在应用前检查当前访问方式所用名单的域名格式；提示指出需修正的名单。手机先完成本地检查再自动保存名单；服务端只校验本次方式实际使用的名单，综合方式会同时校验阻止与允许例外名单。
- 常见娱乐网站和学习网站名单可在教师端编辑并保存到本机。保存只改变之后导入使用的预设，不会自动改动或推送已保存的校区名单。
- 当前域名格式预检版本下，TeacherConsole 普通版、课堂快捷管控试点版和 StudentSetup Release 构建均成功；教师端版本各有 0 错误和 3 条既有警告，StudentSetup 为 0 警告。手机端 `node --check` 与 `git diff --check` 通过。
- `VeyonCampus.Checks` 的 82 项检查在本轮预检改动前通过；当前版本没有重跑完整检查项目。
- 未在教师端 Windows 设备运行窗口视觉检查；缩放、窄窗口和键盘操作仍需按 UI-10 的验收项检查。
