# UI-08：策略、预设、更新与运维

## 本次调整

- 网站、应用、系统限制和更新分区统一使用页面标题、说明、主题卡片和子面板样式。
- 网站目标电脑独立成浅色分区，与规则编辑区分开；操作按钮可在窄窗口下换行。
- Edge 试用版加载说明、长期软件保护技术范围和系统保护细节默认收起。
- 软件目录选择、精确规则生成、完整扫描及手工 SID/规则入口收进高级展开区；长期软件运行保护的免扫描入口保留在应用限制页顶部。
- 学生更新的逐台结果改用统一设备行样式，并按成功、等待、处理中、待核对和失败显示状态颜色；阶段耗时仍在行内展开。
- 离线更新、策略结果详情、身份诊断和影响结果仍使用原入口。

## 保留边界

- 只调整 AXAML 展示结构和逐台更新显示模型的状态画刷；网站策略、AppLocker、系统限制、确认条件、更新流程、签名、回滚和诊断服务接口未改。
- 系统限制与课堂快捷管控仍在不同页面；解除系统限制仍使用原有按钮和确认行为。
- 软件目录和手工规则虽默认折叠，仍可从“高级”区域访问。

## 检查状态

- `TeacherWindow.axaml` 通过 XML 静态解析；`git diff --check` 无空白错误。
- 未运行构建、测试或桌面视觉检查；当前环境缺少仓库指定的 .NET 10.0.100 SDK。
