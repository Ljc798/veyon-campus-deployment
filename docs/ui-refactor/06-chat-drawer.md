# UI-06：学生聊天抽屉与全班通知

## 本次调整

- 移除课堂页底部常驻的一对一聊天卡片和通知编辑卡片。
- 主窗口页头增加「学生消息」入口及未读数；右侧抽屉覆盖内容区，页面切换时保持打开。
- 抽屉提供学生搜索、学生姓名/座位、Agent 连接能力、消息时间线、空会话状态、发送失败提示和重试入口。
- 每个学生线程在当前课堂 UI 生命周期内分别保存未发送草稿；课堂事件会话变化时清空线程和草稿。
- 只有抽屉打开且当前选中该学生时，新消息才直接标为已读；关闭抽屉期间的消息会计入未读数。
- 页头「全班通知」打开确认窗口，显示当前课堂目标数量、两分钟有效期和既有发送结果；仍调用原发送处理与授权校验。
- 保留原消息协议、Enter 发送、Shift+Enter 换行、消息重试、交付状态、教师/学生身份及事件游标处理。

## 人工验收

1. 开始课堂后，从设备健康、策略和更新页面打开学生消息抽屉，切换页面时确认抽屉及当前对话保持。
2. 选中学生 A 输入草稿，切换学生 B 再切回，确认 A 的草稿仍在；结束课堂后确认会话内容和草稿清除。
3. 抽屉关闭时让多名学生发消息，确认页头未读总数增加；打开抽屉并逐个查看后确认计数减少。
4. 检查 Enter 只发送一次、Shift+Enter 换行、中文输入法候选确认不提前发送。
5. 断开学生端后尝试发送，确认显示失败且草稿保留；恢复连接后重试并核对回执。
6. 打开全班通知窗口，确认显示目标数和两分钟时效；取消不发送，发送后保留逐台目标语义与结果状态。
