### 1.0.3 候选变更摘要（发行说明草稿）

以下根据 [`beta-v1.0.2` 到 `release/basic-v1` 的 52 个提交](https://github.com/Ljc798/veyon-campus-deployment/compare/beta-v1.0.2...release/basic-v1)整理。`beta-v1.0.2` 只有标签、没有公开 Release；发行前仍应复核文案与最终标签对应的实际文件。

- 学生部署向导、校区配置包下载、预检和维护提示更精简；教师端机房设置与网站策略操作也减少了重复入口和技术性措辞。
- 学生网站策略 Agent 的重配/修复增加回滚保护：替换失败时保留此前可用配置和 Agent 文件；同时改进任务路径规范化、校区哈希比较和学生账户默认密码处理。
- Windows 发布流水线增加 Agent 重复部署/失败恢复检查；Teacher/Student 安装器安装、角色元数据、文件及卸载均有自动化冒烟覆盖，并生成 `SHA256SUMS`。
- 本摘要不代表真实校区验收完成；自动 CI 通过仍需配合教师机/学生机、校园网络和恢复场景的人工记录。
