# 课堂倒计时

倒计时只在活动课堂中显示，独立于网站、应用和长期系统策略。

1. 在“课堂控制”页开始课堂。
2. 保留默认的 15 分钟，或输入 1–180 分钟，再点“开始”。
3. 教师电脑显示剩余时间；同一课堂中已配对的手机会在课堂卡片中只读显示。
4. 需要提前停止时点“结束倒计时”。倒计时到零只显示“时间到”，不会自动切换策略或结束课堂。

倒计时按当前本机课堂 session 保存，并使用 UTC 截止时间，因此关闭或重启 Teacher 后仍可恢复。下课会清理本堂计时；计时文件损坏时保留原文件，不影响课堂和策略操作。

自动检查与 TeacherConsole Release 构建通过；Windows 重启/睡眠恢复和真实手机 LAN 显示仍需实机验收。
