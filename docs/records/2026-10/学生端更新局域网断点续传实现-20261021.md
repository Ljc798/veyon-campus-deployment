# 学生端更新局域网断点续传实现

日期：2026-10-21（Asia/Hong_Kong）

## 目标

在不改变完整签名 StudentSetup 安装包和既有原子更新事务边界的前提下，允许学生端在局域网连接中断后从已接收偏移继续下载。下载不完整、服务端资源变化或签名摘要不符时，不能进入安装流程。

## 实现

- Teacher 局域网下载服务从已验证的发布清单接收包的 SHA-256 和大小；响应公布 `Accept-Ranges: bytes`，并使用强 ETag `"sha256-{清单摘要}"`。服务持有只读文件句柄租约，整个服务生命周期内拒绝其他写入者改包；每个请求仍核对路径不是重解析点且文件大小与签名清单相同。
- 服务端接受单个 `Range: bytes=N-`。带 `If-Range` 时只有与当前强 ETag 完全匹配才返回 206；不匹配就返回完整的 200。无效范围返回 400，超出文件大小返回 416。响应 206 中的 Content-Range、Content-Length、ETag 都绑定同一签名文件大小和偏移。
- 学生端在本次命令的受保护 staging 目录中按签名 SHA-256 命名 `.partial` 文件。重试前重新读取实际落盘长度并重算已有前缀摘要，再使用 `Range` 和 `If-Range` 请求余下字节；最大三次有界请求尝试，间隔 200 毫秒。暂时性下载中断保留部分文件，尺寸超限或最终摘要错误会拒绝包。
- 如果 Teacher 版本不支持 Range、对续传请求返回 200，学生端会从零截断并重写，绝不将完整响应追加到旧前缀。对 206 响应，客户端要求偏移、末尾、总大小和 ETag 全部匹配期望值；不匹配就拒绝该次更新。
- 完整包写入完成后，学生端核对签名清单声明的总大小和完整 SHA-256，设置受保护 ACL，再用同目录 `File.Move` 发布到更新事务使用的安装包路径。只有该步骤完成后，现有事务才会创建恢复点或修改 StudentSetup/Agent。续传没有旁路签名校验或事务处理。
- 性能计时中的网络字节数包含重试期间重复传输的字节。本提交当时尚未单独上报 HTTP 重试次数；后续已由[LAN 重试遥测 v3 实现](学生端更新重试遥测v3实现-20261021.md)补齐。更新命令并发上限仍为 8，LAN 服务连接上限仍为 24，本次未调整并发、等待策略、哈希方式或安装行为。
