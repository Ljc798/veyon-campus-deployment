# 教师主界面组合预设覆盖确认

日期：2026-10-17（Asia/Hong_Kong）

## 变更

教师主界面的“保存学生代理+应用组合策略”入口此前直接覆盖同校区、同类型、同名称的已有预设，没有沿用手机控制窗口的覆盖确认。

- 保存前检查当前校区的同名组合预设；发现已有预设时显示“确认替换”对话框。
- 对话框列出当前电脑范围和逐电脑账户选择摘要，并说明将替换组合规则及账户映射。
- 取消时不调用保存流程，原预设保持不变；确认只替换本地预设，不改变已应用到学生电脑的策略。
- 更新需求、任务和使用指南，明确教师主界面和手机控制窗口的预设保存入口都需要覆盖确认。

## 当前验证

- `git -c core.whitespace=cr-at-eol diff --check`：通过（按原文件的 CRLF 换行规则检查）。
- 当前环境没有 .NET SDK；未编译 Avalonia/XAML，也未运行自动化检查。
- Windows 教师主界面对话框及取消后的原预设保留行为尚无现场验收记录。
