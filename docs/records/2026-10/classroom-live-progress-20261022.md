## 本轮实现

- “地点与学生名单”和“首次设置向导”放入默认收起的“遇到问题？”抽屉；展开即可访问，抽屉内可滚动。主侧栏保持只显示课堂日常入口。
- 课堂快捷管控卡片重做为当前网站预设、网站限制/键鼠锁定选项、当前选择和进度、统一解除入口，并提供逐台进度明细。
- 两种管控方式按钮已统一为等宽等高卡片，添加盾牌与鼠标指针线框图标，标题和说明居中排列。
- 课堂控制区移除重复会话说明和静态帮助句，摘要只显示本堂课地点与电脑数；通知/消息状态精简，逐台推送进度栏横向拉伸至卡片等宽。
- 课堂仍有效时，离线或 Agent 暂不可用的目标可进入等待队列。教师端以有界并发重试，Agent 上线后重新读取签名健康状态并核对身份，再应用最新保存的网站策略。桌面状态约每两秒刷新，手机约每五秒读取。
- 会话结束前从未送达的策略不再下发。已应用的课堂管控进入恢复重试；恢复重试依赖 TeacherConsole 进程持续运行，进程关闭时网站策略的一小时租约是兜底。键鼠锁定不会在设备稍后上线时自动补发。

## 用户现场测试

使用可恢复的测试学生电脑，并先准备一台 Agent 在线电脑和一台关机/断网电脑：

1. 安装最新教师试点包，确认主侧栏保持简洁；展开“遇到问题？”后检查“地点与学生名单”和“首次设置向导”可见并可进入，列表可滚动。课堂控制区只显示一行地点/电脑数摘要，通知与消息状态没有重复说明。
2. 开始课堂并选择网站限制。在线电脑应开始执行并显示逐台结果；离线电脑应显示等待 Agent，而不是被记为电脑已关机或操作失败。
3. 启动离线电脑并等待 Agent 连接。检查进度从等待变为执行，签名身份核对通过后自动应用当前保存的网站策略；然后在学生电脑上确认目标网站是否按预期受限。
4. 结束课堂后，在设备仍在线时确认策略恢复。另做一次离线目标尚未上线就结束课堂的情况：它上线后不应收到已取消的旧课堂策略。
5. 对可恢复设备验证键鼠锁定、解除和“一键解除所有设备管控”；确认离线的键鼠锁定不会在 Agent 后续连接时自动执行。
6. 展开逐台进度并检查预设摘要、设备名称、状态刷新；如有配对手机，也确认手机展示同一课堂的进度。
7. 可选恢复边界：结束课堂后先让已受限学生机离线，再关闭 TeacherConsole；重开教师端并观察是否需要手动重试。当前恢复队列不会跨教师端进程持久化；网站租约最多一小时后到期。
