# Windows 原子更新 G0 只读证据采集器

日期：2026-10-21（Asia/Hong_Kong）

## 本次实现

- 新增 `scripts/collect-student-update-g0-evidence.ps1`，面向 Windows PowerShell 5.1+ 管理员会话，读取 StudentSetup 角色版本、SYSTEM Agent 任务动作/ACL、恢复任务/watchdog 触发器、Agent loopback 健康状态、journal 安全字段、恢复材料存在性和目标卷剩余空间。
- 配置文件、Agent 身份密钥、健康配置指纹和命令 ID 只在本机内存处理，并以每台电脑、每个 `CaseId` 独立随机盐生成 HMAC 连续性标签。报告不包含电脑名、用户名、校区标识、配置路径、私钥、配置正文或原始命令 ID。
- 脚本不发起更新/恢复、不改任务、不重启；它只在本机创建报告与私有随机盐文件，并对 Agent loopback 健康端点发 GET。所有报告固定为 `g0Acceptance=false`。
- 在《学生端更新可靠性计划》中新增现场采集说明：同一电脑的同一案例在更新前后复用 `CaseId`，跨电脑保留各自本机盐；快照只作为人工步骤、Teacher 新鲜签名回执、CI artifact 和故障注入结果的补充。
