# 设备健康搜索与姓名显示补齐

日期：2026-10-22  
版本：TeacherConsole / StudentSetup 1.1.22  
状态：本地试用安装包已构建；桌面、手机和学生机现场验收待统一进行。

## 调整内容

- 点击设备健康异常提醒时，搜索框填入该设备的学生姓名，不再填电脑编号、Veyon 名称或网络地址。
- 设备健康列表按学生姓名、状态和诊断内容搜索；不再用电脑编号或主机名筛选。显示顺序按状态类别和学生姓名排列。
- 课堂快捷管控、设备健康、更新进度、策略结果、课堂消息、手机设备、聊天、屏幕和操作记录继续使用学生姓名映射。
- 没有唯一姓名映射时显示“未填写姓名”，不回退显示 `PC-01` 一类设备编号。座位与设备配置仍用本机电脑编号维护关联，连接和内部匹配方式不变。

## 统一现场测试

1. 点击“需要处理”里的设备异常，确认设备健康列表会聚焦到对应学生姓名。
2. 在设备健康搜索框输入学生姓名、状态和异常原因，检查过滤结果与分页。
3. 已配置姓名的设备在健康卡片、课堂推送进度、策略结果、课堂消息和手机设备/聊天/屏幕/操作记录中都应显示对应学生姓名。
4. 对姓名缺失或映射冲突的设备，确认只显示“未填写姓名”，且操作仍按内部 Veyon 目标正常匹配，不会串到另一名学生。
5. 在教师座位配置中核对电脑编号与学生姓名的本地关联仍正确；这些编号只用于配置关联，不应作为课堂设备状态标签。
