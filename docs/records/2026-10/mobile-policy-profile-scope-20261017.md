# 手机策略预设电脑范围摘要

日期：2026-10-17（Asia/Hong_Kong）

## 变更

策略预设保存窗口此前没有显示当前教师端目标列表或逐电脑账户覆盖数，教师无法在保存前快速核对预设可用于哪些电脑。

- 保存区显示应用/系统策略预设可用的电脑映射数量，最多预览五个名称，并可展开查看全部电脑名称。
- 显示学生账户选择数及覆盖电脑数；应用页启用高级手动 SID 时，说明应用预设与系统预设各自使用的账户来源和多电脑限制。
- 无 Veyon 显示名时生成“未命名电脑 N”标签，电脑范围摘要及相关教师结果不回退显示 IP。
- 手机继续只接收预设摘要，不接收 SID。

需求与操作说明见[手机控制需求](../../../specs/mobile-teacher-control/requirements.md)、[手机控制任务](../../../specs/mobile-teacher-control/tasks.md)和[手机控制使用指南](../../手机控制使用指南.md#查看和切换策略)。
