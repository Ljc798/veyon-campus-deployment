# 设备列表统一显示学生姓名

日期：2026-10-22  
版本：TeacherConsole 1.1.18（姓名显示补齐）  
状态：本地试点安装包已构建；桌面及手机现场验收待统一进行。

## 调整内容

- 设备列表、健康状态、更新进度、策略结果、课堂消息和课堂快捷管控优先按本机座位表，将 Veyon 主机地址、Veyon 名称、机房编号映射为学生姓名。
- 手机端设备名单、屏幕巡视、聊天目标和操作记录也按学生姓名显示；打印座位表显示学生姓名及座位行列，不显示 PC 编号。
- 找不到学生姓名时统一显示“未填写姓名”，不回退到 PC-01 一类电脑名称、主机名或电脑序号。
- 映射只影响教师界面显示。连接仍使用 Veyon 地址和内部设备标识；本地课堂会话仍不保存学生姓名，也不修改 Veyon 电脑名。
- 座位表中的编号编辑和自动分配规则不变，仍用于在本机维护座位与设备的关系。

## 初版用户现场测试

1. 用有学生姓名及座位关联的课堂名单，检查教师端策略名单、设备健康、学生更新进度和策略结果。已填姓名的设备应只显示学生姓名，不应出现 PC-01 一类设备名。
2. 开始课堂互动，检查求助消息、聊天目标和快捷管控的逐台进度都显示学生姓名。
3. 手机配对后查看设备名单、屏幕巡视、聊天目标和操作记录；确认名称与教师端一致。
4. 导出打印座位表，确认卡片显示学生姓名和座位行列，不显示电脑编号或 Veyon 电脑名。
5. 选择一台未录入姓名的测试设备，确认界面只显示“未填写姓名”，设备仍按原 Veyon 地址正常匹配。

## 1.1.18 补齐遗漏显示

代码巡查发现策略名单曾在学生姓名下面附带 Veyon 电脑名；课堂模式结果和手机待恢复列表也会直接显示会话保存的电脑标签。1.1.18 已移除策略名单中的电脑名副行，并将课堂模式、待恢复列表和应用影响预览改为通过本机座位表映射学生姓名。无匹配姓名时显示“未填写姓名”。手机列表已改用明确的 `studentName` 字段。

TeacherConsole 与 StudentSetup 均已重新构建为 1.1.18，安装包、大小和 SHA-256 见[统一现场验收清单](../../下一阶段统一现场验收清单.md)。TeacherConsole 0 个编译错误、2 条既有过时 API 警告；StudentSetup 0 个编译错误、1 条既有 Companion XAML runtime-loader 警告。未运行测试套件、启动或安装应用，未进行教师/学生机或手机现场验收。
