# 手机配色与独立管控状态（2026-10-23）

## 改动

- 手机统一蓝色主色，导航、按钮、品牌、回执和消息采用同一套蓝色；等待与警告仍保留琥珀色，错误仍保留红色。清除旧绿色装饰；资源版本为 v41。
- 网站和键鼠按钮分别调用原有独立通道。网站操作不读取键鼠状态，键鼠操作不以网站状态为前置条件；发送中的短暂互斥与原有身份、签名、试点门控保持。
- 新增网站状态汇总：未启用、等待上线、正在下发、已写入待浏览器核对、已确认生效、需核对、已到期、正在解除、状态未确认。键鼠另行显示状态。
- 快捷管控账本增加可选 `WebsitePhase`，不再用最后一次键鼠操作的 Phase 决定是否继续网站补发。旧记录缺省该字段时沿用原状态。
- 只有已请求启用的网站任务会在学生机上线后自动发送；未启用时仅查询状态，不自动施加新策略。失败身份校验不会绕过，来源不明的已有策略不会被接管。
- 网站补发仍以原有五秒间隔调度，受连接、并发和目标互斥影响；开机服务就绪等待期间提示可能需 1–2 分钟，不承诺固定完成时限。
- 已写入的策略持续读取签名状态及浏览器执行回执；页面不会把签名写入当作浏览器已生效。普通策略页施加的限制也可只读展示，不改变其所有权。
- 解除或结束课堂时取消尚未发送的补发任务，避免随后上线又重新施加策略。
- 快捷管控采用已保存的明确黑/白/组合模式，不因同时存在两种名单而更换模式。
