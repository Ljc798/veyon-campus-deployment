# 教师端设备标签全面改用学生姓名

日期：2026-10-22  
版本：TeacherConsole 1.1.24  
状态：本地试用安装包已构建；桌面及手机现场验收待完成。

## 调整内容

- 复查教师运行状态、设备健康、策略结果、更新进度、课堂消息、手机名单/聊天/巡视等显示路径；这些路径按本机座位与 Veyon 关联映射到学生姓名。找不到唯一映射时显示“未填写姓名”。
- 补齐换座确认计划和逐台结果：不再显示 Veyon 电脑名、地址或电脑编号，改显示换座涉及的学生姓名及状态。
- Veyon 设备选择项的文本显示改为关联到的学生姓名；关联缺失或冲突时显示“未填写姓名”。连接地址、Veyon 对象标识及电脑编号仍用于教师端本机的设备关联和核对，不作为运行状态页的设备标签。
- 这次标签映射不修改学生机 Windows 主机名；换座仍按原流程把 Veyon 显示名同步为新座位学生姓名，连接地址和对象标识保持不变。手机端继续使用教师端提供的学生姓名映射。

## 现场验收

1. 选择已有唯一学生姓名映射的教室，在设备健康、课堂快捷管控、更新进度、策略结果和手机设备/聊天/巡视页面核对标签；应显示学生姓名，不应出现 `PC-01` 一类标签。
2. 选择两个已关联学生的座位生成换座计划；确认计划行只显示学生姓名与座位行列，不显示 Veyon 电脑名或地址。
3. 执行换座后查看逐台结果，确认每项显示对应学生姓名与结果状态，不显示旧/新电脑名或连接地址。
4. 对未填写姓名或无法唯一映射的设备确认各运行页面统一显示“未填写姓名”；设备连接和座位关联仍应正常工作。
