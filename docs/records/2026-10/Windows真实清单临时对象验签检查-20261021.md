# Windows 真实清单临时对象验签检查

日期：2026-10-21（Asia/Hong_Kong）

## 实现内容

- 新增 `scripts/verify-file-update-inventories.cjs`：读取 Windows CI 刚生成的 StudentSetup、TeacherConsole 清单及对应发布目录，使用运行时生成的 RSA-3072 临时密钥，在 runner 临时目录构建两种角色的 SHA-256 内容对象包，再验证 detached signature 和全部对象。
- 复用生产发布工具的完整根目录盘点、文件大小与哈希校验、CAS 去重和签名读回逻辑。Student Agent payload 与版本化运行时仍分别扫描，并由已生成清单绑定。
- 工作流在清单生成后执行该检查。临时私钥、release 目录和对象目录位于 runner 临时目录，函数结束后递归删除；没有使用生产私钥、上传对象、发布索引或访问已安装机器。
- 保留完整离线安装器和未签名的诊断清单 artifact；临时签名只用于 CI 自检，输出始终为 `deployable: false`。
