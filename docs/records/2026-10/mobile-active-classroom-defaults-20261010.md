# 手机策略范围默认值实现记录

日期：2026-10-10

范围：减少手机控制页中电脑选择步骤，同时保留限制策略的明确范围确认。

## 用户操作

教师打开手机控制页时，系统默认使用当前活动课堂的目标电脑，并折叠完整机房列表。教师需要改动时展开“更改电脑范围”。若没有活动课堂，或课堂目标不能与 Veyon 机房清单逐台完整匹配，页面保持未选择并提示教师核对；不把未匹配电脑静默加入范围。策略预设使用列表第一项，启停策略仍由教师主动确认。

## 实现与边界

- Teacher `/api/session` 为已配对手机返回当前校区的活动课堂目标快照；下课或校区不匹配时返回空列表。
- MobileWeb 仅在目标列表无重复且全部唯一匹配机房电脑时自动选中；手动展开后更改目标会保留当前选择。
- 该默认值只减少范围选择，不自动启用或解除任何策略。范围及签名、审核、操作确认流程保持原有边界。
- 更新手机使用指南和架构摘要。
