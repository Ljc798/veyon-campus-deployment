# 手机端接口错误提示简化

日期：2026-10-17（Asia/Hong_Kong）

## 改动

- 手机通用 API 请求不再把教师电脑返回的错误正文或 HTTP 编号直接显示给教师。
- 配对码错误、配对请求失效、手机连接失效、状态变化、请求过于频繁和教师电脑暂时不可用分别使用简明提示；无法连接时说明检查网络并重试。
- 手机配对凭据被撤销的判断仍在内部完成，并保留重新配对流程；服务端原始原因不进入用户提示。
- 屏幕画面读取失败此前已统一显示普通提示，本次没有改变屏幕采集、授权或重试行为。

## 检查边界

通过源码路径复核及 `git diff --check`；未运行测试、构建或浏览器验收。手机端错误文案和状态码映射尚需在教师电脑与真实手机上核对。
