# 2026-10-11 第十二轮新增问题处理记录（0.4.70）

## 处理结果

- 学生端旧 Agent 更新：根据 image-81 中恢复旧校区策略时的 AppLocker 失败路径，修正 AppIDSvc 被禁用时清理空策略的流程：仅在清理期间临时启动服务，结束后恢复原禁用状态。若检测到仍有活动策略，不会在服务禁用的状态下继续换校区或换密钥。AppLocker 调用错误现在带有操作阶段与 HRESULT，截断错误也单独识别，方便用户提供有效诊断信息。
- 手机策略入口：手机策略页说明策略需先在教师电脑配置，再到“手机控制 → 策略预设”保存。教师端可保存当前网站策略、应用策略或系统限制；手机端无预设时显示“暂无策略预设”。
- 教师称呼：在教师端“手机控制”窗口可编辑并保存手机页显示名称，手机欢迎页显示保存值，默认使用“教师”。
- 暂离与重入：手机端“暂离”只离开控制页面并停止临时轮询/屏幕预览，保留本机配对凭据。重新打开连接页后可点击“重新进入控制页”；教师撤销授权或服务器判定凭据无效时才要求重新配对。
