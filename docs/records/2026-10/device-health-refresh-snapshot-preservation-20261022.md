## 问题与修复

截图中设备健康页自动扫描后四类状态都变成 0，并提示“校区或设备选择已变化”。定位到 `WebsitePolicyTargetChoices` 每次重建都会无条件清空健康快照；若重建发生在异步扫描期间，扫描完成时原设备行已被清掉，回执无法应用到行上，列表和计数就会显示为空。

- 现在先比较重建前后的已选设备集合。设备集合未变时保留健康行、状态和扫描节奏，并刷新学生显示名；真实选择变化仍会清除旧快照。
- 健康读取和自动轮询携带选择版本号。请求进行期间若校区或设备选择变化，即使之后又切回原选择，也会丢弃旧请求结果，避免跨选择污染。
- 因超时或未收到签名回执，设备仍应留在列表并显示未知/未收到回执；不能从页面消失或让四类统计全部归零。
- StudentSetup 1.1.29 随包 InputGuard 版本对齐到 1.1.29；Agent 仍为 0.4.55，Companion 仍为 0.4.68。

## 用户现场验收

1. 用选中 4 台的地点打开设备健康页，观察自动扫描至少 3 轮。设备列表和状态计数不能在扫描间隙消失或全部归零。
2. 让一台设备 Agent 暂停或断网，确认它保留在列表中，显示未知/未收到回执；恢复 Agent 后等下一轮，状态更新但其它设备状态不清空。
3. 读取同一地点/电脑名单两次，确认相同目标集合不会清空健康快照；再切换地点或取消选择，确认旧目标状态作废，切回后新扫描重新填充。
4. 扫描进行中切换选择后立即切回，确认旧扫描结果不会覆盖当前选择；最终列表与当前所选目标一致。
5. 同时回归学生姓名显示：健康卡片显示学生名，缺名或冲突时显示“未填写姓名”。
