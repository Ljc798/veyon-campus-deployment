# P13-06 发布载荷核对

日期：2026-10-19
代码基线：`8478c6d`（课堂私聊）、`ee1aaac`（原子学生端更新）、`5e0a7b0`（打包检查与原子安装规则对齐）
环境：macOS；.NET SDK `10.0.401`。仓库 `global.json` 固定 `10.0.100` 并设置 `rollForward: latestFeature`，因此本机 SDK 满足仓库规则。

## 构建范围

对 Windows x64、框架依赖 Release 载荷执行发布：

- `VeyonCampus.App` 的 `StudentSetup` 角色输出到 `artifacts/verification-20261019-p13-06/StudentSetup`。
- `VeyonCampus.App` 的 `TeacherConsole` 角色输出到 `artifacts/verification-20261019-p13-06/TeacherConsole`。
- `VeyonCampus.UpdateHelper` 输出到 `artifacts/verification-20261019-p13-06/UpdateHelper`，使用单文件发布参数。

所有发布均使用 `-r win-x64`、`-c Release`、`--self-contained false`、`NuGetAudit=false` 和仓库锁文件；StudentSetup 发布前还单独还原了 `EdgePolicyExecutor`。命令入口为：

```sh
dotnet restore src/VeyonCampus.EdgePolicyExecutor/VeyonCampus.EdgePolicyExecutor.csproj -r win-x64 --locked-mode -p:NuGetAudit=false -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -p:VeyonCampusIncludeInstaller=false
dotnet restore src/VeyonCampus.App/VeyonCampus.App.csproj -r win-x64 --locked-mode -p:NuGetAudit=false -p:VeyonCampusRole=StudentSetup -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -p:VeyonCampusIncludeInstaller=false
dotnet publish src/VeyonCampus.App/VeyonCampus.App.csproj -c Release -r win-x64 --self-contained false --no-restore -p:NuGetAudit=false -p:VeyonCampusRole=StudentSetup -p:VeyonCampusIncludeInstaller=false -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -o artifacts/verification-20261019-p13-06/StudentSetup
dotnet restore src/VeyonCampus.App/VeyonCampus.App.csproj -r win-x64 --locked-mode -p:NuGetAudit=false -p:VeyonCampusRole=TeacherConsole -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -p:VeyonCampusIncludeInstaller=false
dotnet publish src/VeyonCampus.App/VeyonCampus.App.csproj -c Release -r win-x64 --self-contained false --no-restore -p:NuGetAudit=false -p:VeyonCampusRole=TeacherConsole -p:VeyonCampusIncludeInstaller=false -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -o artifacts/verification-20261019-p13-06/TeacherConsole
dotnet restore tools/VeyonCampus.UpdateHelper/VeyonCampus.UpdateHelper.csproj -r win-x64 --locked-mode -p:NuGetAudit=false -p:VeyonCampusIncludeInstaller=false -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json
dotnet publish tools/VeyonCampus.UpdateHelper/VeyonCampus.UpdateHelper.csproj -c Release -r win-x64 --self-contained false --no-restore -p:PublishSingleFile=true -p:AppHostDotNetSearch=Global -p:DebugType=None -p:VeyonCampusIncludeInstaller=false -p:VeyonCampusCoreLockFile=packages.win-x64.lock.json -o artifacts/verification-20261019-p13-06/UpdateHelper
```

## 核对结果

- StudentSetup、TeacherConsole 的 `veyon-campus-role.json` 均标记为版本 `1.1.7`，角色和产品名匹配各自入口程序。
- StudentSetup 载荷包含 `WebsitePolicyAgent/VeyonCampus.Agent.exe`、Student Companion、Edge Policy Executor、Edge Native Host、Edge 扩展和提权 Worker。
- TeacherConsole 载荷包含教师入口和提权 Worker；没有 StudentSetup、Agent、Companion 或 Edge Policy Executor 产物。
- `classroom-chat.v1` 能力字串存在于 StudentSetup/Agent、TeacherConsole 载荷中的 Core 程序集；Agent 与 Teacher 共享该 Core 能力声明。
- UpdateHelper 单文件入口存在，版本对应 `0.4.40`。
- 角色元数据、必需入口文件和跨角色隔离检查通过。

## 警告和边界

- Release 发布完成。Companion 有 Avalonia `AVLN3001` 警告：沟通窗口无公开无参构造函数，Avalonia runtime loader 不能反射实例化；当前窗口由应用代码直接构造。TeacherConsole 有一条既有 `TextBox.Watermark` 过时 API 警告。
- 本机没有 PowerShell Core 或 Inno Setup，因此没有从这两个发布目录重建离线安装器 EXE。旧的 63.60/65.86 MiB 安装器早于原子更新改动，不能作为当前更新包。
- 本记录不代表 Windows 安装、覆盖更新、故障回滚、课堂聊天或非抢焦点验收通过。未运行自动测试套件。Windows 验收仍见 P13-07/08 和[学生端更新可靠性计划](../../学生端更新可靠性计划.md)。
