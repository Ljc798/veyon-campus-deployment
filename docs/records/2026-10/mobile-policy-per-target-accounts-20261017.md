# 手机应用与系统策略预设逐电脑账户映射

日期：2026-10-17（Asia/Hong_Kong）

## 变更

Windows 本地学生账户的 SID 按电脑生成。同名学生账户在不同电脑上不是同一个 SID，因此共用一个 SID 的手机应用/系统预设不能安全复用于多台电脑。

- 桌面端保存应用、网站+应用和长期系统预设时，按当前选定的每台 Veyon 目标保存对应学生账户 SID。
- 多目标手动 SID 输入被拒绝；教师需要在电脑列表中逐台读取并选择账户。
- Teacher 在签名或发送任何启用策略前验证预设覆盖全部目标；旧版扁平 SID 预设仍可读取，但只允许启用到单台电脑。
- 系统策略签名按目标使用对应 SID。解除策略不需要账户映射，因为解除文档不携带学生 SID。
- 手机 API 只返回预设摘要和逐台结果，不返回 SID。应用 Enforce 仍保留先审核、阅读影响、再次确认和签名发送流程。

需求、设计和实施任务见[应用策略规格](../../../specs/application-policy/requirements.md)、[手机系统策略规格](../../../specs/mobile-system-policy-control/requirements.md)及[手机控制规格](../../../specs/mobile-teacher-control/requirements.md)。操作步骤见[手机控制使用指南](../../手机控制使用指南.md#查看和切换策略)。
