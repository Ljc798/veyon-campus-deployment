## 非虚拟机教师自更新：具体步骤

1. 选一台允许维护的 Windows 教师测试电脑。先保存当前安装器及重要配置的恢复途径，暂停课堂操作；本轮不用改学生机。关闭所有教师窗口。本机更新服务需要 Node.js；开发机已有 Node，可直接使用，不需要 CloudBase 凭据。
2. 解压 Teacher 本机更新测试 ZIP 到普通本地目录。里面的 0.4.55 是**带本轮公钥的更新基线**；obsolete 或旧根目录的普通 0.4.55 不具备此公钥，不能替代它。
3. 安装测试目录中的 VeyonCampus-Teacher-Setup-0.4.55-win-x64.exe，同意正常管理员授权。覆盖相同版本是为了写入固定测试公钥，不更换校区签名密钥。安装结束先关闭自动启动的教师窗口。
4. 在该目录打开**管理员 PowerShell**，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Teacher-Update-Test.ps1`。该命令的执行策略仅作用于本次进程。脚本在后台启动本机更新服务，将 API 地址仅设置到启动的教师进程，并打开已安装的教师端。保留脚本窗口；不要立即按 Enter。若端口占用或 Node 不可用，脚本提示错误，不应继续安装。
5. 教师界面确认当前版本 0.4.55，进入“更新”，点击检查，应显示最新 0.4.56。关闭提示不会自动安装。点击“下载并重启”，等待验证与安装，不要手工结束更新助手或关闭脚本窗口。
6. 自动打开教师端后确认版本为 0.4.56，再点检查应显示当前已是最新版本。核对原校区、机房档案、电脑目标及密钥选择仍可用；课堂控制顶部三种策略可切换，共用目标、规则内容不丢失。
7. 结束教师窗口，在脚本控制台按 Enter，临时服务停止。随后从普通快捷方式启动，恢复默认 API；不会永久设置系统环境变量，不需要开放防火墙。本机回环测试只证明客户端更新流程，不证明 CloudBase 或学生跨电脑下载链路。
8. 先保存上述成功证据，再验证错误签名/篡改拒绝。服务启动前会拒绝与清单不一致的文件；不要修改唯一的原包，可复制测试目录后操作。真实安装中断和恢复测试尚未执行；如要人为终止安装，先确认测试机具备恢复条件，不要在正在上课的设备做此项。
