# 增量签名清单与内容对象本地工具

日期：2026-10-21（Asia/Hong_Kong）

## 实现内容

- 新增 `scripts/file-update-release.cjs`，支持从已生成的完整目标清单和固定角色文件根生成本地签名发布目录，并提供只读验证命令。
- 发布前按完整清单重新盘点所有受管根，逐文件校验相对路径、文件数、大小与 SHA-256；复制到 CAS 时再次流式计算摘要。重复内容按 SHA-256 去重，已有对象必须先通过大小和摘要校验。
- 仅接受规范 UTF-8 JSON；使用 RSA-PSS-SHA256 签署原始清单字节，并验证私钥与明确指定的公钥匹配。目标发布目录只含 `manifest.json` 和 `manifest.sig`；已存在的相同清单只有在 detached 签名仍可由指定公钥验证时才按幂等成功处理。
- 校验拒绝清单与文件不匹配、损坏对象、冲突发布目录、额外发布文件、密钥不匹配、含私钥/凭证特征的文件路径，以及通过目录别名指向输入根的输出路径。发布只在本机输出 CAS 对象与签名清单；没有 CloudBase/GitCode 上传、生产索引写入或学生端文件应用入口。命令输出始终标记 `deployable: false`。
- Windows installer CI 已接入相同 Node 检查，以便在真实 Windows runner 验证文件系统语义；本地没有访问 GitHub Actions 的 DNS/网络，因此该工作流结果尚未取得。

## 验证

- `node --test scripts/file-update-planner.test.cjs scripts/file-update-release.test.cjs`：25 项通过，0 项失败。
- 覆盖三来源只读规划、真实 RSA-3072 临时密钥签名、对象去重、签名/对象读回、重复发布、篡改对象、冲突清单、无效密钥、敏感路径和目录别名拒绝。
- 以上是本机隔离 fixture 验证；没有签署或上传生产清单，也没有实机或 Windows 更新事务验收。
