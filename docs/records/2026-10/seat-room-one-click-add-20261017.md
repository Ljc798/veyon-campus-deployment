# 座位网格地点检查与添加合并

日期：2026-10-17（Asia/Hong_Kong）

## 改动

- 新建地点流程不再要求教师分别点击“检查电脑清单”和“添加到 Veyon”。“检查并添加到 Veyon”会先运行本机目录只读冲突检查；检查无冲突后，在同一操作内调用原有写入与读回流程。
- 名称或地址冲突、检查失败、没有可新增电脑、或课堂正在进行时均停止写入，并在界面显示原因。
- Veyon 写入后的读回校验、全部电脑一次性按座位顺序关联，以及失败时不产生部分关联的保护保持不变。
- 使用指南和座位网格任务说明已同步。

完成源码路径复核及 `git diff --check`；未运行测试、构建或 Windows Veyon 实机操作。本改动仍需在 Windows 上验收按钮状态、冲突停止和实际读回。
