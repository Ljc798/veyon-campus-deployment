# 课堂设备姓名按原教室映射

日期：2026-10-22  
版本：TeacherConsole 1.1.28  
状态：本地试点安装包已构建；桌面与手机现场验收待用户统一测试。

## 调整内容

- 课堂事件和手机课堂服务按活动课堂的原教室、座位和设备映射学生姓名。无法唯一映射时显示“未填写姓名”，不回退显示 PC-01 一类编号。
- 待恢复记录按各自保存的课堂会话映射姓名；不同教室重复使用同一电脑编号时，不会拿当前选中教室的姓名替代原课堂姓名。
- 换座/聊天等课堂界面的设备姓名使用同一课堂映射；冲突的座位别名不会任意选取第一名学生。
- 不修改 Veyon 目标、学生机 Windows 主机名、电脑编号或连接方式。

## 请测试

1. 找两个教室都含有 `PC-01` 的测试机房，分别给设备设置不同学生姓名；检查教师端状态、聊天、策略、快捷管控、手机设备列表和屏幕巡视显示各自姓名。
2. 在第一间教室开始互动，再将教师端当前教室切换到第二间；活动课堂、求助和聊天仍应显示第一间教室学生姓名。
3. 结束互动并检查待恢复记录，姓名应按该记录所属的原教室显示。若身份或座位关联不唯一，只显示“未填写姓名”。
4. 检查更新进度、设备健康、策略逐台结果、手机操作记录；已映射目标只显示学生姓名，不应显示 PC 编号、Veyon 名称或网络地址。
5. 用姓名缺失或冲突的设备检查同一批界面，确认均显示“未填写姓名”，且目标操作仍连接原设备、不串到其他学生。
