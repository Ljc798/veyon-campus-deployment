## image-38 的具体原因

DESKTOP-FGVQHIA 返回了策略已写入的签名回执，但教师端未固定该电脑身份。实际浏览器限制成功与教师端尚未完成身份验证可以同时成立；之前通用提示“没有返回确认”掩盖了这一区别。本轮分开显示并提供就地核对入口，不自动信任第一次出现的密钥。

PC-02 则是电脑名解析失败，没有取得回执。修复界面不会让现场不存在或不可解析的电脑名变得可连接。先只填写实际学生机 IPv4，成功后再测电脑名；未部署或不存在的编号应从本次目标移除。

## AppLocker 原理与这次简化

Windows 在程序启动时，将运行账户和程序规则匹配：发布者规则依据数字签名、产品、文件及版本；哈希规则依据具体文件内容。普通课堂限制只阻止所列程序的后续启动，不结束已经运行的软件。软件升级后精确版本或哈希会变化，需要重新读取并生成规则。[微软规则条件说明](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/app-control-for-business/applocker/understanding-applocker-rule-condition-types)

本项目维持课堂正常程序放行，只对选定学生账户添加拒绝规则；拒绝优先于允许。学校已有管理策略可能继续限制程序，恢复本工具的课堂限制不能保证覆盖它们。[微软允许和拒绝规则说明](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/app-control-for-business/applocker/understanding-applocker-allow-and-deny-actions-on-rules)

勾选列表是读取的程序库存和本次准备应用的清单，**不是当前远端禁用状态**。恢复按钮解除全部课堂应用限制；六项长期策略中的软件安装限制须在该卡片分别解除。

## 实机复测步骤

1. 关闭旧窗口，安装 artifacts 根目录的 Teacher/Student **0.4.55**。这轮学生工具和后台 Agent 有修改，不能只升级教师。安装部署工具后，学生仍要载入原校区包并执行一次完整“配置 Veyon”流程，使运行中的 Agent 更新到 **0.4.43**；保持原校区和公钥。不需要仅为补丁更新还原学生机，也不要勾选不需要的账户改密/改名操作。
2. 学生第三步确认异常在上、警告居中、正常在下，展开详细文本核对顺序。原先五分钟内未变报告复用和第四步完整部署流程继续保留。
3. 教师目标先只填一台真实学生 IPv4。点击“核对学生电脑身份”，把完整指纹与该学生部署结果逐台对照；明确核对后固定身份。推送一个测试网站黑名单，应显示“已确认 1/1”。等待 15 秒并重启浏览器，验证阻止和解除。再加入不可解析的 PC-02 时，应明确显示另一台连接未确认，不能将已应用的真实学生机一并描述为失败。
4. 应用卡片点击“读取学生账户”，勾选实际上课的普通账户；管理员不应出现。若列表为空，确认学生账户已创建并启用、属于本地普通用户；不要为了绕过检查使用管理员 SID。若提示旧 Agent 不支持，先完成步骤 1 的学生配置，确认后台实际版本。
5. 点击“读取所选电脑软件”，搜索 QQ、微信、WPS 或浏览器，核对路径和发布者后勾选一个无害测试程序。没有可用条件或受保护的系统/维护程序不能勾选。默认选择“先检查影响”，点击“应用当前设置”；所有目标应返回可信确认。
6. 在对应学生账户登录，关闭测试程序后重新启动一次。课堂审核阶段应可启动；教师点“查看影响检查结果”，核对返回的程序、账户和版本。若启用了长期软件安装限制，返回可能是登记程序影响模拟而不是启动日志，界面会明确说明。**若已有课堂执行策略，推送审核会替换为审核模式，原课堂禁用会暂停；请在非上课测试时段调整。**
7. 选择“禁用勾选软件”，阅读影响结果并勾选执行确认，点“应用当前设置”。学生关闭该程序后重新启动，应被阻止；原已运行进程不会被结束。核对未勾选软件、管理员维护及 Agent/Veyon 仍正常。
8. 若只恢复某个软件，取消勾选它，保留其他要禁用的软件，再走检查影响/执行流程，新清单成功应用后该软件解除课堂限制。全部恢复直接点“恢复软件（解除课堂应用限制）”，无需清空账户；核对回执并在学生账户再次启动。随后另测到期自动恢复和重启行为。
9. 单台完成后再用两台**独立安装、同名学生账户**测试：分别勾选各自账户，同一软件在两台均能禁用与恢复，不能出现“本地找不到另一台的 SID”。任一台账户未选时应不能执行。改变选择后旧审核不能直接复用。
