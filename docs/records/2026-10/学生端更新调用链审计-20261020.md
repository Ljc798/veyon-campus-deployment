## 对计划第 13 节核实问题的回答

1. **发布缓存与并发**：Teacher 使用 `%LOCALAPPDATA%/VeyonCampus/Updates`，以签名 release manifest/envelope 和文件名识别可复用对象；命中时会再次完整 SHA-256 校验。一次 Teacher rollout 只下载/校验一份安装器，再由 LAN server 供多个目标读取。目标更新并发上限是 8；LAN server 连接上限是 24。没有对缓存文件设置只读属性，也没有配置化并发上限。
2. **局域网断点续传与速度**：LAN handler 只接受普通 GET 并返回整个文件，不解析 `Range`；Agent 为每条命令新建 staging 目录，断线后临时文件会清理，没有续传或已有完整 StudentSetup 安装包复用。仓库无单机/多机真实性能数据。
3. **SHA-256 与目录校验**：Teacher miss 时在外网下载流中计算一次 SHA-256；cache hit 重新完整读取并校验；Student Agent 在 LAN 下载时边写边计算完整 SHA-256；Agent stage 另行核对候选与来源树。当前不能从静态源码断言这些工作冗余，后续必须用阶段计时和 I/O 数据决定。
4. **.NET Runtime**：Student Inno 的 `InstallRuntimeInstaller` 先检查所需 shared framework，存在目标版本时立即跳过安装；缺少时才执行嵌入式离线安装器并复核。源码不支持“每次必装”的判断。当前无 Runtime 检查本身耗时数据。
5. **各步骤时长**：现有源码没有足够分段计时，无法回答旧目录保存、Inno、Agent staging、任务切换及健康检查各自耗时；这是 M0 的首要代码交付。
6. **信任与身份校验**：版本目录使用开发者固定公钥验签；Teacher 下载按签名大小和 SHA-256 校验；每设备命令由校区私钥签名并包含 developer release envelope；Agent 双重验签且重新核对本机旧版本/协议/策略能力；LAN 文件边收边验 SHA-256；Agent 健康以版本和配置指纹确认；Teacher 最后验证同一 commandId 的新鲜签名终态及已固定 Agent 身份。
7. **恢复路径**：源码具有 SYSTEM 保护 journal、全局互斥、旧 StudentSetup 同卷恢复点、Agent 版本目录、恢复任务/watchdog、helper 和联合回滚。可靠性计划明确指出 Windows 10/11 计划任务 ACL、SYSTEM、强制终止/重启故障注入及双机实测没有完成，因此只能说“源码路径已实现”，不能说“完全通过验收”。
8. **文件级更新兼容影响**：确实可能影响 StudentSetup Inno/自动卸载、角色路径、Agent SYSTEM 任务、UpdateHelper 版本隔离、校区配置与身份数据；现有 `specs/cloud-updates-and-installers/file-manifest-v1.md` 是只读清单生成/盘点协议，不是可执行的更新授权协议。应把配置/身份目录列为永久排除路径，并在签名目标清单设计和 Windows gate 通过前保持文件级更新关闭。
9. **可复用健康数据**：签名状态接口已有 Agent 与 StudentSetup 版本、更新协议版本/事务状态、网站/应用/系统策略状态、Edge 诊断。Teacher 已有逐台状态和更新结果行；尚未见统一 health snapshot、Veyon 服务健康状态、提醒聚合/确认、诊断命令及有限修复动作组成的完整健康中心。
10. **手机到 Teacher 的网络可靠性**：源码可提供局域网教师控制入口，但代码不能证明有线/Wi-Fi、跨 VLAN 或无线客户端隔离环境下的连通性。计划要求的真实网络与配对验收数据尚未提供。

## 计时实现建议与安全边界

- 用 `Stopwatch.GetTimestamp()` / `Stopwatch` 测耗时，同时保留 UTC 时间用于跨组件排序；不要用两台设备的墙钟差推导时长。
- 每个设备更新使用 `commandId`；Teacher 批次另有独立 rollout id，避免把一次外网缓存准备时间错误归到每台设备。计时事件只存阶段名、持续时间、字节数、尝试次数、结果类别和版本，不存签名正文、URL 临时 token、密钥、学生姓名或敏感路径。
- 第一批仅增加观测和结构化本机记录，不改变 journal 状态顺序、安装器参数、备份、验证、切换、提交或回滚规则。
- 汇总 P50/P95、失败率及网络/并发分组需要真实 Windows 10/11 教师—学生机记录；macOS 构建和可移植检查不能替代该证据。
- 文件级增量和二进制差分继续关闭，直到 [学生端更新可靠性计划](../../学生端更新可靠性计划.md) 的原子更新 Windows gate 完成。
