# 2026-10-11 新增问题处理与 0.4.73 构建验收

## 本轮问题

- 141. image-86：教师端读取学生账户失败。账户扫描会检查管理员、账户操作员和网络配置操作员身份，但旧脚本假设所有 Windows 都存在“账户操作员”（SID `S-1-5-32-548`）组。该组在当前 Windows 10 工作组环境中不存在；递归查询缺失组时把空成员表继续传入 `ContainsKey`，导致学生 Agent 返回“学生端查询失败”，教师界面未能选中账户，系统策略也因此无法推送。

## 修复与验证

- 账户递归判断遇到不存在的可选内置组时返回“不是该组成员”；管理员组和普通用户组仍为必需组，账户筛选仍排除可识别的管理员、操作员、域账户、禁用账户及内置账户。
- 回归检查覆盖完整组列表、缺少“账户操作员”组，以及两个可选操作员组均缺少的情况。修复前检查复现 `ContainsKey` 空键异常；修复后 Windows 本机脚本及完整回归检查通过。
- `scripts/check-app.ps1 -Configuration Release -SkipRestore`：StudentSetup/TeacherConsole Release 构建 0 警告、0 错误；自动检查 **82/82 通过**。
- StudentSetup 与 TeacherConsole 的 Windows x64 发布目录、角色元数据和 Inno Setup 安装包均成功生成并校验为 **0.4.73**；学生包内 Agent 为 **0.4.49**，Core 为 **0.4.48**。两包未签名、未嵌入 Developer Release 公钥，应用自动更新保持停用。
