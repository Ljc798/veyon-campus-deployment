- 2026-10-20 复核教师端和手机端网站限制：界面统一使用“要阻止的网站”和“允许的网站”，保留单独阻止、仅允许、允许例外三种语义；状态回读把内部模式值翻译成中文。同步精简名单为空时的显示和网站操作确认提示。

- 手机操作成功只表示电脑回执，未声称限制效果已经验证。
- 目标电脑范围、无自动到期的长期策略、预检失败的后果和真实 Windows 验收状态均未删减。
