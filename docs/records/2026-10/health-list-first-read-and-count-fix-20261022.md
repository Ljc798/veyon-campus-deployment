状态：Windows x64 离线测试安装器已构建；首次读取展示和状态计数待用户现场复验。

## 修复内容

- 自动轮询新增选中设备行后，立即刷新列表与计数，再等待 Agent 网络响应。新行明确显示“等待读取”，不再留下空列表让人误以为没有设备。
- 健康概览增加“等待读取”计数卡和状态筛选。
- 轻量签名摘要带有“键鼠状态未知”等普通信息提示时归为“需关注”；只有 Agent 无回执仍归为“未收到回执”。这让已签名响应设备不再被误计成未响应。
- 保留 1.1.30 的旧电脑名单事件解除订阅修复和用户已确认可用的聊天 Enter 发送。
