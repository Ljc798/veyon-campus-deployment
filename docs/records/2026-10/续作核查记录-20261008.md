## 壁纸实现差距

- 用户已选择统一使用“蓝色背景、Windows 徽标位于画面中间偏右”的桌面图。
- 当前 `WindowsDefaultWallpaper.Resolve()` 将 `%WINDIR%\\Web\\Wallpaper\\Windows\\img0.jpg` 作为来源，验证文件不是重解析点、JPEG 结构完整、RGB 且不小于 1280×720；它没有比较内容指纹，也没有识别主色或徽标位置。可移植测试仅覆盖这些结构边界。因此，一个结构正确但显示其他图片的 `img0.jpg` 目前会通过。
- Microsoft Windows Experience Blog 把 Windows 11 首次显示的默认桌面图称为 Bloom；当前“各机使用各自 `img0.jpg`”不能保证 Windows 10/11 使用相同徽标图。[Windows 11 Bloom](https://blogs.windows.com/windowsexperience/2021/10/06/windows-11-blossoms-with-bloom-a-new-symbol-for-a-new-operating-system/)
- Microsoft Learn 的 Windows IoT 壁纸包清单列出 Windows 11 IoT Enterprise LTSC 2024 和 Windows 10 IoT Enterprise LTSC 2021 都使用 `%windir%\\web\\wallpaper\\windows\\img0.jpg` 路径，但该清单不证明两个文件内容相同或符合用户所选徽标图。[Desktop Wallpaper package](https://learn.microsoft.com/en-us/windows/iot/iot-enterprise/optimize/removable-packages/microsoft-windows-shell-wallpaper-common)
- 结论：统一图片来源、再分发/校内使用边界及可信内容识别是非实机实现门槛；实际目标 Windows 版次与桌面效果仍是另外的实机门槛。项目任务主表新增 P14，专项规格新增壁纸实现任务 10，并将设备验收顺延为 task 11。未修改 Windows 运行时代码，也未把壁纸标成完成。

## 壁纸资源传递设计

- Microsoft 桌面背景策略支持本机图片路径；系统默认路径 `img0.jpg` 不能提供跨 Windows 10/11 的同一内容证明，Windows 11 默认图为 Bloom。显示比例也会裁切图片，偏右徽标需要按目标比例留安全区。[桌面背景策略](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-desktop)、[配置与裁切](https://learn.microsoft.com/en-us/windows/configuration/background/)、[Windows 11 Bloom](https://blogs.windows.com/windowsexperience/2021/10/06/windows-11-blossoms-with-bloom-a-new-symbol-for-a-new-operating-system/)
- 架构建议：由负责人提供有公开发行权的统一图片，作为 Student Agent 发布资源；Agent 对照代码内受信任 SHA-256 验证后，复制到 `%ProgramData%\\VeyonCampus\\SystemPolicy\\Assets\\<sha256>.jpg`，以安全 ACL 保护并将策略指向该稳定路径。系统策略状态记录摘要及引用；更新和回滚保留仍有活动引用的资源，撤销后只清除摘要匹配且无活动引用的文件。此方式不需要扩展 CloudBase 配置包 schema。
- 当前安装/更新复制器的扩展名白名单不接受 `.jpg`，策略状态也未跟踪图片资产引用；因此该建议仍是待实现设计。Student Agent 发布包中的资产需同时通过 installer bundle 与 release 的完整性校验。
- Microsoft 官方 Windows Insider 专用壁纸包明确限个人使用并禁止再分发、修改和商业使用；这条限制只涉及该特定下载包，不能直接推断 Windows 系统内置壁纸的授权范围。[Windows Insider wallpaper terms](https://blogs.windows.com/windows-insider/2014/11/07/a-little-something-for-windows-insiders/)
- 本轮已将学生系统策略专项规格的壁纸实现任务排在物理验收前，并将现场矩阵顺延至下一任务；仍未修改运行时代码或选择任何壁纸素材。
