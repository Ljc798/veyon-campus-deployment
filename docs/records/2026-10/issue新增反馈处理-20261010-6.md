# 2026-10-10 新增测试问题处理记录（0.4.67）

本轮逐项处理 `artifacts/assets/issue.md` 中的 image-72、Agent 残留/密钥更新、image-73、手机配对立即过期和 image-74 按钮颜色反馈；对应条目为 117–121。

## 修复

- 网站策略停止确认窗的“返回”按钮现在明确关闭对话框并返回未确认结果。文案收敛到一条操作说明和一条管理员权限提示。
- Agent 任务身份按精确的 VeyonCampus 受管根目录及版本路径核验，不依赖旧 EXE 仍存在。手动删掉 Agent 文件后，仍可识别旧任务并修复/清理；同版本目录缺文件或内容不匹配时先检查归属、停止指向该目录的 Agent，再用已校验暂存副本替换并保留失败回滚路径。
- 同校区签名公钥变化时，安装器先运行旧 Agent 安全卸载流程，恢复本工具拥有的网站、应用和系统策略后才部署新密钥。无法确认策略所有权或旧策略恢复失败时会终止换钥。配置元数据更新支持原子替换，但不允许借此静默替换信任公钥。
- 手机配对截止状态现在以教师服务器的轮询结果为准，不用手机系统时间本地倒计时。API 拒绝请求时间时返回服务器 UTC 时间，网页校准偏移后重试一次，缓解手机与教师机时间不一致造成的误判。
- 教师手机批准使用蓝色确认、取消使用灰色；拒绝/撤销/删除使用红色确认。学生端停止策略及其他确认窗也区分取消、普通确认和破坏性确认。
- 教师端待配对时间不显示“UTC+8”标签；手机策略安装状态和维护页面删减了面向开发者的解释文字。
