## 原始 goal

> 首先给网站的管理员界面加上一个一键更新下载地址和版本号，更新的是网站下载页面的下载地址，自动获取 GitHub 和 GitCode 最新的版本。之后重新优化一下一键添加地点和配置。因为大家都是一个平面的校区，所以我想直接来一个 25×25 或者更大的格子因为要预留过道，然后让老师自定义地选择哪个格子有座位，一旦点击之后就可以输入这个座位的人的名字。编号的话就从左到右从上到下根据用户选择的座位依次编号。这样还可以删掉常用校区和地点，这一个就取代了，非常方便。常用校区和地点后期有需求再加上。做好这个之后我们还要支持换座位模式，进入这个模式之后，可以任意交换两个人的座位，然后只更换 Veyon 座位的名称不更换 IP 地址。然后想尽一切办法，在手机端支持之前给每个学生预留的屏幕，把 Veyon 监视到的学生机屏幕转移过来，然后可以调整画质，刷新时间，等等的。最后，因为手机端也是给不懂计算机的人使用的，所以你还是要做减法，一切都做减法，给大家能看懂的文字来展示。这些都完成的话那就继续往后深入开发应用锁定策略和系统策略层面。
