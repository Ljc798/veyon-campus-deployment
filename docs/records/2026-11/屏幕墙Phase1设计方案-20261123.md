> 依据：`artifacts/next.md`（学生屏幕墙设计语言与实施规范）+ 2026-11-23 单设备 WebAPI 可行性实测。

## 一、范围与边界

**做**：课堂控制页右栏**默认**为「屏幕墙」视图，用**真实** WebAPI 画面显示 5–10 台学生机缩略图；每张卡片带「键鼠锁定」与「网站策略」两个课堂功能；点击进入独立窗口看大画面。

**不做**：远程键鼠、更高帧率传输优化、独立监控窗口、云中转、批量操作扩展、70 台并发承诺。

**硬约束**：

- 画面必须来自真实设备；拿不到就显示明确状态，禁止占位假图/假数据。
- 不改变 Veyon 密钥权限模型，不改现有课堂管控/网站策略/更新链路。
- 列表视图保持现状，屏幕墙是并列视图，不是替换。

## 三、总体架构

```
课堂会话（TeacherViewModel）
   │  targets: TargetId / HostAddress / Seat / StudentName
   ▼
ScreenWallViewModel ──► ScreenWallRefreshScheduler ──► ScreenWallConnection（每设备一条）
   │  tiles（按座位排序）        │ 并发闸门 + 分级节奏            │ 认证一次，取帧 N 次
   │                            ▼                              ▼
   │                     StudentScreenTileViewModel      VeyonWebApiClient
   ▼                            │ 状态/位图/画面年龄            │ HTTP 127.0.0.1:11080
ScreenWallView（卡片网格） ◄─────┘                              ▼
   │ 点击                                           veyon-service（本机 WebAPI）
   ▼                                                        │ VNC
StudentScreenDetailWindow（大画面，5–8 fps）                 ▼
                                                        学生机 Veyon Server
```

关键取舍：

- **一条连接一台设备**，认证一次、取帧多次（实测认证 257–2049 ms，取帧 2–6 ms）。
- **取帧与解码都不在 UI 线程**；解码后只把 `Bitmap` 交给 UI 层做一次赋值。
- **调度器统一限流**，不让 70 个定时器同时打服务端。

## 五、连接与刷新状态机

```
            ┌──────────── WebAPI 未启用 / 缺私钥 ────────────┐
            ▼                                               │
  未就绪 ──► 连接中 ──► 等待首帧 ──► 实时 ──► 画面过期(>6s)
            │            │              │            │
            │            └─ 10s 超时 ──►│            └─ 自动重取
            ▼                           ▼
       认证失败(401/400)            连接断开(401 code2)
            │                           │
            └──────── 退避重连 ◄─────────┘
                        │
                设备不可达(408, 15s) ──► 离线
```

规则：

- **状态必须来自真实信号**：`实时` 只在成功取帧后成立；`离线` 只由传输层失败（408/连接被拒）判定，不能因为「最后一张图旧」就判离线。
- **503 必须看 `error.code`**：9=格式错误（不重试，报配置错），10=首帧未就绪（重试）。
- 401/code2（连接过期）→ 立即重认证一次；再次失败进入退避（2/4/8/16 s，上限 60 s）。
- 不可见（切页/最小化）→ 暂停取帧但保留连接；超过 45 s 无请求主动关连接，回来再认证，避免撞 60 s 空闲过期。
- 连接寿命 3 h：到 3 h 前主动重认证，不依赖报错。

## 六、刷新节奏与资源预算

| 场景 | 尺寸/格式 | 节奏 | 依据 |
| --- | --- | --- | --- |
| 屏幕墙默认 | 320×180 JPEG q60 | 1.5 fps/台 | 3.8 KB、约 5 ms/帧（实测） |
| 屏幕墙「大」档 | 480×270 JPEG q70 | 1.5 fps/台 | 仍低于 12 ms |
| 选中卡片 | 640×360 JPEG q75 | 5 fps | 14.2 KB、6 ms |
| 详情窗口 | 960×540 JPEG q80 | 8 fps | 25.8 KB、6 ms |
| 全局并发 | — | 4 路并行 | 单设备 201 fps 上限的保守切片 |

- 解码成本 3.6 ms/帧（960×540）；320×180 约 0.5 ms。按 10 台×1.5 fps 估算，UI 线程外解码总开销 < 20 ms/s。
- 位图内存：320×180 RGBA ≈ 230 KB/台，70 台 ≈ 16 MB；详情只保留 1 张 960×540（≈2 MB）。
- 带宽：10 台×1.5 fps×3.8 KB ≈ 57 KB/s；30 台同档 ≈ 171 KB/s。真正的成本在学生端 VNC 画面变化，不在缩略图。

## 七、WebAPI 调用契约（实测确认）

```http
GET  /api/v1/authentication/{host}
→ 200 {"methods":["0c69b301-81b4-42d6-8fae-128cdd113314"]}

POST /api/v1/authentication/{host}
{"method":"0c69b301-…","credentials":{"keyname":"<密钥目录名>","keydata":"<私钥 PEM>"}}
→ 200 {"connection-uid":"<uuid>","validUntil":<epoch>}

GET  /api/v1/framebuffer?width=320&height=180&format=jpg&compression=5&quality=60
Header: Connection-Uid: <uuid>
→ 200 <二进制图像>

DELETE /api/v1/authentication/{host}   Header: Connection-Uid
→ 200
```

错误映射：

| HTTP | code | 含义 | 处理 |
| --- | --- | --- | --- |
| 400 | 4 | 凭据不完整/PEM 无效 | 认证失败，不重试，提示检查私钥 |
| 401 | 2 | 连接无效/已过期 | 重认证 1 次 |
| 401 | 6 | 认证失败（密钥不匹配） | 认证失败，不重试 |
| 408 | 8 | 连接超时（约 15 s） | 离线，退避重试 |
| 503 | 9 | 图像格式不支持 | 配置错误，停该设备取帧 |
| 503 | 10 | 首帧未就绪 | 250 ms 后重试，上限 10 s |
| 429 | 7 | 连接数超限 | 全局降速/排队，提示容量上限 |

## 八、界面设计

### 8.1 布局

- **默认视图是屏幕墙**：进入课堂页即显示画面网格；右栏顶部保留 `屏幕墙 | 列表` 分段开关，列表一键可回，切换不重建连接。
- 工具栏当前只保留课堂摘要（`10 台 · 8 实时 · 1 画面过期`）。搜索/筛选/尺寸档留到 Phase 2，避免首版塞入无效控件。
- 网格区独立滚动，工具栏与课堂信息栏固定。
- 列数断点：<700 px→2；700–950→3；950–1200→4；1200–1500→5；>1500→6。卡片宽度目标 200–260 px。

### 8.2 卡片（四层）

1. **顶部**：`张三 · PC-01`（13 px SemiBold，超长省略 + Tooltip）；右侧状态点 + 文字（在线/连接中/已锁定/画面过期/离线/认证失败）。
2. **两个课堂功能（每张卡片都有）**：`锁定键鼠 / 解除键鼠` 与 `网站策略 / 恢复网站`，另加画面右上角「放大」。
   - 键鼠：走现有单设备租约（`LockDeviceInput` / `UnlockDeviceInput`），有确认框、截止时间与 20 秒断线宽限。
   - 网站：走 `EnableWebsiteRestriction` / `ClearWebsiteRestrictions` + `selectedTargetIds:[该设备]`，并传 `preserveControlExpiry:true`，**不改动全班倒计时**。
   - 发消息/更多不进 Phase 1，避免出现不可用按钮。
3. **画面**：固定 16:9 容器，`Stretch=Uniform`，不裁切不拉伸；连接中显示轻量加载，失败显示明确原因，过期时叠「画面已过期 · 12 s 前」角标。
4. **底部**：`#03 · 画面 2 s 前 · 连接正常 · 已锁定`，11 px 次要色，高度 ≤ 24 px。

### 8.3 色彩映射（沿用品牌，不新造体系）

| 语义 | 取值 | 现有资源 |
| --- | --- | --- |
| 主背景 | `#EDF5F8` | 新增 `ScreenWall.Background` |
| 卡片 | `#FFFFFF` | `Teacher.Color.Surface` |
| 边框 | `#DFE8ED` | `Teacher.Color.Border` |
| 主文字/次文字 | `#20313D` / `#738590` | 现有正文/muted |
| 强调（选中） | `#168B83` | `Teacher.Color.Primary` |
| 在线 / 受限 / 失败 | `#24A66A` / `#E3A12D` / `#E15858` | Success / Warning / Danger |
| 卡片工具区 | `#F7FAFC` | `Teacher.Color.SurfaceSubtle` |

阴影只保留 1 px 边框 + 极轻投影；不做深色大卡片。

### 8.4 交互

- 单击卡片 = 选中（批量对象，与现有 `IsSelectedForInputLock` 语义分开，用独立 `IsWallSelected`）。
- 双击或点「放大」= 进入详情；`Esc` / 「返回屏幕墙」退出，连接不重建。
- 切换列表/屏幕墙不销毁连接，只改节奏与可见性。
- 卡片位置在取帧完成顺序不同的情况下保持稳定（集合只按座位排序，图片属性单独更新）。

## 九、安全设计

1. **只听回环**：客户端固定 `127.0.0.1:11080`；不接受可配置远端地址。部署脚本启用 WebAPI 时同步加防火墙规则，仅允许本机访问 11080（`netsh advfirewall firewall add rule ... remoteip=127.0.0.1`）。
2. **密钥零暴露**：私钥只在 `VeyonKeyMaterial` 内读一次，`ToString()` 遮蔽；异常信息不含 PEM；不写入任何日志/审计/崩溃转储字段。
3. **最小权限**：屏幕墙只读画面 + 复用既有命令入口；不新增任何管控通道。
4. **连接生命周期**：页面退出、课堂结束、应用关闭、切换教室都必须 `DELETE` 释放；进程退出前兜底关闭。
5. **失败可见**：连接/认证/取帧失败显示原因，不静默降级为「离线」。
6. **前置检查**：启动时探测 11080 与私钥；不可用则屏幕墙入口置灰并给出可执行提示（如何在部署中启用 WebAPI），不自动改系统配置。

## 十、前置条件（P0，必须先做）

1. **部署启用 WebAPI**：`veyon-cli config set WebAPI/HttpServerEnabled true` + 重启 `VeyonService`；安装包/部署脚本补充该步骤并写防火墙规则。
2. **确认密钥可读**：教师端进程能读 `C:\ProgramData\Veyon\keys\private\<name>\key`（当前实测可读）。
3. **容量确认**：`ConnectionLimit=32` 只够 30 台；>32 台需调大并实测（Phase 3）。

## 十二、验收标准（对齐 next.md 第 10 节）

- 画面为真实学生屏幕；断开学生机后卡片在 20 s 内转为「离线」，不残留旧图冒充在线。
- 10 台并发 1.5 fps：UI 输入无阻塞（拖窗、切页流畅），内存 30 min 内无持续增长。
- 单台离线/认证失败不影响其他卡片刷新。
- 离开课堂页或结束课堂后，`Connection-Uid` 全部释放（服务端连接数归零）。
- 列表与屏幕墙共享同一份设备状态与选中语义，切换不丢状态。

## 十三、风险与待决策

| 风险 | 影响 | 建议 |
| --- | --- | --- |
| WebAPI 监听 `0.0.0.0` + 无 TLS | 私钥可被同网段嗅探 | 防火墙仅回环；后续评估 HTTPS |
| `ConnectionLimit=32` | 40+ 台不可用 | Phase 3 调参并实测，不提前承诺 |
| 首帧 0.24–3.3 s 波动 | 首次进入画面慢 | 占位 + 10 s 超时 + 并行预热 |
| 离线单次阻塞 15 s | 批量并发被拖慢 | 认证阶段独立限流，离线快速跳过 |
| 学生端 VNC 负载 | 70 台同时连接可能压垮学生机 | Phase 3 用 30/50/70 台实测，必要时降低取帧或分片轮询 |
| 私钥读取权限 | 部分部署读不到 | 启动探测 + 明确提示，不回退到假画面 |

**已决策（2026-11-23）**：① 屏幕墙是课堂页**默认视图**；② 每张卡片直接放「键鼠锁定」与「网站策略」两个功能；③ 详情用**独立窗口**（复用同一条连接，打开期间该设备升到 8 fps，关闭回落 1.4 fps）。
