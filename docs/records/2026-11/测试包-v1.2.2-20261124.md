## 本轮修复

1. **时钟差导致课堂助手「本机回执时间无效」**：`ClassroomStatusAgentState` 不再把教师端绝对截止时间和本机接收时间相减，改为用「剩余有效期 = 截止 − 签发」锚定本机时钟。
2. **时钟差导致键鼠锁定后无法解除**：`StudentInputGuardTransport` 用签名状态测出两端时钟差，命令与回执的时间校验按差值换算；状态窗口放宽到 12 小时（nonce 已防重放），提示里直接写出相差秒数。
3. **改名后 Agent 被判 `untrusted agent`**：`StudentAgentIdentityTrustStore.FindTrustedPins` 允许同一指纹对应多个座位名，Agent 通道与维护通道把所有名称都注册到同一连接，不再要求「指纹唯一」。
4. 1.2.1 已包含的屏幕墙与课堂视图 UI 修正、本机 WebAPI 启用入口、`--enable-local-webapi` CLI、卸载清理回归修复。

## 建议验收顺序

1. 教师机装 1.2.2，学生机装 1.2.2（覆盖安装即可，学生配置包范围 1.0.0–2.0.0 兼容）。
2. 把一台学生机系统时间故意调慢 3 分钟，观察课堂助手是否仍显示正常课堂状态（不应出现「回执时间无效」）。
3. 在时间偏慢的那台机器上锁定键鼠，再从教师端解除，确认能立刻解除且状态回读为已解除。
4. 修改某台设备的座位名称后重新推送，确认不再出现「认证失败 / 不信任的 Agent」。
5. 若仍有设备被锁死，用 `scripts/release-input-lock.ps1`（先 `-DryRun`）在现场解锁。
