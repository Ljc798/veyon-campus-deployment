## 流水线

`Windows installers`（run 45301455852，tag `v1.2.0`）：build-installers、sign-release-installers、publish-release 全部 success。

首轮与次轮失败于 `Verify repeated Windows Agent deployment and recovery`，两次均为同一根因，已修复后重出：

1. 首轮失败信息只有一句汇总文案，无法定位。先给 `WebsitePolicyRuntime.VerifyAbsent` 加分项输出（`b…`），重跑后得到"具体残留：Agent 注册表状态"。
2. 根因一：`RemoveOwnedState` 清空注册表值但不删键，`HasAgentState()` 只看键是否存在。已在清空后调用 `RemoveEmptyAgentState()`。
3. 根因二：`BlockedAddressRoute.RemoveAll()` 用 `CreateSubKey` 打开状态键，卸载清理阶段反而把刚删掉的键重建。改为 `OpenSubKey`（不创建），并在卸载收尾、所有清理完成后再次确认注册表为空。

## CloudBase 注册

首轮发布时该步骤 404：`External installer is unavailable (HTTP 404)`——因为 GitCode 附件尚未上传。按既定顺序（GitHub → GitCode → CloudBase）在本机上传 GitCode 后，用 `register-cloudbase-release` 工作流补注册成功。

## 版本决策

- `VeyonCampus.App.csproj` 版本从 `1.1.100` 直接提到 `1.2.0`。1.1.90–1.1.118 都是以 `-TestVersionOverride` 打出的本地测试包，源码版本从未推进。
- 学生配置包兼容区间按产品主版本计算（`1.0.0`–`2.0.0`），1.2.0 不会让现有 1.1.x 学生机被判为不兼容。
- 学生端 1.2.0 内置 Agent `0.4.68`；教师端与学生端应一起升级。

## 未覆盖项

- 本机 `VeyonCampus.Checks` 无法完整运行：`sc.exe` 被本机安全策略列入黑名单，`Veyon 探测状态非法：unknown` 属环境限制，CI 上通过。
- 1.2.0 的真实设备验收（屏幕墙画面、键鼠锁定保持、网站策略落库）仍需在教学机上复核。
