## 本轮变更

### 课堂管控

1. **单台设备可选时间**：桌面端给单台设备推送网站策略或锁定键鼠前，先弹「截止时间（HH:mm）」对话框，含 15/30/45/60/90/120 分钟快捷键与合法性校验；单台截止时间不再复用全班截止时间，全班 `ControlExpiresUtc` 不被改动。单台截止到期后不再补发策略，直接清除该设备的网站控制。
2. **手机端单台管控**：手机课堂页每行设备与巡视卡片新增「单台管控 · 选时长」，可选 10–120 分钟或自定义，四个动作（网站策略、锁定键鼠、解除、查看）都能只作用于这一台；服务端校验目标属于当前课堂、时长 1–720 分钟并按时区午夜裁剪。
3. **去掉指纹核对**：删除教师端「核对并固定身份」按钮与核对码对话框，身份变化改为自动信任（`approveChangedKeys: true`）；Agent 通道握手在无匹配固定项时用 Hello 公钥验签本机 nonce 后自动 `Pin(replaceChangedKey: true)`。界面文案同步改为「将自动信任」，不再引导用户去点已删除的按钮。
4. **手机端实时画面**：手机取帧改为与桌面屏幕墙同源——教师机本机 Veyon WebAPI 认证后取 framebuffer 并复用缓存连接，WebAPI 不可用时才回退 `veyon-cli feature Screenshot`；失败时把「认证被拒绝／主机不可达」等真实原因回给手机，不再只是超时。

### 1.2.2 已包含、本包继续保留

5. **时钟差修复**：课堂助手「本机回执时间无效」、锁键鼠后无法解除，根因都是跨机器比较绝对时间。改为用「剩余有效期 = 截止 − 签发」锚定本机时钟，并用签名状态测出两端时钟差换算命令与回执时间；提示直接写出相差秒数。
6. **改名后 Agent 被判 untrusted**：同一指纹允许对应多个座位名，Agent 通道与维护通道把所有匹配名称注册到同一连接。

### 防断网逃课（学生端）

7. **网络开关加固**：Agent 启动时写入 `HKLM\...\Policies\Explorer\SettingsPageVisibility=hide:network`、`HKLM\...\Network Connections` 的 `NC_LanConnect=1`、`NC_LanChangeProperties=1`，普通账号无法从设置页或网络连接界面关网卡；管理员仍可通过注册表或服务手段恢复，方便换 Wi-Fi 口令。
8. **断网锁键鼠**：连续 60 秒无「可用网络」（有 Up 网卡 + 非 APIPA 地址 + 默认网关，不看教师机是否可达）且当前有生效课堂策略时，Agent 经本机 IPC 锁键鼠并每 5 秒续租；网络恢复 5 秒内自动解除，最长 45 分钟硬上限，只解除自己签发的租约，教师端下的锁不接管。
9. **离线游戏压制**：任何非 Disabled 策略都会同时关闭扫雷、纸牌、空当接龙、麻将、植物大战僵尸、街机模拟器等离线单机游戏进程。
10. **卸载恢复**：学生端卸载时新增「解除网络开关加固」，只在值仍等于本产品写入值时才删除，管理员改过的值不动。

## 建议验收顺序

1. 教师机与学生机都覆盖安装 1.2.3（学生配置包范围 1.0.0–2.0.0 兼容，可直接覆盖）。
2. 教师端选中单台设备 → 推送网站策略，选一个 15 分钟后的截止时间，确认到点自动解除且其他设备不受影响。
3. 手机扫码进入课堂页 → 对单台设备点「单台管控 · 选时长」，分别试网站策略与锁定键鼠。
4. 修改某台设备的座位名称后重新推送，确认不再出现「认证失败 / 不信任的 Agent」。
5. 手机看某台设备的实时画面，确认能出图；若失败，确认错误信息写的是认证或连通性原因而不是超时。
6. 学生机断网 90 秒：确认键鼠被锁、提示断网；恢复网络后 5 秒内自动解锁。
7. 学生端卸载：确认「网络和 Internet」设置页恢复、网卡可以启用/禁用。

## CI 首次失败与修复

`v1.2.3` 第一次推送（提交 `62e6bc1`）时 `Windows installers` 在「Verify repeated Windows Agent deployment and recovery」失败：
安装、重装、回滚、换签、换校区全部 PASS，最后清理卸载报「Agent 私有状态文件 ACL 无效；拒绝删除」。
原因是配置文件目录里 `agent-<hash>.json.teacher-channel-status.json` / `health-repair-ledger.json` 这类产品自有状态文件由继承 ACL 创建，未显式收紧到 SYSTEM + Administrators。

提交 `db39e17` 改为：文件名已证明归属时先收紧 ACL 再复查，只有收紧后仍不合规才拒绝卸载；错误信息里带上具体文件路径。随后删除并重建 `v1.2.3` 标签重跑（此时尚未生成 GitHub Release，重建标签安全）。
