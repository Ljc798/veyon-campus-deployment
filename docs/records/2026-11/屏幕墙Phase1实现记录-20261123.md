## 一、当天确认的三项决策

| 决策 | 落地方式 |
| --- | --- |
| 屏幕墙是课堂页**默认视图** | `TeacherViewModel.IsClassroomScreenWallMode` 默认 `true`；右栏顶部 `屏幕墙 / 列表` 分段开关，列表一键可回 |
| 每张卡片放**键鼠锁定 + 网站策略** | 卡片第四行两个按钮，分别走既有单设备租约与 `EnableWebsiteRestriction/ClearWebsiteRestrictions + selectedTargetIds:[该设备]` |

## 二、新增代码

| 文件 | 职责 |
| --- | --- |
| `ScreenWall/VeyonWebApiClient.cs` | 仅 `127.0.0.1:11080`；认证（嵌套 `credentials`）、取帧、释放；`VeyonWebApiException` 带 `code`，区分 503/9 与 503/10 |
| `ScreenWall/VeyonKeyMaterial.cs` | 只读 `%ProgramData%\Veyon\keys\private\*\key`，按目录名排序；PEM 不进日志/异常文本 |
| `ScreenWall/ScreenWallConnection.cs` | 单设备会话：认证一次取帧多次；首帧 10 s 重试窗、401/2 重认证一次、408 冷却 20 s、密钥被拒冷却 60 s、150 min 主动换会话 |
| `ScreenWall/ClassroomScreenWallService.cs` | 120 ms 调度心跳、全局并发 4、可见时 700 ms/台、聚焦时 130 ms/台；每 5 s 探测 WebAPI；设备离场即 `DELETE` |
| `ScreenWall/ClassroomScreenTileViewModel.cs` | 卡片状态（实时/连接中/等待首帧/画面过期/离线/认证失败/WebAPI 未启用/格式不支持）+ 位图替换时释放旧图 |
| `ScreenWall/ClassroomScreenWallViewModel.cs` | 按座位排序、指纹去重、摘要统计、1 s 画面年龄刷新 |
| `ScreenWall/ClassroomScreenTarget.cs` | 课堂目标投影（TargetId / HostAddress / Seat / 学生名 / 电脑名） |
| `Presentation/Views/TeacherScreenWallView.axaml(.cs)` | 卡片网格（WrapPanel 按宽度 210 px 断点 2–6 列）、WebAPI 未就绪横幅、空态 |
| `Presentation/Views/TeacherScreenDetailWindow.axaml(.cs)` | 独立窗口：画面 + 两个管控按钮 + 画面年龄；`Esc` 关闭 |
| `scripts/enable-teacher-webapi.ps1` | 启用 WebAPI、重启服务、添加**仅 127.0.0.1** 的入站规则；`-Disable` 可回滚 |

## 三、部署前置（本机已执行）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\enable-teacher-webapi.ps1
```

执行结果：`WebAPI/HttpServerEnabled=true`、端口 11080 监听、入站规则 `VeyonCampus Teacher WebAPI (loopback only)` 仅允许 `127.0.0.1`。
注意：WebAPI 仍绑定 `0.0.0.0`、无 TLS，**防火墙规则是唯一屏障**；撤销用 `-Disable`。

## 五、未验证项（必须补）

1. **界面视觉**：本机教师端正由用户进程占用（单实例互斥），未重启验证；卡片布局、分段开关、详情窗口需人工看一眼。
2. **调度器端到端**：`ClassroomScreenWallService` 的并发/节奏/聚焦切换只经编译校验，未在真实课堂跑 10 分钟。
3. **多设备**：仅 PC-01 单台；`ConnectionLimit=32` 与 70 台分片策略仍属 Phase 3。
4. **单设备网站策略**：走的是既有 `ExecuteAsync(selectedTargetIds:[id], preserveControlExpiry:true)`，逻辑路径已存在，但未在本轮实测落库结果。

## 六、已知限制

- WebAPI 未启用时卡片只显示「WebAPI 未启用」，不降级到 CLI（CLI 每次 1.2 s 且落盘，会拖垮 10 台以上的墙）。
- 离线设备在**认证阶段**仍会占一个并发槽最多 15 s；离线台数多时首轮标记会变慢，Phase 2 再拆认证队列。
- 画面年龄超过 6 s 自动转「画面过期」，但连接本身仍保留；恢复后同一条会话继续取帧。
- 详情窗口升频只作用于被打开的那一台，其余保持 1.4 fps。
