更新时间：2026-09-27。逐项任务状态以[开发路线与任务清单](开发路线与任务清单.md)为准。

## 当前结论

当前源码版本为 **0.4.6 Windows 本地离线部署实验版**。教师和学生角色 App 均构建通过（0 警告／0 错误），Windows x64 自包含交叉发布并检查过角色产物：学生包含 `VeyonCampus.StudentSetup.exe` 与后台 Agent，教师包含 `VeyonCampus.Teacher.exe` 且不含学生入口或 Agent；对方窗口类型未编入各自 App 程序集。主检查 31 项和专项 fixture 4 项通过。路线清单仍按严格验收条件统计；代码切片和交叉发布不代替 Windows 实机证据。

本轮完成的本地工作：

- 网站策略后台运行代码拆为独立 `VeyonCampus.Agent.exe`。它是 Windows GUI 子系统程序，不含 Avalonia UI；安装位置为 Program Files，由 SYSTEM 开机计划任务启动。
- 任务注册时设置受保护 ACL，只允许 SYSTEM 与本机 Administrators 完全访问；部署后只读验证会检查计划任务身份、命令、代理健康响应和任务 ACL。
- 部署完成后可先做只读读回；必要组件全部确认后才能退出并清理。清理只移除发布清单列出的 GUI 部署文件，保留未列出文件、Veyon 和独立 Agent。
- 教师可给选定设备推送 Edge/Chrome 黑名单、白名单或停用策略；策略默认 60 分钟到期，可选 45/60/90/120 分钟或不自动到期。教师也可一键解除所选设备限制。
- 策略带签名时限，最长 24 小时。Agent 启动时和每 30 秒检查过期策略，仅清除本工具仍拥有且未被外部改写的值；固定事件日志有 64 KB 上限。
- 教师端本机保存最近 50 次推送的逐台状态，不保存域名清单或签名内容；失败设备可以填回目标框供教师复核后重推，不会自动重试。
- 教师控制台与学生部署工具已分成独立窗口、ViewModel 和程序集；教师构建排除学生窗口及 Agent，学生构建排除教师窗口和教师操作 ViewModel。Windows 打包脚本支持 `StudentSetup`／`TeacherConsole` 两个角色，学生清理逻辑识别新 exe 名并拒绝教师包清单。
- UI 样式统一并设计了新图标，已接入 Avalonia 资源、窗口标题栏及 Windows 应用图标构建项。

以上代码未在真实 Windows 学生机执行。当前主机为 macOS；本轮没有运行 PowerShell Windows ZIP 脚本、打开 Windows GUI、注册 SYSTEM 计划任务、操作 HKLM、启动真实浏览器或连接另一台 Windows 电脑。因而两角色 ZIP 和窗口验收、标准学生用户无法暂停 Agent、清理后双击无页面、黑白名单实际生效以及到期／断网／重启恢复都保持“待测”。

## 当前最高优先级

先运行[Windows 学生端后台代理与网站限制自测验收单](Windows学生端黑白名单与后台代理自测验收单.md)。它覆盖当前最关键的验收：学生部署后读回、受清单保护的 GUI 清理、双击无页面、SYSTEM 计划任务、普通用户无法停止任务、Edge/Chrome 黑白名单、一键解除、到期／重启恢复、策略冲突以及逐台历史记录。只在快照可恢复的 Windows 10/11 测试机上执行，不在生产机房电脑上试。

该文档从当前源码生成专用 Windows x64 ZIP 的命令如下（在 Windows 开发机仓库根目录执行）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role StudentSetup `
  -OutputDirectory artifacts\windows-x64-v0.4.6-student-runtime-test `
  -ZipPath artifacts\VeyonCampus-0.4.6-student-runtime-test.zip
```

记录源码提交、Windows 版本、浏览器版本、ZIP SHA-256、快照名及每项结果。对任何“失败”“未执行”或“无法判定”项记录截图／命令输出并恢复快照；不要把 Agent 回执单独当成浏览器拦截通过。
