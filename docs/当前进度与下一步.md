当前源码版本为 **0.4.33**。此前一教师一学生部署、Veyon 地点创建及黑名单／白名单基础流程已由用户手工验收；用户刚确认 0.4.31 的 Agent 卸载入口已在本机实测成功。0.4.29 将校区配置传输改为 Windows 共享文件夹；0.4.30 修复跨校区任务／策略记录不一致；0.4.31 兼容缺失计划任务并改进旧 Agent 残留清理。0.4.33 修复同名 Veyon 公钥导致执行器停止的问题：只有在从 Veyon 密钥库导出并确认指纹与学生包一致时才跳过重复导入，然后继续安装 Agent；同时新增不重新导入 Veyon 公钥的独立 Agent 安装／修复入口。

此前 0.4.23 Windows 回归曾复现旧安装器的文件权限缺陷：递归套用目录权限的 `icacls` 命令退出码为 0，DLL 却得到没有允许访问条目的 DACL。0.4.23 改为使用 Windows ACL API 分别设置、核验目录和文件，恢复 Agent 安装到 ProgramData，并修复已有文件和未变配置的权限。该版本当时的构建、7 项文件安装回归和 5 项专项检查结果仅作历史记录。详细过程见[学生虚拟机网站 Agent 启动失败排查记录](学生虚拟机网站Agent启动失败排查记录.md)。

此前完成的本地工作（截至 2026-09-27）：

- 教师端新增“一键添加到 Veyon”：为新地点生成 1–150 台电脑；学生名单可从 Excel 按行粘贴，电脑显示名只显示学生姓名，主机名保留编号。检测到同名地点或主机名时停止，写入后读回核对；部分失败时提示先在 Configurator 检查，避免盲目重试。地点页另有可选预览和手动打开 Configurator 的入口。
- 教师端改为固定左侧导航：“课堂控制”默认打开，地点与学生名单、教师安装及学生配置包生成收进低频页面。
- Veyon 电脑显示名改为只显示已填写的学生姓名；编号留在主机名字段中，供连接使用。
- 学生端启动后只读检测并显示本机 Veyon 状态；“生成预览并检查环境”统一生成计划并运行预检。两种执行路径都会在启动安装器前复核 Veyon，兼容版本已安装时跳过安装。
- 网站策略后台运行代码拆为独立 `VeyonCampus.Agent.exe`。它是 Windows GUI 子系统程序，不含 Avalonia UI；0.4.21 按版本安装在 ProgramData，0.4.22 源码改为按版本安装在 Program Files，但用户虚拟机部署在暂存目录阶段被拒绝，未完成 Agent 安装。Agent 由 SYSTEM 开机计划任务启动，计划使用 ACL 限制为 SYSTEM／管理员可写、普通用户只读。监听改用 TCP 39174；可安全接续已识别的旧版计划任务与防火墙规则，旧 URL ACL 保持不变。
- 教师策略推送结果现在明确显示目标的 TCP 端口和网络检查项。学生机检查结果显示 TCP 39173／39174 都没有 URL ACL 记录；旧安装逻辑把空查询误判成其他账户占用。0.4.16 改为核实实际 URL ACL 记录后再判断，并继续使用按版本隔离的代理目录，以免旧文件影响重试。需要重新部署后在两台电脑验收。
- 0.4.15 学生机回传的任务 XML 已确认任务以 SYSTEM 启动，Agent 路径和参数正确；任务尚未运行（`0x41303`），因为此前 ACL 设置阶段失败。只读回读还发现 `<Command>` 含外层引号，而路径比较未剥除引号，导致验证器误报。0.4.16 只设置受保护 DACL、保留现有任务所有者／组，放宽组 SID 的安全描述符解析，并在比较任务路径时剥除外层引号；ACL COM 错误也会带出 HRESULT。
- 0.4.16 实机重试在防火墙规则迁移阶段停止。0.4.17 已去掉对 `LocalSubnet` 文本的依赖，但 PC-19 回传的 `netsh` 摘要未显示程序路径，仍无法核对规则归属；部署因此在计划任务升级之前停止，后续只读检查继续看到旧版 `.15` 路径。0.4.18 改用 `netsh ... show rule ... verbose` 读取详细规则，再按已知 Agent 路径和端口识别并迁移。
- 0.4.18 实机回传在 ProgramData 中读取代理运行库文件时遇到“访问被拒绝”，随后部署后只读检查使学生界面退出。0.4.19 对已存在的版本目录先重新应用 SYSTEM／管理员 ACL 再核对文件；只读检查把意外异常转成页面错误提示，并保持清理禁用。该修复仍需在 PC-19 验收。
- 学生部署后的 Veyon 公钥核验改为从本机 Veyon 密钥库导出预期公钥并与配置包指纹比较；当前完成代码和构建验证，仍需在实机确认 4.11.2 CLI 的读回行为。
- Windows 会阻止普通权限的资源管理器向管理员窗口 OLE 拖放；普通模式可拖入，管理员模式显示提示并引导使用配置包选择器。
- 任务注册时设置受保护 ACL，只允许 SYSTEM 与本机 Administrators 完全访问；部署后只读验证会检查计划任务身份、命令、代理健康响应和任务 ACL。
- 部署完成后可先做只读读回；必要组件全部确认后才能退出并清理。清理只移除发布清单列出的 GUI 部署文件，保留未列出文件、Veyon 和独立 Agent。
- 教师可给选定设备推送 Edge/Chrome 黑名单、白名单或停用策略；策略默认 60 分钟到期，可选 45/60/90/120 分钟或不自动到期。教师也可一键解除所选设备限制。
- 策略带签名时限，最长 24 小时。Agent 启动时和每 30 秒检查过期策略，仅清除本工具仍拥有且未被外部改写的值；固定事件日志有 64 KB 上限。
- 教师端本机保存最近 50 次推送的逐台状态，不保存域名清单或签名内容；失败设备可以填回目标框供教师复核后重推，不会自动重试。
- 教师控制台与学生部署工具已分成独立窗口、ViewModel 和程序集；教师构建排除学生窗口及 Agent，学生构建排除教师窗口和教师操作 ViewModel。Windows 打包脚本支持 `StudentSetup`／`TeacherConsole` 两个角色，学生清理逻辑识别新 exe 名并拒绝教师包清单。
- UI 样式统一并设计了新图标，已接入 Avalonia 资源、窗口标题栏及 Windows 应用图标构建项。

0.4.31 的 36 项自动检查、6 项学生专项检查和本机只读预检属于上一轮证据；用户随后已在本机确认卸载成功。0.4.33 本轮构建了两个角色包并核验内嵌 Veyon 安装器摘要；本轮没有运行自动检查或执行系统安装。Agent 首次失败后的独立修复、同名公钥重试和 Agent 健康读回需由用户使用 0.4.33 实机验收；SMB 权限、浏览器策略刷新及教师到学生机连接仍待验证。
