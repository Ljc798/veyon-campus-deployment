## 当前结论

当前源码版本为 **0.4.5 Windows 本地离线部署实验版**。本工作区源码已完成构建，0 警告／0 错误，34 项自动检查全部通过；检查覆盖学生初始密码可选、管理员目标名默认 `Administrator`、模拟账户操作、Veyon 角色隔离和网站策略签名/包格式。已重新生成当前源码的 `sitepolicy-test` Windows x64 自包含测试包；原先的 0.4.5 ZIP 仍是旧包，不能用于验收本轮功能。Windows 10/11 系统验收、真实账户登录、浏览器策略和教师机到学生机连接闭环仍未完成，当前不具备正式交付条件。

这轮继续推进 P3 的跨进程互斥：四个共享的修改入口（教师密钥／配置包生成、教师端 Veyon 安装、学生端单独安装、所选操作执行）现在使用 `NamedPipeTaskLease`。它在进程内租约之上占用一个仅当前用户可访问的单实例命名管道；其他 App 实例无法同时取得同一任务锁。管道不承载执行命令或高权限请求。

这只是 P3-02/P3-05 的互斥切片。尚未建立受限 Worker、版本化 IPC 请求、执行身份核对或崩溃后恢复流程；本轮未进行 Windows 双实例验收，因此不能将 P3-02 或 P3-05 标为完成。

网站访问控制按用户要求使用免费自研实现，不集成付费 IAC Add-ons。本轮已接入 Edge/Chrome 机器级黑白名单编译、教师证书私钥签名、学生包公钥、SYSTEM 代理任务注册/验签/策略写入和教师端局域网推送代码。自动检查通过，但没有在真实学生机注册 SYSTEM 任务、写 HKLM 或验证浏览器策略生效；详细状态与操作顺序见[教师端网站访问控制与角色隔离](教师端网站访问控制与角色隔离.md)。

按开发路线清单的严格验收口径，当前 132 个编号任务中有 11 项完成，闭合率为 **8.3%**。这代表已达到交付验收条件的任务比例，不是代码完成百分比；若干未勾选任务已有部分实现，但仍缺本机或系统验收证据。

## 已具备的基础

- App/Core 分层、150 台命名规则、不可变计划和四种独立操作的计划预览已存在。
- 资料解析、路径／资源校验、只读预检、固定 Veyon 安装器信任基线、资源快照和运行记录已有实现或本地检查证据。
- 执行协调器能按依赖顺序处理步骤，在失败、取消、待重启和需核对状态下停止后续步骤。
- 最近一轮审阅修复了公钥快照未被实际导入、最终验证状态未纳入汇总、改名命令错误、SID 来源错误和账户空密码入口。本报告原记录时账户操作仅预览；随后已加入密码输入及 SID 绑定执行代码，实机状态仍未知。
- 本轮新增跨进程任务锁代码，尚无双进程运行证据。
- 学生安装使用 `/NoMaster`、教师安装包含 Master；schemaVersion=3 学生包带网站策略公钥、不带私钥。34 项检查覆盖组件参数与网站策略纯代码路径，但 Windows 角色部署仍待实机验收。
- 网站策略私钥保存在教师当前用户证书库；学生代理只持公钥，以 SYSTEM 身份接收签名消息。现有 URLBlocklist/URLAllowlist 冲突时拒绝覆盖。仅支持 Edge/Chrome，首次学生包交付仍须通过可信渠道。
