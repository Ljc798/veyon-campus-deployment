# 管理员部署、软件保护与灰度试点手册

本文是教师端部署和试点的入口指南。StudentSetup 逐项操作、故障恢复以及长期 AppLocker 事务的细节分别保留在[学生端首次部署与恢复指南](学生端首次部署与恢复指南.md)和[Phase 5 软件管控与恢复记录](../specs/next-phase/phase-5-application-policy-ux.md)。

## 一次部署与学生关联

1. 在教师电脑安装 TeacherConsole；首次初始化时核对校区身份和已有密钥。不要为了换输出目录或重试而删除现有密钥。
2. 使用管理员生成的本校区配置包。在每台测试学生电脑上运行 StudentSetup，选择配置来源和本次确实要执行的部署项目；先检查计划和环境结果，再明确确认执行。
3. 读回 Veyon、Agent、部署版本和学生账户状态，并由教师端核对 Agent 身份。安装完成或下载完成本身不代表教师连接、浏览器策略或学生姓名已验证。
4. 在教师端“配置与部署 → 地点与学生名单”维护 Veyon 地点、电脑编号、座位和学生显示名。姓名是可变展示信息；电脑身份和电脑编号应单独核对。新增或换座后检查地点内是否有重复电脑目标。
5. 使用“设备健康”读取在线状态。未知、离线、身份冲突和过期回执必须保留为待处理状态，不得映射成正常或已关机。

详细 StudentSetup 检查、组合执行顺序和本机管理员恢复方式见[学生端首次部署与恢复指南](学生端首次部署与恢复指南.md)。

## 配置长期软件运行保护

1. 在“策略与预设 → 系统限制”读取所选电脑的学生账户，逐台核对账户范围。
2. 选择“长期软件运行保护（含部分安装限制）”。普通配置不要求先扫描并逐个勾选已安装软件。
3. 阅读影响说明并确认。Student Agent 会在每台电脑执行环境、身份、ACL、策略归属和恢复状态预检，再写入策略并进行本机读回。
4. 只把逐台签名回执显示“已确认”、并经管理员读取本机策略的电脑记录为完成。失败、超时、未知、外部策略冲突均需保留并调查；不得通过反复重试覆盖组策略或 MDM。
5. 停止保护时取消同一选项并提交解除。按设备逐台确认策略已恢复；课堂临时软件规则需另到“应用限制”解除，两者是分离操作。

AppLocker 的覆盖集合和限制、故障场景、管理员逐步恢复流程见[Phase 5 软件管控与恢复记录](../specs/next-phase/phase-5-application-policy-ux.md)。不要手工删除 `%ProgramData%\VeyonCampus\ApplicationPolicy` 事务账本，不要停止 `AppIDSvc` 或清除其他管理员拥有的策略。

## 课堂快捷管控灰度试点

快捷网站限制和键鼠锁定属于新课堂控制层。普通 TeacherConsole 构建默认关闭新快捷命令；查看状态和释放本工具已有管控仍可用。只向指定测试教师提供带试点编译标记的 TeacherConsole：

```powershell
.\scripts\package-windows-offline.ps1 `
  -Role TeacherConsole `
  -ClassroomQuickControlManualTest `
  -OutputDirectory .\artifacts\pilot\TeacherConsole `
  -InstallerPath .\artifacts\pilot\VeyonCampus-TeacherConsole-Pilot-Test.exe
```

试点包会包含 `CLASSROOM-QUICK-CONTROL-PILOT.txt`。学生端不需要为教师快捷管控单独切换灰度开关；其 Agent 仍执行现有签名、身份、版本、归属、租约和恢复验证。

按“1 台 → 2–5 台 → 整间测试教室”的顺序推进。每一级都记录网站模式、设备回执、断网行为、键鼠恢复耗时和解除结果；失败或恢复未知时停止扩围。未取得可恢复 Windows 10/11 实机证据前，不把 InputGuard 或 AppLocker 效果写成已通过，也不把试点包当作稳定发行物。

## 现场问题定位

- **教师端看不到学生电脑**：核对地点映射、Veyon 地址/电脑名、Agent 版本、网络可达性和固定身份；再从“设备健康”读取详细诊断。
- **没有收到签名状态**：状态是未知，不代表电脑已关机。确认网络和 Agent 后手动重读；不要自动重放离线控制命令。
- **Edge/网站结果不符**：核对策略模式、策略版本、浏览器策略读回和浏览器实际访问。Agent 回执不能单独证明网页行为。
- **课堂快捷管控冲突**：查看逐台所有权和状态。“解除课堂管控”用于恢复本工具持有项；要清除当前课堂学生电脑上的全部网站黑名单/白名单，使用独立的“恢复全班网站访问”操作。该操作逐台比较策略版本，不支持或未核验的 Agent 会保持不变并提示更新/核对。应用限制、系统限制和键鼠租约不受网站恢复操作影响。
- **软件保护无法写入或解除**：保留状态账本和完整诊断，按 Phase 5 恢复指南检查本机与有效 AppLocker 策略；发现 GPO/MDM 或其他管理工具冲突时停止操作并交由策略所有者协调。
- **手机控制连接失败**：按[手机控制使用指南](手机控制使用指南.md)重新核对 LAN、证书信任、连接码及教师批准。手机端由教师电脑聚合状态，不使用 CloudBase 逐机心跳。
