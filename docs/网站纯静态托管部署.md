# 网站纯静态部署（不依赖 CloudBase）

CloudBase 环境隔离后，网站域名与后台一起失效。下载页在 1.1.82 那轮已经改成纯静态读取 GitCode / GitHub 的 `releases/latest`，因此**网站本身不再需要任何后端**：只要有一个能放静态文件的托管点，`kidscode.fun` 就能恢复，且不会再因为某个账号欠费而停。

本文只覆盖"把网站挂回去"。后台管理与心跳统计仍依赖后端，见文末「已知限制」。

## 构建

```bash
cd website
npm ci
npm run build:static-only
```

产物在 `website/dist`，约 1.4 MB。

要直接得到可上传的 zip，用仓库里的打包脚本：先构建再打包，或用 `-SkipBuild` 只打包已有产物。脚本会在打包前检查产物里是否混入了后台管理代码——静态模式本应把它摇树删掉，混进去就说明构建模式用错了，会直接报错，而不是打出一个"后台全报 402"的包。

`build:static-only` 与默认 `build` 的区别：

- 隐藏管理后台入口（`app.js` 用 `import.meta.env.MODE === 'static-only'` 判断，构建时静态折叠，后台模块被摇树删除，产物里搜不到 `cloud-admin`）
- 不产出 `dist/api/openapi.yaml`

产物结构：

```
dist/
├── index.html          # 首页（history.pushState 路由，未知路径需回落到它）
├── assets/             # 带内容哈希的 js/css/图片
├── docs/               # 36 篇文档 + pagefind 搜索索引
├── old/                # 旧版入口
├── pagefind/           # 站内搜索
├── robots.txt
└── sitemap.xml
```

## 部署到腾讯云 COS

选 COS 而不是 CloudBase 的理由很实际：按量计费不会"到期"，静态网站托管 + 自定义域名 + 免费证书都能做，一个月几毛钱。

1. **建桶**：地域选离学校近的（如 `ap-shanghai`），访问权限「公有读私有写」。
2. **开静态网站**：桶 → 基础配置 → 静态网站 → 开启。
   - 索引文档：`index.html`
   - 错误文档：`index.html`
   - 错误文档这一项是必须的：站点用 `history.pushState` 做干净 URL，`/docs/` 这类路径在存储里不存在，必须回落到首页由前端接管，否则刷新就 404。
3. **上传**：把 `artifacts/website-static-<日期>.zip` 解压后把**解压出来的内容**上传到桶根目录（不要多一层文件夹）。
4. **绑域名**：桶 → 域名管理 → 自定义域名 → 添加 `kidscode.fun`，按提示在 DNSPod 加 CNAME。原来指向 `*.tcbaccess.tencentcloudbase.com` 的记录要先删掉。
5. **证书**：腾讯云证书管理申请免费 DV 证书（域名验证可在 DNSPod 自动加记录），绑定到该域名，并开启强制 HTTPS。
6. **缓存**：
   - `index.html` 设 `Cache-Control: no-cache`（否则发新版后用户看不到）
   - `assets/*` 设长缓存（文件名带哈希，可以 `max-age=31536000, immutable`）
   - `pagefind/*` 中等缓存即可

## 备选托管

| 方案 | 说明 |
|---|---|
| 任意 Nginx | `root /srv/veyon-web;` + `try_files $uri $uri/ /index.html;` |
| 阿里云 OSS 静态网站 | 与 COS 等价，规则同上 |
| 华为云 OBS / 七牛 | 同上 |
| Cloudflare Pages / Vercel | 能用，但跨境访问慢且不稳，不建议给国内学校 |
| `*.tcloudbaseapp.com` | **不要当长期主机**：免费环境 6 个月到期需手动续，且免费版绑不了自有域名 |

## 先让域名立刻能打开（不建站）

如果只想要"现在就能访问"，不想等上传和证书，可以在 DNSPod 加一条显性 URL：

| 主机记录 | 类型 | 记录值 |
|---|---|---|
| `@` | 显性 URL（301） | `https://gitcode.com/ljc_1126/veyon-campus-deployment/releases` |

TTL 600，5 分钟生效。地址栏会跳到 gitcode 的发布页，下载链接就在页面上。之后真正建好静态站时，删掉这条、换成 CNAME 即可。

这条不能替代站点：没有自己的首页、没有文档、地址栏是别人的域名。

## 验收清单

- [ ] `https://kidscode.fun` 打开是站点选择页（不是 402）；点「Veyon 校园站」进入主站
- [ ] 主站显示的版本号是当前最新版（说明真的读到了 release，而不是兜底常量）
- [ ] 教师端下载按钮能下到 exe（约 71 MB），学生端约 68 MB
- [ ] 直接访问 `/docs/` 再刷新，不出现 404
- [ ] https 无证书警告，http 自动跳转 https
- [ ] 页面上**看不到**「管理后台」入口（静态构建已移除）

## 已知限制

静态模式下这三件事没有数据源，不是 bug：

| 功能 | 现状 | 替代 |
|---|---|---|
| 后台管理（登录、发布配置包、设备列表） | 不可用，入口已在静态构建里移除 | 配置包用 `scripts/publish-package.cmd` 拖拽发布；设备状态在教师端本机看 |
| 心跳 / 遥测统计 | 不再上报 | 课堂内实时状态走局域网，不受影响 |
| 在线下载页的"下载次数" | 无统计 | 无 |

将来如果又有后端（自建或重新开通 CloudBase），用 `npm run build`（不带 `static-only`）重新构建即可，后台入口和 API 说明会一起回来。

## 每次发版之后

静态站不会自己更新。发新版本后要重新构建并上传，同时把 `website/app.js` 里的 `DOWNLOAD_FALLBACK_RELEASES` 改成新版本号——它是 GitCode 和 GitHub 都读不到时的兜底值，不改的话接口一抖，页面就会退回上一个版本号。
