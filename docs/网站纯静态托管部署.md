# 网站纯静态部署（不依赖 CloudBase）

CloudBase 环境隔离后，网站域名与后台一起失效。下载页在 1.1.82 那轮已经改成纯静态读取 GitCode / GitHub 的 `releases/latest`，因此**网站本身不再需要任何后端**：只要有一个能放静态文件的托管点，`kidscode.fun` 就能恢复，且不会再因为某个账号欠费而停。

本文只覆盖"把网站挂回去"。后台管理与心跳统计仍依赖后端，见文末「已知限制」。

## 构建

```bash
cd website
npm ci
npm run build:static-only
```

产物在 `website/dist`，约 1.4 MB。

要直接得到可上传的 zip，用仓库里的打包脚本：先构建再打包，或用 `-SkipBuild` 只打包已有产物。脚本会在打包前检查产物里是否混入了后台管理代码——静态模式本应把它摇树删掉，混进去就说明构建模式用错了，会直接报错，而不是打出一个"后台全报 402"的包。

`build:static-only` 与默认 `build` 的区别：

- 隐藏管理后台入口（`app.js` 用 `import.meta.env.MODE === 'static-only'` 判断，构建时静态折叠，后台模块被摇树删除，产物里搜不到 `cloud-admin`）
- 不产出 `dist/api/openapi.yaml`

产物结构：

```
dist/
├── index.html          # 首页（history.pushState 路由，未知路径需回落到它）
├── edgeone.json        # EdgeOne Pages 的 SPA 回落声明；对象存储不读它，留着无害
├── assets/             # 带内容哈希的 js/css/图片
├── docs/               # 36 篇文档 + pagefind 搜索索引
├── old/                # 旧版入口
├── pagefind/           # 站内搜索
├── robots.txt
└── sitemap.xml
```

除 `/` 和 `/docs/` 之外，`/product`、`/download`、`/about`、`/contact` 都是**只有前端认识**的干净 URL，磁盘上并没有同名文件。所以托管点必须支持"找不到文件时回落到 `index.html`"，否则刷新这些页面就是 404。`edgeone.json` 就是给 EdgeOne 用的那份声明：

```json
{
  "rewrites": [
    { "source": "/*", "destination": "/index.html" }
  ]
}
```

EdgeOne 把这个**精确配置**识别为 SPA 回退（不是普通重写）：先匹配实体文件和函数，全都没命中才返回 `index.html`。这正是 `/assets/*.css` 不会被吞成 HTML 的原因。

## 部署到腾讯云 EdgeOne Pages（免费，首选）

这是目前唯一同时满足**免费 + 国内节点 + 能绑自有域名**的托管点，而且支持直接拖 zip，不用 Git。

免费版额度（2026 年 9 月按官方文档核实）：40 个项目、500 次构建/月、200 个自定义域名、5 GB 存储、单文件 25 MB、流量与请求官方写"不限量"。直接上传不消耗构建次数。

**前提：域名必须已备案。** 建项目时"加速区域"三选一，这一项决定速度也决定能不能用：

| 加速区域 | 要备案 | 实际走哪 |
|---|---|---|
| 中国大陆可用区 | 要 | 国内节点，最快 |
| 全球可用区 | 要 | 国内 + 海外 |
| 全球可用区（不含中国大陆） | 不要 | 纯境外，和用 Cloudflare 没区别 |

去 `https://beian.miit.gov.cn/` 查 `kidscode.fun`。

### 这里有个容易误判的点：要的是"备案"，不是"腾讯云接入备案"

备案分两层，很多人卡在这：

| | 是什么 | 谁管 |
|---|---|---|
| ICP 备案 | 域名在工信部登记，拿到 `XICP备YYYYYYY号` | 任何一家接入商办都行，全国通用 |
| 接入备案 | 在**某一家**云厂商登记"这条线路由我承载" | 每家单独办，互不通用 |

**EdgeOne 要的是第一层。** 腾讯云官方文档写明：域名在工信部已有 ICP 备案号，且只使用 CDN / EO / WAF / 高防 IP 这类产品时，**ICP 备案信息不强制要求接入腾讯云**。只有源站是腾讯云 CVM 或轻量应用服务器时，才需要在腾讯云做接入备案——而 EdgeOne Pages 的源站是它自己的边缘节点，不是你的 CVM。

所以备案在京东云、阿里云或任何一家，都不影响 EdgeOne 选「中国大陆可用区」，只要工信部查得到备案号。

如果绑定域名时仍然提示未备案，按顺序试：

1. **等 2 小时再试**。备案数据同步到各家系统有延迟，官方 FAQ 明确写了这一点。
2. **改用京东云 OSS**。备案本来就在京东云，绑自有域名最顺，见下节。
3. **最后才考虑接入备案**。它要求账号下有符合条件的大陆云服务器（包月 ≥3 个月），审核 3–20 个工作日。为了一个静态站买服务器不划算，除非你本来就要用。

步骤：

1. `https://edgeone.cloud.tencent.com` → 创建项目 → 选**直接上传**（注意：选了这个以后不能切成 Git 集成，要自动部署得另建项目）
2. 项目名 5–50 位小写字母/数字/连字符，**加速区域按上表选**
3. 拖入 `artifacts/website-static-<日期>.zip`（zip 内必须 `index.html` 在根，别多套一层 `dist/`）→ 开始部署
4. 部署完点预览链接自检。**这个链接在中国大陆只有 3 小时有效期**（超时 401），别拿去分享
5. 域名管理 → 添加 `kidscode.fun` → 按提示去 DNSPod 加 CNAME；原来指向 `*.tcbaccess.tencentcloudbase.com` 的记录先删
6. 证书由平台自动签发（免费），开启强制 HTTPS

免费版的代价要说清楚：官方文档同时写着"长期有效"和"当前处于限时免费阶段，配额在商业化后可能调整"。如果学校这套不能接受政策变动，选下面的 COS。

## 部署到腾讯云 COS（几毛钱/月，最稳）

选 COS 而不是 CloudBase 的理由很实际：按量计费不会"到期"，静态网站托管 + 自定义域名 + 免费证书都能做，一个月几毛钱。

1. **建桶**：地域选离学校近的（如 `ap-shanghai`），访问权限「公有读私有写」。
2. **开静态网站**：桶 → 基础配置 → 静态网站 → 开启。
   - 索引文档：`index.html`
   - 错误文档：`index.html`
   - 错误文档这一项是必须的：站点用 `history.pushState` 做干净 URL，`/docs/` 这类路径在存储里不存在，必须回落到首页由前端接管，否则刷新就 404。
3. **上传**：把 `artifacts/website-static-<日期>.zip` 解压后把**解压出来的内容**上传到桶根目录（不要多一层文件夹）。
4. **绑域名**：桶 → 域名管理 → 自定义域名 → 添加 `kidscode.fun`，按提示在 DNSPod 加 CNAME。原来指向 `*.tcbaccess.tencentcloudbase.com` 的记录要先删掉。
5. **证书**：腾讯云证书管理申请免费 DV 证书（域名验证可在 DNSPod 自动加记录），绑定到该域名，并开启强制 HTTPS。
6. **缓存**：
   - `index.html` 设 `Cache-Control: no-cache`（否则发新版后用户看不到）
   - `assets/*` 设长缓存（文件名带哈希，可以 `max-age=31536000, immutable`）
   - `pagefind/*` 中等缓存即可

## 京东云 OSS（备案在当前接入商时的备选）

如果 EdgeOne 绑定域名被拦，而备案正好在京东云，这条路最顺——备案本来就在这家，不需要任何新的审核。

1. 建 Bucket，权限「公有读私有写」
2. 空间设置 → 静态网站托管 → 开启
   - 索引文档：`index.html`
   - 错误文档：`index.html`（和 COS 同理，SPA 回落靠它）
   - 注意：静态网站规则**只在 S3 域名和自定义域名下生效**，用 OSS 服务域名访问不会生效
3. 空间设置 → 域名管理 → 绑定 `kidscode.fun`，提交 ICP 备案号审核（京东云要求提供备案号，你已有）
4. DNSPod 加 CNAME，指向该 Bucket 的 S3 服务域名
5. HTTPS 需要自己上传证书（京东云 SSL 证书服务）

费用：标准存储每地域 10 GB 免费额度，外网下行流量与 CDN 单独计费。静态站一个月通常几毛到几块。

## 备选托管

| 方案 | 说明 |
|---|---|
| 任意 Nginx | `root /srv/veyon-web;` + `try_files $uri $uri/ /index.html;` |
| 阿里云 OSS 静态网站 | 与 COS 等价，规则同上 |
| 华为云 OBS / 七牛 | 同上 |
| Cloudflare Pages / Vercel | 能用，但跨境访问慢且不稳，不建议给国内学校 |
| `*.tcloudbaseapp.com` | **不要当长期主机**：免费环境 6 个月到期需手动续，且免费版绑不了自有域名 |

## 先让域名立刻能打开（不建站）

如果只想要"现在就能访问"，不想等上传和证书，可以在 DNSPod 加一条显性 URL：

| 主机记录 | 类型 | 记录值 |
|---|---|---|
| `@` | 显性 URL（301） | `https://gitcode.com/ljc_1126/veyon-campus-deployment/releases` |

TTL 600，5 分钟生效。地址栏会跳到 gitcode 的发布页，下载链接就在页面上。之后真正建好静态站时，删掉这条、换成 CNAME 即可。

这条不能替代站点：没有自己的首页、没有文档、地址栏是别人的域名。

## 验收清单

- [ ] `https://kidscode.fun` 打开是站点选择页（不是 402）；点「Veyon 校园站」进入主站
- [ ] 主站显示的版本号是当前最新版（说明真的读到了 release，而不是兜底常量）
- [ ] 教师端下载按钮能下到 exe（约 71 MB），学生端约 68 MB
- [ ] 直接访问 `/docs/` 再刷新，不出现 404
- [ ] **直接访问 `/product` 再刷新，不出现 404**——这条验的是 SPA 回落，EdgeOne 靠 `edgeone.json`，COS 靠"错误文档填 index.html"，漏配就只坏这一处
- [ ] 刷新页面后样式仍在（说明 `/assets/*.css` 没被回落吞成 HTML）
- [ ] https 无证书警告，http 自动跳转 https
- [ ] 页面上**看不到**「管理后台」入口（静态构建已移除）

## 已知限制

静态模式下这三件事没有数据源，不是 bug：

| 功能 | 现状 | 替代 |
|---|---|---|
| 后台管理（登录、发布配置包、设备列表） | 不可用，入口已在静态构建里移除 | 配置包用 `scripts/publish-package.cmd` 拖拽发布；设备状态在教师端本机看 |
| 心跳 / 遥测统计 | 不再上报 | 课堂内实时状态走局域网，不受影响 |
| 在线下载页的"下载次数" | 无统计 | 无 |

将来如果又有后端（自建或重新开通 CloudBase），用 `npm run build`（不带 `static-only`）重新构建即可，后台入口和 API 说明会一起回来。

## 每次发版之后

静态站不会自己更新。发新版本后要重新构建并上传，同时把 `website/app.js` 里的 `DOWNLOAD_FALLBACK_RELEASES` 改成新版本号——它是 GitCode 和 GitHub 都读不到时的兜底值，不改的话接口一抖，页面就会退回上一个版本号。
