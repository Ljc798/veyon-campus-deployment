# 课堂功能现场验收台账

本台账按能力、构建、设备/校区、账户类型、教师端与 Agent 版本、日期记录证据。`FIELD-PASS` 只描述记录中的具体版本和场景，不表示其他版本或能力也通过。收到命令、HTTP 200 或签名回执本身都不代表策略在学生端实际生效。

## 状态定义

- `FIELD-PASS`：在对应设备上完成教师下发、Agent 回执、学生普通账户实际效果及解除/恢复的完整核验。
- `FIELD-FAIL`：现场按预期步骤执行但实际结果不符合预期；附复现步骤和证据。
- `CODE-SUSPECT`：代码审查或自动化检查发现可能影响现场的风险，尚无现场结果。
- `NOT-TESTED`：没有满足完整现场验收条件的证据。
