# App 开发路线与任务清单

更新日期：2026-09-25。本文是后续 App 开发的任务主清单。勾选项代表已在代码和当前环境中验证；Windows 实机任务仍保持未完成。

配套文档：[架构与实现约束](架构与实现约束.md) · [测试验收与发布清单](测试验收与发布清单.md) · [当前预览版运行说明](app-development.md)。原脚本问题保留在 [开发改进清单](../开发改进清单.md)，后续 App 任务以本文为准。

## 1. 已确定的产品要求

| 项目 | 已确定要求 | 实现边界 |
| --- | --- | --- |
| 技术路线 | C# + Avalonia | macOS 用于开发和界面预览；真实部署只在 Windows 实现 |
| 目标电脑 | Windows 10 / Windows 11 | 具体版本、版本号、架构和支持状态在 P0 建立实测矩阵，不承诺所有旧版本 |
| 机房容量 | 每个机房最多 150 台学生电脑 | 编号、名称、列表导入、计划生成和后期结果面板统一支持；不等于已经实测 150 台并发 |
| 离线 | 安装配置不依赖互联网 | 开发机还原依赖可联网；目标电脑需要的程序和依赖随包交付 |
| 使用方式 | 教师端、学生端均用 App | 用户不需要复制脚本、打开 PowerShell 或输入命令 |
| 操作拆分 | Veyon 部署、电脑改名、账户配置可以分别操作 | 账户配置进一步拆为创建普通学生账户、修改指定管理员密码；可只做其中一项 |
| 操作组合 | 可以一次选择多项后执行 | 只执行明确选中的项目，不隐式加入改名、改密或重启 |
| 资料输入 | 按钮选择和拖拽并存 | 当前支持文件夹及 campus.json；ZIP 导入不是首版必做功能 |
| 分发顺序 | 基础 App 及本地部署功能完成后再做局域网分发 | 本地完整版本可独立交付；分发不是核心运行前提 |
| 环境未知 | 是否加域、是否有还原卡／还原软件不清楚 | 软件尽可能只读检测；不能确定时显示“未知”，不能假定没有 |

默认交互建议：进入某项功能才选择该操作；组合任务中改名、创建账户、修改密码均默认不选。是否重启由用户在任务结果页另行决定。

## 3. 任务执行与完成规则

- 任务 ID 固定，例如 P3-04；问题反馈、实现记录、测试记录引用 ID，避免只说“安装部分”。
- `[ ]` 表示未达到完整验收条件，不区分“还没写”或“写了没测”；在任务后追加实际状态和证据。
- `[x]` 只在任务的交付物和验收证据齐备后勾选。部分完成时拆分任务，不把整阶段提前勾完。
- 每项任务记录负责人、开始日期、完成日期、关联提交、验证环境和未解决问题。负责人初始为“待分配”，不虚构团队成员。
- 下阶段准备工作可以提前开展，但不得绕过前一阶段的系统修改、凭据或发布门槛。
- 每次实现控制范围：一个可验证行为、一组相关变更；先验证单机，再扩大设备范围。
- 本文以验收条件安排顺序，不在 Windows 测试条件未知时承诺具体发布日期。
- UI、架构、数据协议、运行产物和文档版本同步更新；新产物使用新补丁版本，避免不同代码一直叫 0.1.0。

任务记录模板：

```text
任务 ID / 标题：

前置任务：
本次变更与不包含的内容：
代码、文档、产物位置：
验证环境 / 步骤 / 结果：
关联提交 / 缺陷：
下一步或阻塞条件：
```

- [ ] P0-04 记录 Veyon 安装程序版本、来源、摘要和数字签名验证结果；本地已有 EXE 不自动视为可信基线。代码已固定上游资产摘要，并在 Windows 预检和安装入口校验 Authenticode 与签名者指纹；未知或不同的现有安装版本也会阻断安装/配置。需在 Windows 10/11 实机验证 WinVerifyTrust 互操作和信任链后关闭。
- [ ] P0-05 核对选定 Veyon 版本的静默安装、CLI 命令、组件选项及退出码；固定测试版本，不随官网最新版自动漂移。上游 v4.11.2 安装器源码已核对参数和管理员错误码；安装结果、CLI 读回和退出码仍需 Windows 试装。

版本与来源记录（2026-09-25）：暂固定 Veyon `4.11.2.0` x64，不随官网最新版漂移；官方资产名为 `veyon-4.11.2.0-win64-setup.exe`，下载来源为 [GitHub v4.11.2 Release asset](https://github.com/veyon/veyon/releases/download/v4.11.2/veyon-4.11.2.0-win64-setup.exe)。GitHub 官方 Release API 给出的 SHA-256 为 `7EC3F0689F995FE7C79D3F5B106E85DADE089AB24F534E92A168543197F0E428`，大小 16,782,856 字节；本轮下载文件摘要与 API 一致。签名证书提取信息：`Veyon Solutions`，证书 DER 内容的 SHA-256 指纹 `7587C97686BF912155F3C43713B87E7F800890D804AC1EFE479E0744A62C5619`。提取到证书信息不等于已验证 Windows 信任链；实现通过 `WinVerifyTrust` 检查 Authenticode 并固定该证书指纹，但尚未在 Windows 执行。为支持离线机房，WinVerifyTrust 未请求吊销状态下载；发布资产 SHA-256 和叶证书 SHA-256 均固定。参考：[官方 Release API](https://api.github.com/repos/veyon/veyon/releases/tags/v4.11.2)、[Microsoft WinVerifyTrust](https://learn.microsoft.com/en-us/windows/win32/api/wintrust/nf-wintrust-winverifytrust)。

P0-05 源码核对（2026-09-25）：官方 [v4.11.2 NSIS 安装器源码](https://raw.githubusercontent.com/veyon/veyon/v4.11.2/nsis/veyon.nsi.in)使用 NSIS `/S` 静默入口，并实现 `/NoMaster`、`/NoInterception`、`/NoStartMenuFolder`；学生端当前传这三个参数，不传 `/D=`，使用系统默认安装目录。源码在非管理员时设置错误码 `740`；安装服务等内部 `ExecWait` 有部分未读取其退出码，`/ApplyConfig=` 导入失败显示消息但源码未设置明确的外层失败码。应用另用 CLI `config set/get`、`authkeys import <KEY> <FILE>`、服务读回，不依赖 `/ApplyConfig`。官方 CLI 手册说明 `<KEY>` 由仅含字母的名称和 `/public` 或 `/private` 类型组成；当前 App 用 `VeyonAuthKeyId` 从 CampusId 稳定映射为纯 ASCII 字母，再追加 `/public`。这些证据核对了源码和参数形状，不能代替 4.11.2 Windows 实测；尤其 NSIS 的成功码、重启行为、安装组件和 CLI 密钥读回仍是待验收项。参考：[Veyon CLI 手册](https://docs.veyon.io/en/latest/admin/cli.html)、[Veyon 安装说明](https://docs.veyon.io/en/latest/admin/installation.html)。
