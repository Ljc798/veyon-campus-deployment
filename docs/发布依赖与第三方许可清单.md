# 发布依赖与第三方许可清单

更新日期：2026-10-03。本文记录当前发布候选中可复核的依赖、随包声明和仍需负责人决策的事项；它是工程盘点，不构成法律意见或再分发授权。

## Windows x64 离线包

StudentSetup 与 TeacherConsole 使用锁定的 `src/VeyonCampus.App/packages.lock.json`，打包时由 `scripts/Copy-WindowsThirdPartyNotices.ps1` 从 NuGet 锁文件和本机 NuGet 缓存收集许可文件。2026-10-03 的锁定目标合计 25 个 NuGet 包：Avalonia 及子包 12.1.3、Avalonia.Angle.Windows.Natives 2.1.27548.20260419、Avalonia.BuildServices 11.3.2、HarfBuzzSharp 及原生资源包 8.3.1.3、MicroCom.Runtime 0.11.6、SkiaSharp 及原生资源包 3.119.4、Tmds.DBus.Protocol 0.94.1。锁文件许可元数据为 MIT 表达式；Avalonia.Angle.Windows.Natives 随包提供 BSD 风格 `LICENSE` 文件，应以随包原文为准。每个 Windows 发布包还包含自包含运行时 Microsoft.NETCore.App 10.0.12 的许可和第三方声明。

Student 与 Teacher 的安装目录和诊断 ZIP 都应包含根目录 `THIRD-PARTY-NOTICES.txt`、`licenses/` 下的锁定 NuGet 和 .NET 运行时材料，以及嵌入的 Veyon 安装程序对应的 `Veyon-4.11.2-COPYING.txt`。包清单会为这些文件记录 SHA-256。自动复制可以避免遗漏文本，但不能替代兼容性、分发授权或源代码义务审查。

Student 与 Teacher 使用相同的应用依赖锁文件；如角色增加原生或托管依赖，必须重新生成包并确认它进入声明材料。只修改网站依赖时，本节清单不涵盖该网站。

依赖许可来源：[Avalonia 上游仓库](https://github.com/AvaloniaUI/Avalonia)、[SkiaSharp 3.119.4](https://www.nuget.org/packages/SkiaSharp/3.119.4)、[HarfBuzzSharp 8.3.1.3](https://packages.nuget.org/packages/HarfBuzzSharp/8.3.1.3)、[Microsoft .NET 发行许可材料说明](https://github.com/dotnet/runtime/blob/main/docs/project/licensing-assets.md)。最终应以实际随包许可文件和各锁定包源为准。
