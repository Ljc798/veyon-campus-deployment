# 发布依赖与第三方许可清单

更新日期：2026-10-08。本文记录当前发布候选中可复核的依赖、随包声明和仍需负责人决策的事项；它是工程盘点，不构成法律意见或再分发授权。

## 已确认的发行决策

2026-10-07，负责人确认面向公开 GitHub/Gitee 发布，并选择把 Developer Release 私钥存入 GitHub `production-release` 受保护 Environment secret，同时制作离线加密备份。跨平台密钥生成器 `scripts/generate-release-signing-key.cjs` 已加入：只在交互终端隐藏读取口令，在仓库外生成 RSA-3072 加密 PKCS#8 私钥/公钥，显示公钥 SHA-256 指纹并拒绝覆盖。`scripts/release-signing-key.test.cjs` 自动验证加密格式、密钥匹配与 RSA-PSS 挑战、路径边界、文件权限、错误口令、密钥不匹配和禁止覆盖；API/release CI 会在这些脚本变更时运行。此处只验证测试密钥，未生成生产密钥。决定不等于相关环境、正式密钥或发布凭据已经配置。生产密钥生成、对应公钥固定、离线备份可读性验证、Environment secret 设置和首个签名发行仍需实施；本机已有的测试密钥不能自动视为正式发布密钥。

生成正式密钥时，在可信本机终端从仓库根目录运行 `node scripts/generate-release-signing-key.cjs`，按提示输入两次至少 16 位的 ASCII 口令；输入不会回显。macOS 默认保存到 `~/Library/Application Support/VeyonCampus/ReleaseKeys/Production/`，目录权限设为仅当前用户可访问，且已有密钥时拒绝覆盖。不要把该目录选在仓库中。将加密私钥文件作为 `VEYONCAMPUS_RELEASE_PRIVATE_KEY_PEM` 写入 GitHub `production-release` Environment secret；在同一受保护 Environment 中另行设置 `VEYONCAMPUS_RELEASE_PRIVATE_KEY_PASSPHRASE`。把公钥 PEM 写入仓库变量 `VEYONCAMPUS_RELEASE_PUBLIC_KEY_PEM`，并把屏幕显示的 SHA-256 指纹保存在独立的发布记录中。离线备份复制后，可运行 `node scripts/verify-release-signing-key.cjs --private-key "<备份私钥路径>" --public-key "<公钥路径>"`；该命令隐藏读取口令，只输出密钥匹配结果和公钥指纹。工作流所需的 CloudBase/Gitee 凭据仍需按 `.github/workflows/windows-installers.yml` 配置。将加密私钥的离线副本存放在离线加密介质中，解密口令另行保管；不要将私钥、口令或其截图发到聊天、提交到 Git 或放进公开 Release。密钥生成不会自动配置 GitHub，也不会触发发布。

## Windows x64 离线包

StudentSetup 与 TeacherConsole 使用锁定的 `src/VeyonCampus.App/packages.lock.json`，打包时由 `scripts/Copy-WindowsThirdPartyNotices.ps1` 从 NuGet 锁文件和本机 NuGet 缓存收集许可文件。2026-10-03 的锁定目标合计 25 个 NuGet 包：Avalonia 及子包 12.1.3、Avalonia.Angle.Windows.Natives 2.1.27548.20260419、Avalonia.BuildServices 11.3.2、HarfBuzzSharp 及原生资源包 8.3.1.3、MicroCom.Runtime 0.11.6、SkiaSharp 及原生资源包 3.119.4、Tmds.DBus.Protocol 0.94.1。锁文件许可元数据为 MIT 表达式；Avalonia.Angle.Windows.Natives 随包提供 BSD 风格 `LICENSE` 文件，应以随包原文为准。每个 Windows 发布包还包含自包含运行时 Microsoft.NETCore.App 10.0.12 的许可和第三方声明。

Student 与 Teacher 的安装目录和诊断 ZIP 都应包含根目录 `THIRD-PARTY-NOTICES.txt`、`licenses/` 下的锁定 NuGet 和 .NET 运行时材料，以及嵌入的 Veyon 安装程序对应的 `Veyon-4.11.2-COPYING.txt`。包清单会为这些文件记录 SHA-256。自动复制可以避免遗漏文本，但不能替代兼容性、分发授权或源代码义务审查。

Student 与 Teacher 使用相同的应用依赖锁文件；如角色增加原生或托管依赖，必须重新生成包并确认它进入声明材料。只修改网站依赖时，本节清单不涵盖该网站。

依赖许可来源：[Avalonia 上游仓库](https://github.com/AvaloniaUI/Avalonia)、[SkiaSharp 3.119.4](https://www.nuget.org/packages/SkiaSharp/3.119.4)、[HarfBuzzSharp 8.3.1.3](https://packages.nuget.org/packages/HarfBuzzSharp/8.3.1.3)、[Microsoft .NET 发行许可材料说明](https://github.com/dotnet/runtime/blob/main/docs/project/licensing-assets.md)。最终应以实际随包许可文件和各锁定包源为准。
