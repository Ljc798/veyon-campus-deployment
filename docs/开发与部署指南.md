# 开发、部署与排障指南

本文只保留操作步骤。当前版本、验收范围和待办见[任务主表](开发路线与任务清单.md)，目标 Installer/Service/Updater 见[架构计划](veyon_architecture_summary.md)。以下 ZIP 和计划任务是现有实验路径，不能当作目标安装器已经交付。

## 教师与学生部署

StudentSetup 首次配置、四项操作组合规则、错误恢复和教师端迁移边界见[学生端首次部署与恢复指南](学生端首次部署与恢复指南.md)。

1. 在可恢复 Windows 测试机准备对应角色包；完整解压，教师运行 VeyonCampus.Teacher.exe，学生运行 VeyonCampus.StudentSetup.exe。
2. 教师初始化固定版本 Veyon、校区密钥与配置包。已有完整密钥应复用，不通过删钥解决输出目录或重试问题。
3. CloudBase Nodejs20.19 HTTP 函数 `veyon-api` 已部署，默认 HTTP API 域名的 `/health` 和空目录搜索已验证。教师无需登录，填写校区名称、教师姓名、手机号后四位即可发布；免登录上传、学生下载、心跳写入和私有存储链路仍待合成数据验收。离线时由管理员将配置包复制到学生机本机磁盘后导入。
4. 明确选择 Veyon、改名、创建账户或指定管理员改密，先预览和检查，再执行。只执行已选择操作；待重启、失败和状态未知按页面结果处理。
5. 相同公钥且 Agent 安装失败时先验证指纹，可使用独立“安装/修复网站策略 Agent”入口；同名异指纹不覆盖，不要求先删除 Veyon 公钥。
6. 读回 Veyon 与 Agent，教师连接测试后实际检查浏览器黑白名单、解除和到期行为。不要仅凭 Agent 回执判断浏览器生效。

## 配置包来源

线上目标是教师端发布到 CloudBase 私有存储，学生端搜索后下载。教师不需要 CloudBase Auth 登录或预先获管理员授权；发布时填写校区名称、教师姓名和手机号后四位。免登录发布迁移已应用至 `20260930130000`，Nodejs20.19 HTTP Function `veyon-api` 已部署，默认域名为 `https://veyon-control-d3gs8hmuyd09c00a7-1348081197.ap-shanghai.app.tcloudbase.com`，`/health` 和空目录搜索已验证。教师发布、私有存储读写和学生下载仍待端到端验收；该 ZIP 路线不需要 TCR。首次验收请使用合成校区和配置包，不要发布真实校区配置。

断网维护时，将教师生成的配置包通过管理员信任的本地介质复制到学生机，再用“导入本地配置”选择本机磁盘中的文件夹。当前 App 已移除 UNC/映射网络盘导入，不再指导配置 Windows 文件共享。学生本地仍会完整校验 manifest、公钥和路径。

## 开发与检查

安装 .NET 10 SDK；`global.json` 指定 10.0.100 并允许 `latestFeature`，历史构建记录使用 10.0.401，实际版本以本次构建记录为准。首次依赖还原需要网络，锁文件约束 NuGet 依赖；目标电脑运行自包含发布版无需 SDK。

在仓库根目录统一执行：

```powershell
.\scripts\check-app.ps1
dotnet run --project src/VeyonCampus.App
```

`check-app.ps1` 会按锁文件还原、构建完整解决方案、额外构建 TeacherConsole 角色并运行现有检查集；它不会在本轮自动执行系统部署操作。Windows x64 打包冒烟可另外运行 `.\scripts\check-app.ps1 -WindowsPackageSmoke`，这会生成并核对两种角色 ZIP，不会安装或更改 Windows 系统。首次依赖还原需要网络。

采集 Windows 10/11 兼容矩阵摘要：

```powershell
.\scripts\collect-windows-test-environment.ps1 -OutputPath .\artifacts\test-matrix\windows-test-environment.json
```

采集器始终非交互，不会等待控制台输入；人工确认的恢复基线和 MDM 状态通过参数传入，省略时记为 `unknown`。例如 `-RestoreEnvironmentStatus confirmed -MdmEnrollmentStatus not-enrolled`。它不会探测或修改还原软件，也不采集设备、租户、账户标识。schema v2 摘要还含 EditionID、SKU、DisplayVersion、build/UBR、报告的 hotfix ID、AppIDSvc 读回，以及本机/组策略 AppLocker 规则集合计数和模式。`Get-AppLockerPolicy` 不涵盖 AppLocker CSP/MDM，所以 MDM 状态由现场人员确认；`KB5024351` 未出现在 QuickFixEngineering 列表中也不等同于已证明未安装。请在 Windows 10 和 Windows 11 测试机各运行一次，未知的恢复及 MDM 状态保持 `unknown`。

未传 `VeyonCampusRole` 时默认为 `StudentSetup`；要预览教师控制台，可运行 `dotnet run --project src/VeyonCampus.App -p:VeyonCampusRole=TeacherConsole`。检查程序写入临时测试目录并读取平台状态，不运行真实部署。Windows GitHub Actions 会调用同一检查入口；远程结果以 Actions 实际记录为准。脚本和锁文件齐备不等于干净构建、Windows 运行或系统部署已通过。

## 打包与分发

从 Git 克隆后，可在 Windows x64 开发机上自行生成离线 ZIP。需要安装 .NET 10 SDK；首次还原依赖时通常需要互联网访问 NuGet 源。固定版 Veyon 安装器已随仓库跟踪，无需另行下载。

```powershell
git clone https://github.com/Ljc798/veyon-campus-deployment.git
cd veyon-campus-deployment
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-windows-offline.ps1
```

脚本会在 `artifacts` 下按 `-Role` 生成教师或学生 Windows x64 自包含目录和 ZIP。`/artifacts/` 被 `.gitignore` 排除，因此其他人克隆仓库时不会自动得到生成的 ZIP；他们需分别运行脚本构建。当前尚未选择正式发布平台或配置自动上传；同一发布页可列出这两份角色包，但不能托管真实校区配置、教师私钥、管理员密码或学生设备清单。GitHub/Gitee 等平台的最终选择、发布物签名与校区配置可信下发流程属于 P10，尚未实现。

脚本的 `-Role` 参数选择发布角色，默认 `StudentSetup`。当前项目版本会写入 ZIP 名称。脚本写入角色标记并检查对方角色程序集／Agent 未混入；学生包另含受清理逻辑保护的文件 manifest 和标记。两个角色均为 Windows x64 自包含 App，并从发布后的 Core 程序集重读安装器资源验证大小及 SHA-256。只有学生端后台 Agent 随 StudentSetup 发布；`.ico` 同时用作 Windows 应用图标和 Avalonia 窗口图标。两个角色不再引用应用内 HTTPS LAN 服务。

生成教师控制台 ZIP：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role TeacherConsole
```

生成学生部署 ZIP（默认角色，也可显式传入 `-Role StudentSetup`）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role StudentSetup
```

已有同名输出时默认拒绝。`-Clean` 用于本地重建时替换指定输出，已对外交付版本应递增版本并保留原包。可用 `-OutputDirectory`、`-ZipPath` 指定 artifacts 内的新位置。已还原同一依赖组合的 win-x64 资源后可用 `-SkipRestore`；开发机可离线重建的范围取决于依赖缓存。

解压后保留整个 StudentSetup 文件夹，在可恢复 Windows 测试机以管理员身份运行 `VeyonCampus.StudentSetup.exe`。可从已部署的 CloudBase 目录搜索，也可从本机磁盘导入 schemaVersion=3 校区包；UNC 路径和映射网络盘已停用。若 Veyon 公钥已经导入、Agent 安装失败，重新载入同一校区包后可选“安装/修复网站策略 Agent”；完整重试会先核对已有公钥指纹。教师在自己的电脑上运行 `VeyonCampus.Teacher.exe`。教师生成包前需已安装固定版本 Veyon；同一校区换用新的输出目录会复用完整密钥对，不应通过删除密钥解决输出路径冲突。新 Wizard、离线本地导入和浏览器效果尚待 Windows 实机验收；学生程序首次获取仍须走受信渠道。

Apple Silicon 开发预览：

```sh
dotnet publish src/VeyonCampus.App -c Release -r osx-arm64 --self-contained true -o artifacts/macos-arm64/VeyonCampus-0.4.40.app/Contents/MacOS
cp packaging/macos/Info.plist artifacts/macos-arm64/VeyonCampus-0.4.40.app/Contents/Info.plist
```

该 Mac 产物仅用于本地预览，未进行发行签名或公证。当前 Windows x64 自包含 ZIP 已生成；固定安装器、SYSTEM 任务、教师界面与浏览器规则仍需在 Windows 实机完成运行验收。


## Agent 排障顺序

先保留现场和版本信息，不删除目录、URL ACL 或策略，不授予 Everyone 完全控制。

| 症状 | 优先检查 | 判定边界 |
| --- | --- | --- |
| Agent 未安装或无法启动 | 安装步骤结果、真实文件路径、DLL 与目录 DACL、SYSTEM 任务身份和启动参数 | 旧 icacls 成功码曾伴随空文件 DACL；必须读回文件权限 |
| 教师推送超时 | Agent 进程、39174 监听、目标地址、规则的程序/端口/LocalSubnet 和网络配置 | 不沿用旧 39173/HTTP URL ACL 假设处理当前 TCP 监听 |
| 重复公钥阻断 | KeyId、公钥导出指纹与当前包 | 指纹一致才跳过；不同或无法确认则停止 |
| 策略回执成功但浏览器无效 | Edge/Chrome 策略页、实际访问、浏览器重启、其他 GPO | 回执与浏览器效果分别记录 |
| 卸载残留或跨校区状态 | 实际任务、运行路径、策略归属记录和当前校区 | 仅删除可确认属于本工具的内容 |

在学生机管理员 PowerShell 可先做只读检查：

```powershell
Get-NetTCPConnection -LocalPort 39174 -State Listen -ErrorAction SilentlyContinue
Get-ScheduledTask | Where-Object TaskName -Like '*VeyonCampus*' | Select-Object TaskName,State,Actions,Principal
Get-Service -Name VeyonService -ErrorAction SilentlyContinue
```

任务查询不等于任务 DACL 检查。需要权限与历史故障细节时查[原始排障步骤](archive/2026-09-29/学生机策略代理故障检查步骤.md)和[启动失败记录](archive/2026-09-29/学生虚拟机网站Agent启动失败排查记录.md)；其中硬编码旧版本路径须按现场修正。

完整验收统一使用[测试验收与发布清单](测试验收与发布清单.md)。不再单独维护一份学生自测任务表。
