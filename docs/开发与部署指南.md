# App 开发与部署指南（0.4.33）

更新日期：2026-09-29。当前为 **Windows 本地离线部署实验版**。本文是运行、开发和打包指南；当前进度和自测入口见[当前进度与下一步](当前进度与下一步.md)。学生端启动后会显示只读 Veyon 探测状态；准备部署按钮一次生成计划并运行环境预检，兼容版本已安装时会跳过安装。学生端 Veyon 安装／导入公钥、电脑改名、创建普通学生账户和设置管理员密码均有独立及组合执行路径。0.4.33 会读回同名 Veyon 公钥指纹，一致时继续 Agent 步骤；学生端另有独立“安装/修复网站策略 Agent”入口，失败重试时不必删除 Veyon 公钥。教师端可推送 Edge/Chrome 黑白名单、从 Veyon 内置目录读取机房并按需选择目标、选择限制时长、一键解除并查看本机逐台推送记录。每次策略推送或取消后提示教师让学生手动重启浏览器。校区资料通过 Windows 共享文件夹读取，不再使用应用内 HTTPS LAN 服务。0.4.33 两角色包已生成，新增 Agent 恢复流程待实机验收。

受管设备上的 Veyon 组件按角色隔离：学生安装参数包含 `/NoMaster`，教师安装包含 Veyon Master；自动检查覆盖了这两个参数组合。App 交付物也按角色分开：`StudentSetup` 只包含学生部署窗口与操作，`TeacherConsole` 只包含教师窗口与操作。学生构建排除教师窗口／ViewModel；教师构建排除学生窗口／ViewModel，也不引用 Agent 项目。两个 App 仍复用 Core 和固定 Veyon 安装器，教师签名私钥只保存在教师 Windows 用户证书库。

## 校区配置共享（Windows 文件共享）

教师在“首次设置”页生成校区配置包后，使用文件资源管理器打开结果中显示的文件夹。右键该文件夹，选择“属性 → 共享 → 高级共享”，启用共享并只给受信任的校园网用户授予读取权限；同时确保共享权限和 NTFS 权限都允许读取。不要共享整个桌面、Veyon 密钥目录或任何教师私钥目录，也不要把共享开放到公用网络。

将共享路径发给学生，例如 `\\TEACHER-PC\Veyon-学生配置包-校区ID`。学生端在“校区配置资料”粘贴共享路径并点击“载入共享配置”，或在教师机共享目录已映射／可浏览时使用文件夹选择器。应用沿用现有 manifest、校区配置和公钥校验；读取失败时可检查网络发现、文件和打印机共享防火墙规则、名称解析及授权账户，也可试用教师机 IP 作为 UNC 主机名。Windows 共享访问需要同一可达局域网，校园 Wi-Fi 客户端隔离会阻止访问。

0.4.27 实机测试曾发现教师 HTTPS 服务启动错误和学生端 TLS 连接失败；经过验收反馈后，0.4.29 移除了应用内教师 HTTPS 服务及学生 HTTPS 下载客户端，改用 Windows 文件共享。0.4.28 对带 UTF-8 BOM 的 `campus.json` 解析修复仍保留。学生部署程序本体仍要通过受信渠道分发；当前网站没有 CloudBase 上传、认证、对象存储或搜索 API。

0.4.29 学生端“部署后只读检查与清理”区新增独立的“卸载本机网站策略代理”入口。0.4.30/0.4.31 改进跨校区和缺失计划任务时的清理边界，用户已报告本机卸载成功。0.4.33 在 Veyon 公钥导入前读取密钥清单；同名公钥必须从密钥库导出并与当前配置包指纹一致，才会跳过重复导入并继续 Agent 步骤。另增加独立 Agent 安装/修复按钮，直接从当前学生配置包安装 SYSTEM 后台代理，不改动 Veyon 公钥。Veyon 和 StudentSetup 不会被 Agent 卸载。外部修改、任务身份不明或文件含重解析点时仍会停止并保留无法确认归属的项目。卸载完成后须手动重启 Edge/Chrome。新增重试和修复入口尚待 Windows 实机验收。

Agent 推送回执表示策略已经写入，不代表浏览器页面效果已验证。教师端每次推送（包括取消策略）都会明确提示：在收到代理确认的学生电脑上手动重启 Edge/Chrome，再检查网站阻止或恢复效果；教师端不会强制结束浏览器。

## 学生端交付物与组件生命周期

学生角色的 `VeyonCampus.StudentSetup.exe` 是临时部署工具；教师角色的 `VeyonCampus.Teacher.exe` 是教师控制台。两者可从同一发布页提供不同 ZIP，但正式发布页尚未建立。学生配置包只含公钥；教师网站策略签名私钥保存在教师当前 Windows 用户的证书库。后台接收端是独立 `VeyonCampus.Agent.exe`，不包含 Avalonia UI 程序集，运行入口要求 SYSTEM 身份；只有 StudentSetup 包含 Agent。

学生端部署完成后可运行只读读回；Veyon 与适用的网站 Agent（或确认 Agent 已卸载）、SYSTEM 开机任务和任务 ACL 均通过后，清理按钮会先要求确认其他 Veyon 配置、普通学生账户和电脑名称／重启均已处理，或明确本次无需处理。便携包清理助手随后按打包 manifest 移除 StudentSetup 文件。当前清理逻辑识别新入口 `VeyonCampus.StudentSetup.exe`，也兼容旧学生包入口 `VeyonCampus.exe`；清单若含教师程序集或教师入口会拒绝清理。后台 Agent 使用独立版本目录并由 SYSTEM 计划任务启动；校区配置和运行日志位于 ProgramData。完成便携包清理不会卸载 Veyon、Agent、学生配置或已应用策略；如不使用策略，请先通过独立卸载入口移除 Agent。请在可还原的 Windows 快照中测试。

网站限制完全由本项目实现，不依赖 Veyon 商业 Add-ons。学生包只带签名公钥，教师签名私钥保留在当前 Windows 用户证书库；学生 SYSTEM 代理验证签名、校区和递增版本后写机器策略。代理在发现已有 URLBlocklist/URLAllowlist 组策略或本工具值遭到外部修改时拒绝覆盖。首次交付仍需通过可信渠道分发包；SHA-256 清单不证明包发布者身份。详细范围和实机验收见[教师端网站访问控制与角色隔离](教师端网站访问控制与角色隔离.md)。

Windows 修改操作要求手动以管理员身份启动整个 App，受限 UAC Worker 尚未实现。预检有效期五分钟，绑定当前表单、资料、账户事实及 SID；执行前重新核对。管理员新密码必须两次输入一致；学生初始密码可两处留空创建无密码账户，也可两次输入一致设置密码。填写的密码保留首尾空格，只通过 PowerShell 标准输入传递；密码不进入计划、命令行参数、运行日志或配置文件，执行结束后清空输入框。四个修改入口在首次 await 前取得进程内 `TaskLease` 和当前用户 ACL 的单实例命名管道租约，阻止其他 App 实例并发；双实例运行验收待完成。该管道只作互斥锁，不传送提权请求。公钥导入实际消费 `PackageResourceSnapshot` 副本，Windows 执行期间保持只读共享句柄以阻止副本改写／删除；安装器仍使用单独的缓存及信任校验，不属于该公钥快照。安装超时、崩溃恢复和 Worker 权限边界仍未完成，见复审 AR-02 及 P3-05。暂不用于生产机房部署。

0.4.31 全量自动检查 36 项、学生专项检查 6 项和本机只读预检属于历史验证；用户已报告在本机成功卸载 Agent。0.4.33 教师／学生角色 ZIP 已构建并通过内嵌安装器摘要校验，本轮没有运行自动检查或执行系统安装。新增的重复公钥重试和 Agent 单独安装/修复入口需在可恢复 Windows 环境验收；共享文件夹访问与只读权限、跨校区旧 Agent 残留、39174 释放、外部策略保护、策略推送及重启浏览器效果仍需覆盖。

## 资料格式与离线交付

固定 Veyon `4.11.2.0` x64 安装器嵌入 `VeyonCampus.Core.dll`。App 提取到当前用户的本地应用数据缓存，检查固定文件名、大小、SHA-256；Windows 还检查 Authenticode 和签名证书指纹。部署期间不下载安装器。

| 资料类型 | 读取规则 | 当前 App 的安装来源 |
| --- | --- | --- |
| legacy `campus.json` + `*-public.pem` | 支持 UTF-8 BOM；不读取 `admin.txt`；验证配置与 RSA 公钥 | App 内嵌固定安装器 |
| `schemaVersion=1` manifest | 校验公钥及清单内安装器的大小、摘要与路径 | 当前 UI 仍使用 App 内嵌安装器，不执行旧包任意 EXE |
| `schemaVersion=2` manifest | 当前生成格式；仅清单化公钥，不允许 `installer` 字段 | App 内嵌固定安装器 |
| `schemaVersion=3` manifest | 新格式；清单化 Veyon 公钥和网站策略验证公钥，不含私钥，不允许 `installer` 字段 | 安装学生 Veyon 与网站策略代理 |

同目录有 manifest 时优先读取 manifest，选择其中的 `campus.json` 不会绕过它。新 schemaVersion=3 包含 `<校区ID>-public.pem`、`website-policy-public.pem`、`campus.json`、`manifest.json` 和 `README.md`；不含 EXE、密码或教师私钥。旧 schemaVersion=1/2 包仍可用于 Veyon，不会安装网站策略代理。当前校区 ID 为 1–100 个非空字符，不允许首尾空格或控制字符；可使用中文，Veyon KeyId 会映射为稳定的 ASCII 标识。正式 ID／显示名分离仍待实现。

原有离线交付路径由 **完整 App 发布文件夹 + 对应校区配置包** 组成。需要减少逐台复制时，教师可通过 Windows 文件共享提供只读校区配置文件夹，学生从 StudentSetup 输入 UNC 路径读取。App ZIP 不含具体校区配置，配置包不含运行程序。只复制 EXE 不足以部署。

当前源码版本 0.4.33 已生成 `VeyonCampus.StudentSetup` 学生部署包和 `VeyonCampus.Teacher` 教师控制台包；Windows 文件共享读取、Agent 修复入口和浏览器刷新仍待实机验收。GitHub/Gitee 发布页自动上传尚未实现。课堂策略仍由教师端向已安装 Agent 直接推送，和 App 文件／首次配置读取分开。

公钥检查支持 RSA 2048–4096 位，拒绝私钥、假 PEM、重复／错误字段及路径越界等。摘要用于检测内容变化，不证明校区资料发布者身份，也不等于已建立执行期间不可替换的资源副本。

## 开发与检查

安装 .NET 10 SDK；`global.json` 指定 10.0.100 并允许 `latestFeature`，本轮实际使用 10.0.401。首次依赖还原需要网络，锁文件约束 NuGet 依赖；目标电脑运行自包含发布版无需 SDK。

在仓库根目录执行：

```powershell
$env:AVALONIA_TELEMETRY_OPTOUT='1'
$env:DOTNET_CLI_TELEMETRY_OPTOUT='1'
dotnet restore VeyonCampus.slnx --locked-mode
dotnet build VeyonCampus.slnx -c Release --no-restore
dotnet build src/VeyonCampus.App/VeyonCampus.App.csproj -c Release --no-restore -p:VeyonCampusRole=StudentSetup
dotnet build src/VeyonCampus.App/VeyonCampus.App.csproj -c Release --no-restore -p:VeyonCampusRole=TeacherConsole
dotnet run --project tests/VeyonCampus.Checks -c Release --no-build --no-restore
dotnet run --project src/VeyonCampus.App
```

未传 `VeyonCampusRole` 时默认为 `StudentSetup`；要预览教师控制台，可运行 `dotnet run --project src/VeyonCampus.App -p:VeyonCampusRole=TeacherConsole`。检查程序写入临时测试目录并读取平台状态，不运行真实部署。Windows GitHub Actions 配置已存在，远程运行结果未核实。本轮使用已有依赖的构建不等于干净检出或完全离线构建已验证。

## 打包与分发

从 Git 克隆后，可在 Windows x64 开发机上自行生成离线 ZIP。需要安装 .NET 10 SDK；首次还原依赖时通常需要互联网访问 NuGet 源。固定版 Veyon 安装器已随仓库跟踪，无需另行下载。

```powershell
git clone https://github.com/Ljc798/veyon-campus-deployment.git
cd veyon-campus-deployment
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-windows-offline.ps1
```

脚本会在 `artifacts` 下按 `-Role` 生成教师或学生 Windows x64 自包含目录和 ZIP。`/artifacts/` 被 `.gitignore` 排除，因此其他人克隆仓库时不会自动得到生成的 ZIP；他们需分别运行脚本构建。当前尚未选择正式发布平台或配置自动上传；同一发布页可列出这两份角色包，但不能托管真实校区配置、教师私钥、管理员密码或学生设备清单。GitHub/Gitee 等平台的最终选择、发布物签名与校区配置可信下发流程属于 P10，尚未实现。

脚本的 `-Role` 参数选择发布角色，默认 `StudentSetup`。当前项目版本会写入 ZIP 名称。脚本写入角色标记并检查对方角色程序集／Agent 未混入；学生包另含受清理逻辑保护的文件 manifest 和标记。两个角色均为 Windows x64 自包含 App，并从发布后的 Core 程序集重读安装器资源验证大小及 SHA-256。只有学生端后台 Agent 随 StudentSetup 发布；`.ico` 同时用作 Windows 应用图标和 Avalonia 窗口图标。两个角色不再引用应用内 HTTPS LAN 服务。

生成教师控制台 ZIP：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role TeacherConsole
```

生成学生部署 ZIP（默认角色，也可显式传入 `-Role StudentSetup`）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role StudentSetup
```

已有同名输出时默认拒绝。`-Clean` 用于本地重建时替换指定输出，已对外交付版本应递增版本并保留原包。可用 `-OutputDirectory`、`-ZipPath` 指定 artifacts 内的新位置。已还原同一依赖组合的 win-x64 资源后可用 `-SkipRestore`；开发机可离线重建的范围取决于依赖缓存。

解压后保留整个 StudentSetup 文件夹，在可恢复 Windows 测试机以管理员身份运行 `VeyonCampus.StudentSetup.exe`。可选择本地 schemaVersion=3 校区包，或按上面步骤从 Windows 共享路径读取。若 Veyon 公钥已经导入、Agent 安装失败，重新载入同一校区包后可选“安装/修复网站策略 Agent”；完整重试会先核对已有公钥指纹。教师在自己的电脑上运行 `VeyonCampus.Teacher.exe`。教师生成包前需已安装固定版本 Veyon；同一校区换用新的输出目录会复用完整密钥对，不应通过删除密钥解决输出路径冲突。0.4.33 新恢复流程、共享访问和浏览器效果尚待实机验收；学生程序首次获取仍须走受信发布渠道。

## 手工验收入口

先在可恢复测试环境验收，再扩大设备范围。完整编号与记录模板见 [测试清单](测试验收与发布清单.md)。

本轮必须人工验收的项目和记录表见[Windows 学生端自测验收单](Windows学生端黑白名单与后台代理自测验收单.md)。

1. 启动后核对 Veyon 状态显示和重新检测；只点一次“生成预览并检查环境”即可看到计划与只读检查两部分。未选操作或无效计划应报错；单选改名无需包，核对 3/99/100/150、0/151 及过长前缀；账户名和密码输入按所选操作显示，确认普通学生账户密码留空可执行、管理员名默认为 `Administrator`。
2. 有效包、无效包、取消选择、拖放与导航往返分别核对；清除包保留其他输入，重置表单才恢复全表默认。
3. 资料或操作表单变更后旧计划和预检失效；缺包、未提升权限、报告过期、账户 SID 变化及密码两次输入不一致均不得开始修改。
4. 分别测试四项单独执行及代表性组合；账户创建验证普通 Users 组身份，改密验证目标本地管理员 SID。重复点击、执行期间输入锁定、失败和待重启均需核对；不能用模拟协调器结果替代入口测试。
5. 两次同校区输出的公钥应一致；检查无私钥混入、残缺密钥停止、生成中断后保留已创建事实；已有安装不可被教师入口覆盖。
6. 一教师一学生完成离线安装、公钥核对、服务、拔除介质、双方重启和日常教师身份连接，并保留失败恢复证据。
