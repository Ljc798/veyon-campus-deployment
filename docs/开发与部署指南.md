# 开发、部署与排障指南

本文只保留当前操作步骤。版本、验收范围和待办见[任务主表](开发路线与任务清单.md)，系统组件边界见[架构与实施边界](veyon_architecture_summary.md)。Teacher/Student Inno Setup EXE 已通过 Windows CI 的构建和安装/卸载 smoke；该记录来自早期候选版本，不能代替当前 0.4.54 的 Windows 实机验收。ZIP 仅作为可选开发归档。

## 教师与学生部署

StudentSetup 首次配置、四项操作组合规则、错误恢复和教师端迁移边界见[学生端首次部署与恢复指南](学生端首次部署与恢复指南.md)。

1. 在可恢复 Windows 测试机运行对应角色的 Setup EXE 安装；从安装后的开始菜单入口启动教师控制台或 StudentSetup。旧 ZIP 仅适用于历史构建，不是当前目标分发方式。
2. 教师初始化固定版本 Veyon、校区密钥与配置包。已有完整密钥应复用，不通过删钥解决输出目录或重试问题。
3. `veyon-api` 已在线提供校区包与发行接口；配置包 schema v6 与 release v2/v3 迁移已部署到预备份的共享体验环境。schema v3 合成包线上发布、下载、撤回及对象清理 E2E 已通过；v5/v6 线上写入验收状态见[项目任务主表 P13-05](开发路线与任务清单.md)及[10 月 8 日续作记录](records/2026-10/续作核查记录-20261008.md)。接口和权限细节见[CloudBase API 运行手册](CloudBase%20API运行与验收.md)。离线时由管理员将校区包复制到学生机本机磁盘后导入。
4. 明确选择 Veyon、改名、创建账户或指定管理员改密，先预览和检查，再执行。只执行已选择操作；待重启、失败和状态未知按页面结果处理。
5. 相同公钥且 Agent 安装失败时先验证指纹，可使用独立“安装/修复网站策略 Agent”入口；同名异指纹不覆盖，不要求先删除 Veyon 公钥。
6. 读回 Veyon 与 Agent，教师连接测试后实际检查浏览器黑白名单、解除和到期行为。不要仅凭 Agent 回执判断浏览器生效。

## 配置包来源

Teacher 当前代码生成 schema v2–v6 校区包，StudentSetup 读取 schema v1–v6；CloudBase 共享环境已部署 schema v6，支持线上 v3–v6 包。StudentSetup 搜索并下载后校验 manifest、版本兼容范围和载荷摘要；无网络时管理员可从本机磁盘导入。Teacher 发布无需 CloudBase Auth 登录，需提交校区名称、教师姓名和手机号后四位；服务端不会将手机号原文持久保存。学生包导入不支持 UNC 或映射网络盘路径。

当前线上迁移账本共 18 条，最新 `20261008100000`；v6 迁移已应用。TeacherConsole/StudentSetup 的 release API v1/v2/v3 已部署，latest 都返回 `release: null`。schema v3 合成包线上 E2E 已通过；schema v5/v6 线上 E2E 已获授权，尚未关闭。部署前备份和最新 runner 状态见[10 月 8 日续作记录](records/2026-10/续作核查记录-20261008.md)。不要把健康检查通过等同于完整包发布/下载验收。

## 开发与检查

安装 .NET 10 SDK；`global.json` 指定 10.0.100 并允许 `latestFeature`，历史构建记录使用 10.0.401，实际版本以本次构建记录为准。首次依赖还原需要网络，锁文件约束 NuGet 依赖；目标电脑运行自包含发布版无需 SDK。

在仓库根目录统一执行：

```powershell
.\scripts\check-app.ps1
dotnet run --project src/VeyonCampus.App
```

`check-app.ps1` 会按锁文件还原、构建完整解决方案、额外构建 TeacherConsole 角色并运行现有检查集；它不会在本轮自动执行系统部署操作。Windows x64 打包冒烟可另外运行 `.\scripts\check-app.ps1 -WindowsPackageSmoke`，这会生成两种角色 Setup EXE 和用于诊断的可选 ZIP，不会安装或更改 Windows 系统。首次依赖还原需要网络。

采集 Windows 10/11 兼容矩阵摘要：

```powershell
.\scripts\collect-windows-test-environment.ps1 -OutputPath .\artifacts\test-matrix\windows-test-environment.json
```

采集器始终非交互，不会等待控制台输入；人工确认的恢复基线和 MDM 状态通过参数传入，省略时记为 `unknown`。例如 `-RestoreEnvironmentStatus confirmed -MdmEnrollmentStatus not-enrolled`。它不会探测或修改还原软件，也不采集设备、租户、账户标识。schema v2 摘要还含 EditionID、SKU、DisplayVersion、build/UBR、报告的 hotfix ID、AppIDSvc 读回，以及本机/组策略 AppLocker 规则集合计数和模式。`Get-AppLockerPolicy` 不涵盖 AppLocker CSP/MDM，所以 MDM 状态由现场人员确认；`KB5024351` 未出现在 QuickFixEngineering 列表中也不等同于已证明未安装。请在 Windows 10 和 Windows 11 测试机各运行一次，未知的恢复及 MDM 状态保持 `unknown`。

未传 `VeyonCampusRole` 时默认为 `StudentSetup`；要预览教师控制台，可运行 `dotnet run --project src/VeyonCampus.App -p:VeyonCampusRole=TeacherConsole`。检查程序写入临时测试目录并读取平台状态，不运行真实部署。Windows GitHub Actions 会调用同一检查入口；远程结果以 Actions 实际记录为准。脚本和锁文件齐备不等于干净构建、Windows 运行或系统部署已通过。

## 打包与分发

从 Git 克隆后，可在 Windows x64 开发机上生成 Teacher/Student 独立 Inno Setup 安装器 EXE。需要 .NET 10 SDK 和 Inno Setup 6；首次还原依赖时通常需要访问 NuGet 源。固定版 Veyon 安装器已随仓库跟踪，无需另行下载。

```powershell
git clone https://github.com/Ljc798/veyon-campus-deployment.git
cd veyon-campus-deployment
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-windows-offline.ps1
```

脚本会在 `artifacts` 下生成教师或学生 Windows x64 自包含目录及对应 Setup EXE；仅显式传入 `-ZipPath` 时才额外生成 ZIP。`/artifacts/` 被 `.gitignore` 排除，因此其他人克隆仓库时需自行运行脚本构建。`.github/workflows/windows-installers.yml` 已配置稳定 tag 发布：构建 Teacher/Student 安装器，创建 GitHub/Gitee 同版 Release 和 SHA256SUMS，并同步源码 tag；附件验证完成后签名并向 CloudBase 发布版本元数据。安装器不上传 CloudBase 私有桶。当前还缺 `production-release` Environment、固定 Developer Release 公私钥、CloudBase 发布凭据和 Gitee 仓库／令牌配置，因此尚无生产签名版本；不得创建生产发布 tag。正式密钥的本地生成与 GitHub secret 名称见[发布依赖与第三方许可清单](发布依赖与第三方许可清单.md)。安装器本身尚未配置 Authenticode 签名；不得把发布私钥、真实校区配置、管理员密码或学生设备清单放入公开工件。依赖和自包含运行库更新流程见[依赖与运行库补丁维护](依赖与运行库补丁维护.md)。

脚本的 `-Role` 参数选择发布角色，默认 `StudentSetup`；输出文件名带项目版本、角色和架构。脚本写入角色标记并检查对方角色程序集／Agent 未混入；学生安装器包含 StudentSetup 及独立后台 Agent。安装器把程序放入 Program Files，分别提供开始菜单入口和可选桌面快捷方式。两个角色均为 Windows x64 自包含 App，并从发布后的 Core 程序集重读 Veyon 安装器资源验证大小及 SHA-256；`.ico` 同时用作 Windows 应用图标和 Avalonia 窗口图标。

生成教师控制台 Setup EXE：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role TeacherConsole
```

生成学生部署 Setup EXE（默认角色，也可显式传入 `-Role StudentSetup`）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\package-windows-offline.ps1 `
  -Role StudentSetup
```

已有同名输出时默认拒绝。`-Clean` 用于本地重建时替换指定输出，已对外交付版本应递增版本并保留原工件。可用 `-OutputDirectory`、`-InstallerPath` 指定 `artifacts` 内的新位置；仅在需要归档/内部调试时传 `-ZipPath`。`-ReleasePublicKeyPath`（或环境变量 `VEYONCAMPUS_RELEASE_PUBLIC_KEY_PATH`）可将 Developer Release 公钥固定进客户端；缺少公钥时，签名更新功能会失败关闭。已还原同一依赖组合的 win-x64 资源后可用 `-SkipRestore`；开发机可离线重建的范围取决于依赖缓存。

在可恢复 Windows 测试机上以管理员身份运行对应 Setup EXE。安装器提供标准卸载入口；StudentSetup 保留为管理员维护 GUI，学生 Agent 按部署计划单独安装。学生当前代码可从 CloudBase 目录搜索或从本机磁盘导入 schema v1–v6 校区包；共享线上目录已部署 v6 支持。教师在自己的电脑上运行 TeacherConsole；生成包前须已安装固定 Veyon 基线。相同校区换用新的输出目录会复用完整密钥对，不要通过删除密钥解决路径问题。安装/卸载、Wizard、离线导入和浏览器效果仍待 Windows 实机验收。

Teacher 自更新与 Teacher 到 Student 的局域网更新代码已实现。安装器内嵌 Developer Release 公钥后，客户端验证签名清单和包摘要；Student Agent 还验证教师的校区签名更新命令以及候选版本的活动策略能力。Teacher 端的学生状态与更新结果按目标固定的 Agent RSA 身份密钥验签，旧版纯 HTTP 回执不能标记成功。Teacher 临时文件服务使用 TCP 39175（仅 LocalSubnet），Agent 控制使用 TCP 39174。更新助手切换失败时保留并恢复旧组件。当前测试安装包未嵌入生产密钥，线上也没有签名 release；故更新仍不可供用户使用。正式密钥、发布凭据和实机安装/回滚验收是发行门槛。

Apple Silicon 开发预览：

```sh
dotnet publish src/VeyonCampus.App -c Release -r osx-arm64 --self-contained true -o artifacts/macos-arm64/VeyonCampus.app/Contents/MacOS
cp packaging/macos/Info.plist artifacts/macos-arm64/VeyonCampus.app/Contents/Info.plist
```

该 Mac 产物仅用于本地预览，未进行发行签名或公证。历史 Windows x64 ZIP 的生成记录不覆盖本轮 Inno Setup EXE；新安装器、SYSTEM 任务、教师界面与浏览器规则仍需在 Windows 实机完成运行验收。


## Agent 排障顺序

先保留现场和版本信息，不删除目录、URL ACL 或策略，不授予 Everyone 完全控制。

| 症状 | 优先检查 | 判定边界 |
| --- | --- | --- |
| Agent 未安装或无法启动 | 安装步骤结果、真实文件路径、DLL 与目录 DACL、SYSTEM 任务身份和启动参数 | 旧 icacls 成功码曾伴随空文件 DACL；必须读回文件权限 |
| 教师推送超时 | Agent 进程、39174 监听、目标地址、规则的程序/端口/LocalSubnet 和网络配置 | 不沿用旧 39173/HTTP URL ACL 假设处理当前 TCP 监听 |
| 重复公钥阻断 | KeyId、公钥导出指纹与当前包 | 指纹一致才跳过；不同或无法确认则停止 |
| 策略回执成功但浏览器无效 | Edge、Chrome、Firefox 策略页、实际访问、浏览器重启、其他管理策略 | 回执与浏览器效果分别记录 |
| 卸载残留或跨校区状态 | 实际任务、运行路径、策略归属记录和当前校区 | 仅删除可确认属于本工具的内容 |

在学生机管理员 PowerShell 可先做只读检查：

```powershell
Get-NetTCPConnection -LocalPort 39174 -State Listen -ErrorAction SilentlyContinue
Get-ScheduledTask | Where-Object TaskName -Like '*VeyonCampus*' | Select-Object TaskName,State,Actions,Principal
Get-Service -Name VeyonService -ErrorAction SilentlyContinue
```

任务查询不等于任务 DACL 检查。需要权限与历史故障细节时查[原始排障步骤](archive/2026-09-29/学生机策略代理故障检查步骤.md)和[启动失败记录](archive/2026-09-29/学生虚拟机网站Agent启动失败排查记录.md)；其中硬编码旧版本路径须按现场修正。

完整验收统一使用[测试验收与发布清单](测试验收与发布清单.md)。不再单独维护一份学生自测任务表。
