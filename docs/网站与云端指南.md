## 2. 本地网站开发

在 website 目录运行 npm ci，按 cloudbase.env.example 创建 .env.local，再运行 npm run dev；构建使用 npm run build，预览使用 npm run preview，输出为 dist。

浏览器配置只含环境、地域、publishable key 和 VITE_API_BASE_PATH；不得写入 service API key、数据库密码或 HMAC 密钥。不要覆盖已有 .env.local。Auth/RDB 需要配置允许来源；原记录中本地安全域名受到套餐限制，须复核后才能声称本地登录闭环通过。

公开路由为 /、/product、/about、/docs、/contact、/privacy；/publish 为已有实验发布入口；/admin 及其子路由为管理工作区，不出现在公开导航。隐藏入口不构成权限控制。管理页面读取真实数据，空表展示空状态。

前端约束见[网站开发规范](../website/docs/开发规范.md)。数据库表、RPC、索引与 RLS 详见[数据库结构](../website/docs/PostgreSQL数据库设计.md)，实际 SQL 以 cloudbase/migrations 为准。

## 3. API 与部署

服务源码为 src/VeyonCampus.Telemetry.Server；根 Dockerfile 和 cloudbaserc.json 配置 HTTP CustomImage 函数 veyon-api，地域 ap-shanghai，Linux amd64，监听 0.0.0.0:9000，网关根路径承接 /health 与 /v1/...。

服务端配置：CloudBase__EnvId、CloudBase__ApiKey、Telemetry__DailyHashKey；镜像仓库凭据与服务密钥只在受控环境保存。已有 HMAC 数据写入后保持根密钥稳定，不把旧“空表”检查当作现在仍可换钥的依据。

准备完整部署预检、密钥配置、同地域镜像拉取授权与回退方案后，现有文档记录的部署命令为：

```powershell
tcb fn deploy veyon-api --env-id veyon-control-d3gs8hmuyd09c00a7 --httpFn --deployMode image
```

该命令是操作参考，本次整合未执行。发布前复核 CLI、配置和授权，不因文档中存在命令直接操作生产。

部署验收分别确认 /health、网关路径、CORS、服务端数据库 RPC 权限、Auth 管理授权和合成数据读写。200 健康响应不等于数据库或权限验收通过。发布静态网站时保护已有认证资源，不清空托管根目录。

## 4. 现有接口和隐私

| 功能 | 当前契约 | 边界 |
| --- | --- | --- |
| 健康 | GET /health | 仅进程健康 |
| 旧 Student 心跳 | POST /v1/heartbeat；installationId、applicationVersion、deploymentId | 默认关闭；UTC+8 去重、HMAC，不存原始安装标识 |
| 配置包 | /v1/deployment-packages 及发布/下载/撤回接口 | 精确方法与字段以源码 openapi/deployment-packages.yaml 为准 |
| 管理数据 | CloudBase Auth + PostgreSQL RLS | 浏览器不能自行提升 admin_profiles 角色 |

现有配置包实验代码包含教师姓名与手机号后四位下载校验。它不是强身份认证，不能替代校区密钥或开发者发布签名；日志不得泄露校验值。ZIP 限 64 KiB、单文件限 16 KiB、请求体限 128 KiB 的历史契约需与源码核对，不能用于分发大型安装器。

旧心跳按 UTC+8 日期、版本和 packageId 持久化成功状态，失败有重试；服务器通过部署包映射校区，旧设备日活统计不能冒充完整资产清单。按日摘要目标保留 90 天、汇总 400 天；不上传学生姓名、浏览历史、屏幕或文件内容。HTTP 基础设施日志可能接收源 IP，需另核对留存。

## 5. 向最小云端迁移

1. 先定义版本接口与开发者签名发布清单，支撑 Teacher 更新；接口路径和版本前缀统一后再实现。
2. Teacher heartbeat 按校区授权、默认关闭，区分配置数、响应数和版本分布；明确一天时区和多个 Teacher 的冲突规则。
3. 新 Agent 停止逐台公网心跳；盘点旧包后定义兼容期与旧端点退役，避免旧客户端持续重试。
4. 数据库迁移只新增，不改写已应用文件；旧日活与新校区快照分开呈现。Campus ID、数据库 ID 和 packageId 明确映射，不仅按名称关联。
5. 前置限流、请求大小限制和授权；大文件走对象存储或 Teacher LAN 文件服务，不穿过云函数传完整安装器。
6. 管理后台首次打开/手动刷新，显示最后上报时间；Teacher 关闭时不承诺日报持续更新。
