在 website 目录运行 npm ci，按 cloudbase.env.example 创建 .env.local，再运行 npm run dev；构建使用 npm run build，预览使用 npm run preview，输出为 dist。

2026-10-02 最新生产构建已部署到 `https://veyon-control-d3gs8hmuyd09c00a7-1348081197.tcloudbaseapp.com/`，CLI `--safe --verify` 显示 5 个文件与 `website/dist` 一致；保留原静态根目录中的认证资源和旧文件，未执行 prune。CloudBase `IndexDocument` 与 `ErrorDocument` 均为 `index.html`，并已加 404 → `index.html` 路由规则。默认域名响应仍带 `Content-Disposition: attachment`，浏览器直接导航显示 CloudBase 开发提示，因此上传校验不能替代公开页面或管理登录验收。Privacy 路由已从最新构建移除。官方限制见[默认域名访问说明](https://docs.cloudbase.net/service/alias)。

前端约束见[网站开发规范](../website/docs/开发规范.md)。数据库表、RPC、索引与 RLS 详见[数据库结构](../website/docs/PostgreSQL数据库设计.md)，实际 SQL 以 cloudbase/migrations 为准。

## 3. API 与部署

API 的对外部署包为 `cloudfunctions/veyon-api` 中的 Node.js 20.19 HTTP 云函数；根目录 `cloudbaserc.json` 配置 ZIP 代码部署，入口监听 `0.0.0.0:9000`，`gatewayPath: "/"`。2026-10-02 已将管理员表路由代码更新部署，函数为 Active、运行时为 Nodejs20.19。`GET /health` 返回 HTTP 200 `{"status":"ready"}`；未登录请求 `/v1/admin/database/admin_profiles` 返回 HTTP 401，确认新处理器已生效；latest-release 仍返回 `release: null`。默认 HTTP API 网关 `/` 路由指向公开的 `veyon-api`（auth=false、启用、目标总限频 100 QPS），OPA 逐路径允许，管理员数据处理器还会验证有效 CloudBase Auth 令牌及 owner/admin 角色。网站前端和 Teacher/Student 客户端调用 HTTP 网关 URL；后端不部署到 CloudRun/云托管。`src/VeyonCampus.Telemetry.Server` 的 .NET 实现仍保留作桌面 API 对照；修改接口行为时要同步核对 Node 云函数和 OpenAPI。

服务端配置：`CloudBase__EnvId`、`CloudBase__ApiKey`、`Telemetry__DailyHashKey`。服务密钥只保存在云函数服务端环境变量。网站静态托管环境和浏览器构建不得包含这些密钥。现有密钥值保存在被 Git 忽略的根目录 `.env.cloudbase.local`，部署脚本会在本机载入；网页 `.env.local` 只保留 Vite 浏览器变量。已有 HMAC 数据写入后保持根密钥稳定，不轮换密钥。

## 4. 现有接口和隐私

| 功能 | 当前契约 | 边界 |
| --- | --- | --- |
| 健康 | GET /health | 仅进程健康 |
| Student 心跳 | POST /v1/heartbeat；installationId、applicationVersion、deploymentId | API 已部署；UTC+8 去重、HMAC，不存原始安装标识；尚未做云端写入验收 |
| 配置包 | 教师免登录上传；学生以教师手机号后四位下载；管理员登录后撤回 | 精确方法与字段以源码 openapi/deployment-packages.yaml 为准 |
| 管理数据 | CloudBase Auth + PostgreSQL RLS | 浏览器不能自行提升 admin_profiles 角色 |

当前 Teacher HTTP 发布不需要登录、Bearer token、校区 ID 或预先授权：教师提交 `campusName`、`publisherName`、`teacherPhoneLast4` 和 schema v3 包。若校区名唯一匹配 active 校区，数据库会关联该记录；否则保留教师输入的校区名供搜索。教师姓名仅写入私有元数据，学生目录不返回；手机号原文不保存，只保存 keyed HMAC 指纹，用于学生下载校验。该四位后缀不是教师身份凭据。2026-10-02 起，成功发布响应不含 `publisherName`。此前一次成功响应曾把该字段带入 CloudBase 函数执行日志；既有日志没有在本次部署中删除，应按现行平台日志访问和保留规则处理，也不要在问题记录或截图中复制该字段。包限制为 ZIP 总计不超过 64 KiB、单文件不超过 16 KiB、multipart 请求体不超过 128 KiB；不能用于分发大型安装器。HTTP API 路由总限频目标为 100 QPS，不按共享公网出口 IP 限流。发布、撤回、下载响应均设置 `Cache-Control: no-store`。

下载错误码限错现由 PostgreSQL `get_deployment_package_download_with_rate_limit` RPC 原子共享：同一包与来源在 15 分钟内连续失败 10 次后封锁 15 分钟，正确输入清零；表只保存来源 HMAC，不保存原始 IP。迁移和函数代码已部署，本地 Node 合约测试覆盖规则，但真实网关来源地址和跨实例并发行为仍待线上验收。HTTP API 根路由总限频目标为 100 QPS（环境上限为 500 QPS）；暂未设置单客户端 IP 限频，因为同一校区的许多学生电脑可能共用一个公网出口。

桌面端默认连接当前 CloudBase 国内环境；可用 `VEYONCAMPUS_DEPLOYMENT_PACKAGES_API_BASE_URL` 覆盖 HTTP 网关地址。教师发布不需要教师账号；网站 `/admin` 管理工作区仍使用管理员 Auth 会话，与 Teacher App 发布分开。

### 教师发布与学生下载

1. Teacher App 生成 schema v3 校区配置包。
2. 填写学生搜索要用的校区名称、教师姓名和教师手机号后四位，然后发布。无需教师登录、创建账号或让管理员预先配置授权。
3. 学生在 StudentSetup 搜索校区或电脑名前缀，选择发布包后输入该教师手机号后四位。下载后 App 再校验 ZIP、manifest 和文件摘要。
4. 如需撤回匿名发布的包，由网站 owner/admin 执行撤回；教师姓名和四位数字都不能用于登录或撤回。

旧心跳按 UTC+8 日期、版本和 packageId 持久化成功状态，失败有重试；服务器通过部署包映射校区，旧设备日活统计不能冒充完整资产清单。按日摘要目标保留 90 天、汇总 400 天；不上传学生姓名、浏览历史、屏幕或文件内容。HTTP 基础设施日志可能接收源 IP，需另核对留存。
