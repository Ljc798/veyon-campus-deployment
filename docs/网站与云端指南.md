# 网站与云端指南

更新日期：2026-10-08。本文说明网站、CloudBase API 和桌面客户端各自的职责，以及常用开发/部署入口。精确接口、权限、迁移和验收命令以[CloudBase API 运行与验收](CloudBase%20API运行与验收.md)为准；当前部署状态由[任务主表](开发路线与任务清单.md)维护。

## 1. 组件职责

| 部分 | 职责 | 边界 |
| --- | --- | --- |
| 公开网站 | 发布产品、文档和联系信息；托管静态构建产物 | 只放公开内容，不存服务端密钥，不提供教师配置包上传表单 |
| `/admin` 管理区 | CloudBase Auth 登录后的管理员数据与版本发布入口 | 接口另行验证活动 Auth 会话及 owner/admin 角色；前端隐藏入口不是权限控制 |
| `veyon-api` | Node.js 20.19 HTTP 云函数，处理校区包、发行版本、心跳和管理 API | 经 HTTPS 网关访问 PostgreSQL REST/RPC 与私有 Storage；不运行在旧 CloudRun/Cloud Run 服务上 |
| TeacherConsole / StudentSetup | Teacher 发布校区包；Student 搜索、下载并本地验证；管理发行版本 | 桌面客户端通过 HTTP API 访问，不直接连接 PostgreSQL |
| 教师手机控制 | 手机在同一校园 LAN 连接教师控制台，读取状态并开关策略 | 不经过网站、CloudBase 或公网中继；见[手机控制指南](手机控制使用指南.md) |

## 3. 网站本地开发

在仓库根目录执行：

```sh
npm ci --prefix website
npm run dev --prefix website
npm run build --prefix website
npm run preview --prefix website
```

开发环境文件按 `website/cloudbase.env.example` 创建 `website/.env.local`。浏览器构建只允许公开环境 ID、区域、publishable key 和完整 API 网关基址；禁止写入 CloudBase service API key、数据库口令或 HMAC 根密钥。不要覆盖已有本地环境文件。

静态网站托管只发布 `website/dist`。生产构建部署前确认 `VITE_API_BASE_PATH` 指向 HTTPS API 网关完整地址；相对 `/api` 会打到静态托管并可能收到 SPA HTML，不能作为 API 代理。部署命令及 `--safe --verify` 操作以 CloudBase API 运行手册为准。

网站使用 CloudBase 默认托管域名。浏览器首次导航可能显示 CloudBase 访问提示页，用户确认后才能进入首页或 `/admin`。当前没有自定义域名配置；域名套餐和提示页行为的官方说明链接保存在 CloudBase 运行手册中。

## 4. 数据与权限流

- Teacher 发布 schema v3–v6 校区包时提交校区名称、教师姓名、手机号后四位和规范包；当前线上服务支持 v3–v6。教师不需要 CloudBase Auth 登录。服务端校验字段、文件集合、路径、大小和摘要，并把 ZIP 存入私有 Storage。手机号原文不持久化，只保存 keyed HMAC 指纹；教师姓名属于私有发布元数据。
- Student 搜索公开目录后，用 API 要求的后四位校验值请求下载；下载文件仍须在本机验证 manifest 和每个载荷摘要。管理员撤回会检查包权限并删除对应私有对象。
- `/admin` 通过 CloudBase Auth 登录；服务端每次管理请求验证活动会话及 owner/admin 角色。未登录或无权请求应拒绝。
- Teacher 心跳按 UTC+8 日期去重，由已发布 `packageId` 关联校区。它报告应用/配置统计，不代表逐台 Student 实际版本或逐台策略状态。
- Teacher 向 Student Agent 推送的网站、应用和系统策略走校园 LAN 签名通道，不经公开目录或网站转发。
- API service key 与 heartbeat HMAC 根密钥只注入云函数服务端环境；不提交 `.env.cloudbase.local`、不放到静态前端，也不写入公开包。

PostgreSQL 表/RPC/RLS 定义见[网站数据库结构](../website/docs/PostgreSQL数据库设计.md)，自动 OpenAPI 契约见 `cloudfunctions/veyon-api/openapi/deployment-packages.yaml`。版本化配置包及策略信任关系见[架构与实施边界](veyon_architecture_summary.md)。

## 5. 部署和验收入口

- 静态网站构建、部署、身份来源和默认域名行为：见[CloudBase API 运行与验收](CloudBase%20API运行与验收.md)相应小节。
- 云函数、迁移、OPA 和网关部署：从仓库脚本 `scripts/deploy-cloudbase-api.sh` 和 runbook 开始；更新 service API key 前须按部署脚本要求完成轮换确认。
- 本地 Node/API 合约检查：`npm run check --prefix cloudfunctions/veyon-api`。
- Schema v5/v6 合成写入 E2E 已获授权，但运行时需要负责人在本机完成 CloudBase Auth 登录。只在本机隐藏密码输入框中输入凭据；不要把密码、token 或密钥发送到聊天。runner 默认测试 v5；可显式传 `--schema-version 6` 验收 v6。runner 会在首个写入前检查撤回权限并在结束后清理合成数据。
- 公开发行前需解决项目/依赖许可审查，配置生产 Developer Release 公钥与受保护私钥、CloudBase/Gitee 凭据，并完成签名版本发布；具体阻断见[第三方许可与发布清单](发布依赖与第三方许可清单.md)。

本指南描述代码/部署路径；线上 `release: null`、尚待完成的 schema v5/v6 写入测试，以及 Windows 下载/导入、教师心跳写入和网关来源限错行为均按实际记录逐项判断，不由 HTTP 健康检查推断通过。
