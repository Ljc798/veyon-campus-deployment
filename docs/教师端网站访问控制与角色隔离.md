# 教师端网站访问控制与角色隔离

更新日期：2026-09-26。此功能由本项目自研，免费，不继承、不调用、不打包 Veyon 商业 Add-ons。代码已经接入教师名单编辑与推送、学生端签名验收和 Edge/Chrome 机器策略写入；真实 Windows 学生机部署仍需按本文验收。

## 当前功能流程

1. 教师在 Windows 教师端生成新的学生校区配置包。程序在当前 Windows 用户的个人证书库创建或复用校区网站策略 RSA 签名证书；私钥不写入配置包。配置包 schemaVersion=3，携带教师公钥、网站策略公钥、校区 ID 和 SHA-256 清单。
2. 学生端载入新包，在“配置并部署”中安装 Veyon 学生组件、配置 Veyon 校区公钥，再安装网站策略代理。旧版 schemaVersion=1/2 包可以继续配置 Veyon，但没有网站策略公钥，代理会跳过。
3. 学生代理以 SYSTEM 身份运行于开机计划任务，程序和配置分别放在 Program Files、ProgramData；普通用户对代理配置只读。学生端只拿到教师网站策略公钥。
4. 教师在“学生网站黑名单 / 白名单”填写校区 ID、学生电脑名/IP 和网站域名，选择模式后推送。教师端使用当前用户证书库私钥签名；学生代理验签、核对校区和递增版本后应用策略，并给教师端返回逐机成功或失败。

单次最多推送到 150 台学生机；域名条目最多 1000 个，自动去重、转为小写 ASCII/IDN punycode。输入裸域名或根路径 HTTP/HTTPS 地址；不支持 IP、端口、URL 路径、通配符或任意协议。名单按浏览器 URL 模式匹配网站域名。

## 浏览器策略与冲突处理

- Edge 使用 `HKLM\SOFTWARE\Policies\Microsoft\Edge\URLBlocklist` 和 `URLAllowlist` 列表策略子项；Chrome 使用 `HKLM\SOFTWARE\Policies\Google\Chrome\URLBlocklist` 和 `URLAllowlist`。每项以子项下的 `1`、`2` 等 `REG_SZ` 值写入。
- 黑名单将域名放入 `URLBlocklist`。白名单将 `*` 放入 `URLBlocklist`，允许域名放入 `URLAllowlist`；允许项作为阻止规则的例外。
- 停用时，代理只删除与上次记录完全相同、且确认由本工具写入的策略值。首次应用若机器已有这两个浏览器策略之一，或之后检测到管理员/组策略改变本工具值，代理拒绝接管、覆盖或清除。
- 教师和学生代理之间用 RSA-PSS/SHA-256 签名，不依赖网络传输保密。名单内容通过 HTTP 在受限局域网传输，不含口令或私钥。防火墙规则只允许 Domain/Private 网络的 LocalSubnet 访问 TCP 39173。

官方浏览器文档确认 Edge 的 `URLAllowlist` 可作为 `URLBlocklist` 例外，并列出 Windows 注册表路径与 1000 条上限；Chrome 文档确认 `URLBlocklist` 的编号字符串列表及 Windows 路径：[Microsoft Edge URLAllowlist](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/urlallowlist)、[Edge URL 过滤格式](https://learn.microsoft.com/en-us/deployedge/edge-learnmmore-url-list-filter-format)、[Google Chrome URLBlocklist（简体中文）](https://chromeenterprise.google/intl/zh_cn/policies/url-blocklist/)。本项目实现须在受支持的 Edge/Chrome 版本上读回并实测，不以文档描述代替现场验收。

## 角色与密钥隔离

| 项目 | 学生端 | 教师端 |
| --- | --- | --- |
| Veyon 组件 | Veyon Service/客户端；安装参数带 `/NoMaster` | 安装含 Veyon Master 的组件 |
| Veyon 认证密钥 | 只导入校区公钥 | 教师私钥由 Veyon 管理 |
| 网站策略密钥 | 只读网站策略公钥；SYSTEM 代理验签并改浏览器机器策略 | 私钥仅在当前 Windows 用户个人证书库；负责签名和推送 |
| 控制能力 | 无法签发有效策略；不安装 Master | 可向学生机发送本校区的新版本策略 |

学生和教师页面在同一个 VeyonCampus 程序中，页面切换本身不构成安全边界。隔离依赖 Windows 用户证书库中的教师私钥、学生包只含公钥、学生端 SYSTEM 代理配置 ACL，以及 Veyon 安装组件按角色分开。学生包清单的 SHA-256 用于发现意外损坏，不提供发行者身份认证；首次部署包仍须经学校可信渠道交付。若教师 Windows 用户证书库丢失或用户配置文件更换，学生端原有信任公钥不会自动轮换，需要重新分发配置包；当前版本没有在线密钥轮换流程。

代理目前按 Edge/Chrome 浏览器策略限制网页导航，不过滤 Firefox、便携浏览器、其他应用或任意网络流量。已有组策略、网络策略或教师机与学生机不在可达的本地子网时，不能假定推送或限制有效。
