# 教师端课堂快捷管控使用指南

本指南说明桌面教师端的课堂网站限制、限时键鼠锁定、恢复网站访问和解除快捷管控。操作按本堂课的电脑范围逐台执行；当前课堂快捷卡片不能在卡片内单独勾选部分电脑。

## 开始一堂课

1. 在侧栏打开“课堂控制”，检查当前地点、电脑数量和学生名单。设备身份、地址或名单有疑问时，先到“配置与部署 → 地点与学生名单”核对。
2. 确认学生电脑已在线、Agent 身份已核对，再点页面顶部的“开始课堂”。课堂状态会一直保持，直到教师手动结束；快捷管控空闲或自动解除不会关闭课堂。
3. 核对“课堂快捷管控”显示的目标数量与课堂范围。操作前教师端会再次读取状态并显示确认窗口。

## 启用当前网站名单

1. 先到“策略与预设”核对当前校区保存的网站名单和黑白名单模式。名单修改会保存在教师电脑；快捷操作使用当前保存内容。
2. 回到“课堂控制”，点“启用网站限制”并确认。系统为本堂课目标逐台检查现有策略归属和设备身份，再发送策略并读回结果。
3. 快捷网站策略默认一小时到期。界面显示逐台已核验、失败或待核对；签名读回代表 Agent 报告状态，不单独证明浏览器实际拦截，必要时在测试电脑上打开目标网站确认。

## 限时锁定键盘和鼠标

1. 先在可恢复的测试电脑上操作，并确认学生屏幕、Veyon 监看和 Windows 安全恢复途径可用。
2. 点“限时锁定键鼠”，仔细核对确认窗口中的课堂目标后再确认。
3. TeacherConsole 会续租短期锁定。按实现设计，TeacherConsole 关闭或失联后租约最多维持 20 秒；这项恢复时序必须在目标 Windows 版本上实测后才能依赖。
4. 点“解除课堂管控”并逐台确认输入已恢复。锁定状态未知或 Agent 回执缺失时，不要把它当作已解锁。

## 切换与解除

- 网站限制和键鼠锁定分别执行、分别核验，也可以同时启用。网站操作只读取网站策略状态；InputGuard 无响应不会阻止网站操作。键鼠操作只读取 Guard 状态，网站状态不会阻止键鼠操作。
- “恢复全班网站访问”会逐台读取学生电脑当前签名网站状态，再用版本比较写入“停用”策略和空黑名单/白名单，最后重新读取确认。每台电脑可以有不同的策略模式、版本和名单；系统不会要求它们一致。学生 Agent 需为 0.4.50 或更新版本。设备离线、身份未核对或版本不支持时不会写入，结果会标为待核对；恢复连接或更新后由教师重试。
- 此操作清除当前课堂目标电脑的生效网站策略，不删除教师电脑上保存的名单，也不改变键鼠锁定、应用限制或系统限制。后续要重新限制网站时，可继续使用教师保存的网站名单。
- “解除课堂管控”分别解除本工具拥有的网站策略和键鼠租约。任一通道状态未知时，只保留该通道的所有权记录并提示核对，不会影响另一通道的恢复。
- “解除课堂管控”只移除本工具能证明归属的网站策略或键鼠租约，不会关闭 AppLocker 长期软件保护或其他教师/管理员设置的策略。
- 页面顶部的“结束课堂”只在快捷管控已解除、倒计时已结束且课堂任务已完成时执行。先使用“解除课堂管控”释放本工具持有的策略，再结束课堂；结束后查看逐台摘要，离线设备显示待核对时，需要恢复连接后手动重新读取和解除。
- 控制操作不会因设备重新连接而自动重放。重新连接后先读取新状态，再由教师决定是否重试。

## 状态含义和常见处理

| 状态 | 含义与处理 |
| --- | --- |
| 已核验 | Agent 签名、身份、操作归属及相关状态读回均符合要求；浏览器或输入实际效果仍应现场确认。 |
| 失败 | 收到明确失败结果。查看逐台详情，修复原因后由教师重新发起。 |
| 尚未操作 | 本堂课还没有从课堂快捷卡片启用网站限制或键鼠锁定；它不代表学生电脑没有其他来源的网站策略，也不表示 Agent 离线。 |
| 需核对 / 键鼠需核对 | 相应通道没有新鲜可信回执、设备身份变化或所有权冲突；只影响对应通道，不代表整台电脑离线。 |
| 按钮不可用 | 尚未开始互动。启用网站限制和锁定键鼠还要求安装开放试点功能的教师端；恢复网站访问和解除课堂管控用于恢复，默认教师端也可使用。 |

设备异常的详细信息位于“设备健康”。先展开诊断详情，再使用页面明确启用的固定修复动作；该页面不提供任意命令。

## 试点版本说明

默认 TeacherConsole 构建不会接受新的课堂快捷管控命令，但仍可读取状态和解除本工具遗留的管控。测试版由管理员通过 `-ClassroomQuickControlManualTest` 单独封装，并带有 `CLASSROOM-QUICK-CONTROL-PILOT.txt` 标识。试点阶段仅在可恢复测试机使用；没有完成 1 台、2–5 台到整间教室的逐步验收前，不向正式教室分发。
