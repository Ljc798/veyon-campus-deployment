# Synthetic Student Configuration Package

This package is for documentation and parser/archive testing only. DEMO-CAMPUS-NOT-REAL and DEMO-PC- are synthetic values. Both included RSA public keys were generated for this sample; their private keys were never written to disk and are no longer retained.

The schema v3 manifest leaves telemetryEndpoint empty. The archive contains only the manifest, campus configuration, and two public keys. Do not upload this package, use it on real school computers, or treat its public keys as an operational trust root. Use a disposable test environment for any future interactive UI preview.
