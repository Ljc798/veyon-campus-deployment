# 更新来源与发布流程

CloudBase 环境（`veyon-control-d3gs8hmuyd09c00a7`）已过期隔离，原来的 `/v4/releases/latest`
版本发现接口和下载页配置接口都不可用了。现在的更新来源是 **发布目录（release catalogue）**：
一份签名的 JSON，作为每个 Release 的资产随安装包一起发布。

## 客户端怎么找新版本

1. 读 `https://api.gitcode.com/api/v5/repos/ljc_1126/veyon-campus-deployment/releases/latest`
2. 在返回的资产里找 `release-catalog.json`，下载并解析
3. 按角色取 `roles.TeacherConsole` / `roles.StudentSetup` / `roles.MaintenanceService`
4. 用内置的 Developer Release 公钥校验清单签名（RSA-PSS-SHA256）
5. 从清单的 `downloadUrl`（GitCode 资产）下载安装包，校验大小与 SHA-256
6. `downloadUrl` 不可用时，依次尝试目录里的 `mirrors`（GitHub 同名资产）；**镜像同样要过摘要校验**，
   签名不覆盖镜像地址，但覆盖摘要，所以镜像无法改变实际安装的内容

GitCode 是首选（国内直连、302 到国内 CDN）；GitHub 只作为第二来源。两个来源都不可用时，
客户端报“版本目录暂时不可用”，不会误报“已是最新版本”。

`VEYONCAMPUS_RELEASE_CATALOG_SOURCES` 可以覆盖来源列表，格式
`gitcode:owner/repo;github:owner/repo`，用于自建托管或本地测试。
`VEYONCAMPUS_DEPLOYMENT_PACKAGES_API_BASE_URL` 一旦设置，旧版 `/v4/releases/latest` 接口会作为
最后的兜底被启用（默认关闭）。

## 目录长什么样

```json
{
  "schemaVersion": 1,
  "tag": "v1.1.81",
  "roles": {
    "TeacherConsole": {
      "release": { "manifest": { "...": "..." }, "signatureAlgorithm": "RSA-PSS-SHA256", "signature": "...", "publishedAt": "..." },
      "mirrors": ["https://github.com/Ljc798/veyon-campus-deployment/releases/download/v1.1.81/VeyonCampus-Teacher-Setup-1.1.81-win-x64.exe"]
    },
    "StudentSetup": {
      "release": { "...": "..." },
      "studentAgentTarget": { "manifest": { "...": "..." }, "signatureAlgorithm": "RSA-PSS-SHA256", "signature": "..." },
      "mirrors": ["..."]
    }
  }
}
```

清单里的 `downloadUrl` 必须是 GitCode 或 GitHub 的
`/{owner}/{repo}/releases/download/{tag}/{fileName}`，且文件名必须与签名清单一致。
旧形态 `{apiBase}/v1/releases/{guid}/artifact` 仍然接受，供自建 API 与本地测试使用。

## 发版时多出来的两步

CI 会在 GitHub Release 创建完成后自动生成并上传 `release-catalog.json`（`build-release-catalog.cjs`），
所以 GitHub 侧不需要手工操作。**GitCode 侧仍然需要手工同步**，因为它没有 CI 凭据：

```bash
# 1. 从 GitHub Release 下载四个资产（两个安装包 + SHA256SUMS + release-catalog.json）
# 2. 一并上传到 GitCode
node scripts/publish-gitcode-release.cjs v1.1.81 1.1.81 <40位提交SHA> docs/releases/v1.1.81.md \
  VeyonCampus-Student-Setup-1.1.81-win-x64.exe \
  VeyonCampus-Teacher-Setup-1.1.81-win-x64.exe \
  SHA256SUMS release-catalog.json
```

漏传 `release-catalog.json` 的后果：客户端能读到新版本，但下载会 404，最后报“安装器下载失败”。

## 兼容性

- **1.1.80 及更早的客户端无法自动升级**。它们的版本发现地址编译期写死在已隔离的 CloudBase 域名上，
  只能手工安装 1.1.81 一次。从 1.1.81 起才走发布目录。
- 1.1.81 及以后的客户端不再访问 CloudBase 的任何接口。
- 教师端生成/发布配置包、设备心跳、后台管理页面仍然依赖 CloudBase 数据库，这些不在本次迁移范围内。
