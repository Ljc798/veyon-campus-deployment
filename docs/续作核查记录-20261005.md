## 本轮实现

- 网站策略信封拒绝重复/未知字段、缺失正文或签名；正文拒绝空域名列表和整数模式；拒绝未来超过一分钟的签发时间，签发端也验证规范 schema。
- 新增应用策略 v1 正文，固定用途 `VeyonCampus.ApplicationPolicy.v1`，只接受唯一学生 SID、审核/阻止/撤销模式、精确发布者与版本条件或哈希规则，限规则数/正文大小/有效期。校区绑定、递增版本、期限和 RSA-PSS 验证均在学生侧重复执行。
- AppLocker 仅编译 EXE 集合。显式 Deny 绑定学生 SID，配套 Everyone `*` 放行基线，避免隐式拒绝误伤其他应用；不启动 DLL、脚本、MSI 或打包应用控制。字节 SHA-256 与 AppLocker 原生哈希分开保存，不能混用。
- 应用策略编排在写 Windows 前保存待完成事务，校验现有本机/有效策略和归属；写后读回；中断后只接受原值或工具意图值；离线到期恢复空基线并保留最高版本。外部改写、存储失败、响应丢失均有故障注入检查。
- Windows cmdlet 适配器已编译：固定脚本，输入经 stdin JSON 传递；写入 XML 使用受保护临时目录；核对管理员/SYSTEM、AppIDSvc、已启用本地学生账户及管理员组；管理状态未确认时拒绝修改。此适配器尚未在 Windows 上运行。
- 修复跨进程租约的 Unix 实现：Windows 保留独占命名管道，Unix 使用持有文件锁。macOS 命名管道实例数不能作为跨进程互斥依据；强制结束子进程后释放租约也有回归检查。
- App/Worker 版本递增为 0.4.47，Core 为 0.4.37。尚未构建或发布本版本 Setup。
- 将用户要求的六项系统策略默认值与更新/恢复边界补入[应用程序限制设计](应用程序限制设计.md)；这些系统策略仍是后续待实现要求。
