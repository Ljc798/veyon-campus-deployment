## 2. 前端与服务端连接

公开页面经 Vite 构建。只有直接访问管理路由时，app.js 才动态加载 CloudBase 管理模块和 Web SDK。公开首屏及公共导航不含后台 URL。即使手动输入 /admin，也只能看到登录表单，数据库数据需通过 CloudBase Auth 与 RLS 验证后读取。

前端模块：

- src/cloudbase.js：从 Vite 环境配置初始化 Auth 和 RDB 客户端；只使用 publishable key。
- src/admin-data.js：查询当前用户角色、校区列表及 UTC+8 日汇总；通过 RDB SDK 新增/编辑校区。
- src/cloud-admin.js：显示登录、拒绝访问、总览、校区、每日统计、导出和设置页面。
- src/VeyonCampus.Telemetry.Server：接收 Agent 心跳、生成按日 HMAC 并调用 CloudBase PostgreSQL REST RPC。

前端没有数据库密码、service API key、HMAC key 或管理员令牌。CloudBase RLS 才是真正权限边界；隐藏路由与 UI 按钮判断不能取代 RLS。

## 3. 公开展示与后台访问边界

- 公开首页、主导航、手机导航、页脚、产品页和隐私页不包含 /admin 链接。
- /admin 是单独管理入口，需要直接输入地址并登录；没有公开注册或自助提权。
- Auth 登录但在 admin_profiles 无角色的用户只看到无权限状态。
- 角色由受控管理渠道维护；浏览器不能更新自己的角色记录。
- owner/admin/editor/viewer 的读写差异在 PostgreSQL grants 与 RLS 策略中落实。
- 网站不保留虚构后台数据或本地演示路由；开发与生产管理页使用同一套 CloudBase Auth + PostgreSQL 代码。

## 4. 管理页面行为

### 数据总览

- 读取今日 UTC+8 unique_devices、登记校区数、活跃校区数及选定周期内的 heartbeat_signals。
- 每日曲线使用数据库实际 telemetry_daily_hkt_stats 数据。
- 启用校区总数由 PostgreSQL 精确计数；地区概况按最近更新的最多 200 条校区资料计算，并在界面注明范围。
- 不会用本地假数填充零值；无数据时显示空状态。
- 显示 API 健康状态，但该状态仅代表遥测进程返回 /health，不代表 PostgreSQL 写入或登录有效。

### 校区管理

- 新建、编辑名称、地区、城市和 active/paused 状态。
- 更新时间由 PostgreSQL 触发器维护。
- 搜索与地区筛选在当前已载入的最多 200 条记录内生效，列表展示精确总数。
- 可导出已载入的校区 CSV。
- 当前没有删除按钮；数据库授权策略允许 owner/admin 删除，后续需通过专门受控流程。

### 匿名使用与趋势

- 匿名统计默认关闭；教师生成 schemaVersion=3 学生包时可单独启用。
- 启用后 Agent 每个 UTC+8 自然日最多发送一次随机安装标识、StudentSetup 版本和配置包 `packageId`。
- 服务端从已发布包记录反查校区 ID，并显示校区、部署包编号、工具版本的每日汇总；不展示逐设备摘要。
- 心跳 JSON 正文不含姓名、账号、电脑名、IP 字段、浏览历史或软件使用记录；CloudBase 网络层仍会接收连接源 IP。
- 7/30/90 天每日活跃数之和不是跨日独立设备总数；同一安装在同日变更版本/包会出现在对应的多个分组。
- 可导出全站每日汇总 CSV；校区/版本细项在趋势页读取 RLS 保护的聚合表。

### Auth 登录

- 使用 CloudBase Auth 用户名密码登录，无公开注册表单。
- 登录之后先读取当前 Auth 用户自己的 admin_profiles 记录。
- 无角色时拒绝后台访问；读写实际由 PostgreSQL RLS 再次限制。
- 页面只提供退出登录，不会显示账号密码或令牌。

## 5. 数据库记录和数据边界

CloudBase PG 已执行迁移 20260928141201_create_site_database.sql，五张业务表和相关权限已核对。当前 owner 角色已从既有 administrator Auth 账号建立；campuses 表目前没有校区资料。当前数据库规模为初始空数据状态。

遥测数据走独立流程：学生包生成时默认不启用；教师明确勾选后，Agent 每日发送匿名安装标识、工具版本和配置包编号。服务器用 UTC+8 日期 HMAC，按已发布包编号关联校区，只存日摘要与聚合统计。逐日摘要保留 90 天，聚合保留 400 天。新迁移需先在 CloudBase 执行，再部署新的心跳服务版本。API 与数据库迁移的设计细节见：

- ../docs/CloudBase接入与验收.md

## 6. 本地开发

首次安装：

    cd website
    npm ci

填好被 Git 忽略的 .env.local 后：

    npm run dev

访问 http://127.0.0.1:5173/ 查看公开站；直接访问 http://127.0.0.1:5173/admin 进入管理工作区。CloudBase 当前套餐拒绝添加本地来源 127.0.0.1:5173，因此本地浏览器的 Auth/RDB 请求无法完成来源校验；需在允许该来源后才会看到正常用户名密码登录表单。

生产构建与本地构建预览：

    npm run build
    npm run preview

构建不会自动发布到 CloudBase。正式站点静态托管、SPA 回退、HTTP 云函数首次部署、kidscode.fun DNS 和 90 天证书绑定尚未执行。
