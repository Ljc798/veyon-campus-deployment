# VeyonCampus App 文档入口

更新日期：2026-09-29。本目录说明 C# / Avalonia App；仓库根目录的原脚本文档仍说明 PowerShell v1.0，两套工具能力和风险不同。

## 当前状态

- App 源码版本：0.4.33，Windows 本地离线部署实验版。
- 0.4.29 将校区配置分发改为 Windows 共享文件夹；0.4.30 修复跨校区任务／策略记录不一致；0.4.31 修复缺失计划任务触发的卸载异常。0.4.33 对 Veyon 同名公钥做指纹读回：确认与当前配置包一致后跳过重复导入并继续 Agent 安装；学生端另有独立的 Agent 安装／修复入口。0.4.31 卸载已由用户在本机实测成功；0.4.33 Agent 恢复流程仍待实机验收。
- 0.4.23 期间曾复现旧安装器递归 `icacls` 返回成功却清空 DLL 文件 DACL 的缺陷。该版本恢复安装到 ProgramData，使用 Windows ACL API 设置并读回目录和文件权限；当时的 7 项回归仅为历史证据。完整过程见[排查记录](学生虚拟机网站Agent启动失败排查记录.md)。
- 0.4.18 的学生策略代理使用版本隔离目录和 TCP 39174；可从已识别的旧版 ProgramData／Program Files 安装路径迁移任务与防火墙规则，不会删除旧 URL ACL。
- 0.4.21 修正学生虚拟网卡被识别为 Public 时防火墙规则不生效的问题；安装时将已识别的旧 Agent 规则更新为 Any 网络配置，并继续限制 Agent 程序、TCP 39174 和 `LocalSubnet` 来源。
- 0.4.31 全量自动检查 36 项通过，学生专项检查 6 项通过；本机只读预检复现“任务不存在、两份跨校区配置、无所有权记录”。用户现已确认本机 Agent 卸载成功；39174 端口、SMB 和浏览器行为仍须 Windows 实机验收。0.4.33 新功能尚未运行自动检查。
- 学生端启动后自动只读检测本机 Veyon；准备阶段由一个按钮同时生成计划预览并执行只读环境检查。结果区说明计划步骤和电脑当前状态，两项通过后才可部署；检测到兼容版本时跳过安装步骤。
- 教师端的一键策略推送要求学生端 Agent 安装并通过读回；用户已在一教师一学生环境验证基础黑名单和白名单效果。地点名单中填写姓名后只显示姓名，编号仍作为主机名。
- Windows 会阻止普通资源管理器向管理员窗口进行 OLE 拖放；管理员模式请用配置包选择器。该边界不能靠放行窗口消息解除。
- 新增独立 `VeyonCampus.Agent.exe`、部署后只读验证与清理、策略到期／一键解除、逐台推送历史及新品牌图标。构建和 fixture 不等于 Windows 系统验收。
- 教师控制台和学生部署工具已拆成 `VeyonCampus.Teacher`、`VeyonCampus.StudentSetup` 两种独立构建；0.4.33 两个角色 ZIP 已构建并通过内嵌安装器摘要核验；启动和系统行为仍须 Windows 实机验收。
- 路线清单勾选只统计具备当前环境证据的项目；P10 的 Windows 文件共享流程已接入界面，权限配置和两机网络验收仍待完成。
- 教师端新增一键建立 Veyon 地点和电脑名单，支持粘贴学生姓名列并保留编号主机名；侧栏固定为课堂控制、地点名单、首次设置。
- 本轮修改了公钥重试逻辑和学生端 Agent 修复入口，未启动 GUI 或操作 Windows 系统设置。0.4.27/0.4.28 限时 HTTPS 配置传输流程不再作为当前分发入口；0.4.29 共享文件夹方案仍需两机验收，0.4.33 Agent 恢复流程待用户实机验收。
- 正式下载页仍未建立。教师通过 Windows 文件共享提供校区配置文件夹，不分发学生程序本体；StudentSetup 首次获取仍需走受信渠道。仓库网站目前没有 CloudBase 上传、认证、存储或搜索 API。

当前网站策略仅操作 Edge/Chrome 机器级 URL 策略。独立 Agent 以 SYSTEM 计划任务运行；受保护任务 DACL、部署后检查和清单限定清理已有实现。用户已验收基础黑白名单及教师端推送；课堂时长、恢复逻辑、普通学生账户权限、重启／到期恢复和扩大设备规模仍待验收。

## 状态用语

“代码已实现”“自动检查通过”“Windows 实机验收通过”是不同状态。系统功能只有在目标 Windows／浏览器上获得对应证据后才能关闭路线任务；模拟设备数量不表示实际连接设备数量。
