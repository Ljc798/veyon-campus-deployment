# 校区配置包版本兼容策略

配置包是签名的部署资料，不应因为教师端或学生端发布一个普通补丁版就突然无法导入。兼容边界按可读取的协议系列处理：

- **Student App：** schema 4–6 的旧包在当前应用与包属于同一主版本时，按该主版本兼容范围读取。例如 1.0.21 创建的包可由 1.1.x 读取。新包也声明当前主版本范围；升级到新的主版本前需要明确处理迁移。
- **Veyon：** 对同一 Veyon 主、次版本系列放行补丁版，例如 4.11.x。跨到新的次版本系列仍需确认兼容，避免把 Veyon 格式变化误当成普通补丁。
- **Student Agent：** 包声明 Agent 兼容区间；当前 0.4.x 系列兼容上限为 0.5.0。普通 0.4 补丁更新不要求重发配置包；进入 0.5.0 前，须先确认 Agent 与策略协议兼容后调整上限或升级包 schema。
- **Schema：** 对未支持或更高的 schema 版本继续拒绝导入。旧包在读取时只调整本机用于判定的兼容区间，不改写原包内容、签名或摘要。

因此，常规 Student App 1.x 更新、Veyon 4.11 补丁更新和 Student Agent 0.4.x 补丁更新不应让已有配置包失效。跨应用主版本、Veyon 次版本、Agent 兼容上限或包 schema 的变更属于显式兼容决策，需要在发布前确认。
