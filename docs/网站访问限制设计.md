# 网站访问限制设计

当前网站限制由学生机的 SYSTEM Agent 设置 Edge 和 Chrome 机器级 URLBlocklist/URLAllowlist 策略。教师输入域名或不带路径的 HTTP/HTTPS 地址；域名先规范化为小写 IDNA 主机名，再按目标浏览器分别生成规则。

Chrome 企业 URL pattern 中，裸域名只匹配精确主机，因此规则写成 `[*.]example.com`，覆盖 `example.com` 和任意层级子域名。Edge URL-list filter 的裸主机名会覆盖主机及其子域名，因此 Edge 规则写成 `example.com`。编译器分开输出两种格式，让 Edge/Chrome 行为保持一致。黑名单直接封锁名单中的域名；白名单封锁 `*`，再允许名单中的域名。

当前覆盖 Edge 与 Chrome；Firefox、其他浏览器、非浏览器应用、DNS 和全设备网络流量过滤不在本实现范围。浏览器策略状态的注册表读回和事务恢复有可移植检查，但 Windows 浏览器实际刷新、根域名/子域名拦截以及现有标签页行为仍须在 Windows 实机验收。

规则依据：[Microsoft Edge URL-list filter format](https://learn.microsoft.com/en-us/deployedge/edge-learnmmore-url-list-filter-format)、[Chrome Enterprise URL pattern format](https://chromeenterprise.google/intl/en_ca/policies/url-patterns/)、[Microsoft Edge URLBlocklist](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/urlblocklist)。
