边注 · 需要人工核对

颜色不是唯一状态提示：所有状态都同时保留文字标签与图标，关键说明不小于 12px。

数据边界：后台只查询经 grants / RLS 授权的字段；公开页面不显示管理员入口。
暂无记录 — 数据库中没有符合条件的记录时显示空状态，不以虚构数据填充。
纸面 #F8F6F0 墨蓝 #132E46 品牌青绿 #187B70 朱赭批注 #B04A30 字体：系统衬线 + 系统无衬线，无外部 CDN
