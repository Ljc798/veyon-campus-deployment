# 课堂任务进度

1. 在教师控制台开始课堂后，在课堂卡片的“课堂任务”输入一行任务并点“添加”。
2. 完成任务时勾选标题；需要重做时取消勾选。点“移除”只删除该项。
3. 已配对手机会在“课堂模式”卡片里只读显示相同清单和完成数。

每堂课最多 20 项，每项最多 120 字。清单保存在教师电脑的 `%LOCALAPPDATA%\VeyonCampus\Teacher\classroom-task-progress.json`，Teacher 重启后会随活动课堂恢复；下课时清除。手机不能编辑，任务不会发送给学生电脑或 CloudBase。

功能已通过自动检查和 TeacherConsole Release 构建。Windows 桌面操作与真实手机同步仍需实机验收。
