| 需求 | 当前实现 | 未完成验收／工作 |

| 教师与学生角色隔离 | 两种构建使用独立窗口、ViewModel 和程序集；学生包带独立 Agent，教师包不带学生部署入口；私钥只在教师用户证书库 | Windows 角色 ZIP 内容、启动界面、普通用户权限和部署后清理行为仍需实测 |
| 部署后清理 | 只读检查全部通过才开放；清理只删除发布 manifest 中列出的便携部署文件 | Windows 真实包验收、清理失败恢复与双击验证 |
| App 下载与校区配置 | 打包脚本可生成同一版本的教师／学生角色 ZIP；首次校区配置目标为教师授权的局域网流程，课堂策略由教师推送已安装 Agent | 正式下载页、校区资料来源认证和局域网文件服务均未实现；角色 ZIP 与策略推送尚未在 Windows 实机验收 |

## 状态用语

“代码已实现”“自动检查通过”“Windows 实机验收通过”是不同状态。系统功能只有在目标 Windows／浏览器上获得对应证据后才能关闭路线任务；模拟设备数量不表示实际连接设备数量。
