## 文档维护约定

1. 新内容优先合并到对应主文档，不为每轮修复再创建“当前进度”或“总结”。
2. 状态只在任务表维护；其他页面链接到它，不复制版本和已通过项。
3. 目标设计、代码实现、自动检查与 Windows 实机验收分别说明。只编译通过不能关闭系统验收任务。
4. 历史记录保留原日期和证据；新结论写入主文档，不继续更新归档。
5. 调整路径时同步相对链接和文本校验值；不把密钥、密码或真实学生资料写入文档。
