## 状态用语

“未实现”“部分实现”“自动检查通过”“Windows 实机验收通过”代表不同阶段。代码存在或自动检查通过，不等于真实系统操作已验证；模拟 150 条记录不等于 150 台设备已经连接验收。任务只有在交付物和对应证据齐备后才勾选。
