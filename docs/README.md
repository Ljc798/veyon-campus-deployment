# VeyonCampus App 文档入口

更新日期：2026-09-28。本目录说明 C# / Avalonia App；仓库根目录的原脚本文档仍说明 PowerShell v1.0，两套工具能力和风险不同。

## 当前状态

- App 源码版本：0.4.23，Windows 本地离线部署实验版。
- 已在 Windows 复现旧安装器递归 `icacls` 返回成功却清空 DLL 文件 DACL 的缺陷。0.4.23 恢复安装到 ProgramData，使用 Windows ACL API 分别设置、读回目录和文件权限，并自动修复已存在目录与配置。7 项文件安装回归及真实发布 Agent 加载通过，学生虚拟机重置后的完整部署／推送仍待现场确认。完整证据见[排查记录](学生虚拟机网站Agent启动失败排查记录.md)。
- 0.4.18 的学生策略代理使用版本隔离目录和 TCP 39174；可从已识别的旧版 ProgramData／Program Files 安装路径迁移任务与防火墙规则，不会删除旧 URL ACL。
- 0.4.21 修正学生虚拟网卡被识别为 Public 时防火墙规则不生效的问题；安装时将已识别的旧 Agent 规则更新为 Any 网络配置，并继续限制 Agent 程序、TCP 39174 和 `LocalSubnet` 来源。
- 本轮构建通过（0 警告、0 错误）；0.4.23 学生 ZIP 已生成，内嵌 Veyon 安装器校验通过。学生专项检查 5 项通过；完整检查在中文校区名的旧拒绝断言处失败，不能沿用历史全通过结论。
- 学生端启动后自动只读检测本机 Veyon；准备阶段由一个按钮同时生成计划预览并执行只读环境检查。结果区说明计划步骤和电脑当前状态，两项通过后才可部署；检测到兼容版本时跳过安装步骤。
- 教师端的一键策略推送要求学生端 Agent 安装并通过读回；0.4.23 Agent 及配置在 ProgramData 的受保护目录。地点名单中填写姓名后只显示姓名，编号仍作为主机名。
- Windows 会阻止普通资源管理器向管理员窗口进行 OLE 拖放；管理员模式请用配置包选择器。该边界不能靠放行窗口消息解除。
- 新增独立 `VeyonCampus.Agent.exe`、部署后只读验证与清理、策略到期／一键解除、逐台推送历史及新品牌图标。构建和 fixture 不等于 Windows 系统验收。
- 教师控制台和学生部署工具已拆成 `VeyonCampus.Teacher`、`VeyonCampus.StudentSetup` 两种独立构建；Windows 打包脚本可分别生成角色 ZIP，学生包清理清单识别新的 StudentSetup 程序名并拒绝教师端产物。本轮两个 ZIP 已通过静态内容核对；启动和系统行为仍须 Windows 实机验收。
- 路线清单按严格验收条件统计为 11/132 项完成（8.3%）；未勾选任务包括已有实现但欠缺 Windows 证据的部分。
- 教师端新增一键建立 Veyon 地点和电脑名单，支持粘贴学生姓名列并保留编号主机名；侧栏固定为课堂控制、地点名单、首次设置。
- 本轮未启动 GUI、修改 Veyon 目录或操作 Windows 系统设置。请在可恢复 Windows 测试机按[学生端自测验收单](Windows学生端黑白名单与后台代理自测验收单.md)验收；构建和静态检查不代替实机验证。
- 正式下载／网络分发仍未实现：尚无 GitHub/Gitee 发布页或局域网学生资料下载服务；教师直推签名课堂策略已有代码，仍待 Windows 网络实测。

当前网站策略仅操作 Edge/Chrome 机器级 URL 策略。独立 Agent 以 SYSTEM 计划任务运行；受保护任务 DACL、部署后检查和清单限定清理已有实现。课堂时长和恢复逻辑、教师本机逐台状态也已有代码；浏览器拦截、普通学生账户不能停止任务、重启／到期恢复和跨机推送仍未在 Windows 实测。

## 状态用语

“代码已实现”“自动检查通过”“Windows 实机验收通过”是不同状态。系统功能只有在目标 Windows／浏览器上获得对应证据后才能关闭路线任务；模拟设备数量不表示实际连接设备数量。
