状态统一使用“未实现／部分实现／本地检查通过／系统验收通过”。可执行表示代码会修改系统，不表示已通过交付验收；模拟 150 条记录不表示 150 台设备已验证。

版本以 [App 项目文件](../src/VeyonCampus.App/VeyonCampus.App.csproj) 为准，安装器基线以 [VeyonInstallerTrust](../src/VeyonCampus.Core/VeyonInstallerTrust.cs) 为准。任务只在交付物与相应验收证据齐备时勾选；历史 PASS、用户反馈和旧 ZIP 不自动证明当前源码已通过系统验收。

根目录 [README](../README.md)、[当前能力与未来计划](../当前能力与未来计划.md) 的主体是原脚本 v1.0。原脚本的改名、改密行为与 App 的能力范围不同，使用前先确认版本。
