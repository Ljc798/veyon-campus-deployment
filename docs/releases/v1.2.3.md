# Veyon Campus 1.2.3

1.2.3 把课堂管控从"只能整班下发"推进到"能精确到一台设备、一个时刻"，同时修掉了一批跨机器与身份相关的故障：改名后的学生机不再被当成不可信的 Agent，锁键鼠后解不开、课堂状态报"回执时间无效"这两个老问题也从根上修掉了。手机端这次补齐了单台管控和实时画面。

**教师端和学生端都要升到 1.2.3。** 只升教师端时，新增的课堂状态与断网处理看不到。

## 单台设备可以单独选时间

以前只有整班推送才能自定义截止时间，给一台学生机锁键鼠或推网站策略只能套用全班的时长或固定一小时，到点全班一起解，也很难给某一台"再加十分钟"。

- 桌面端对单台设备下发前会先弹「截止时间」对话框，可直接填 `HH:mm`，也有 15/30/45/60/90/120 分钟快捷项，时间不合法或已过期会当场提示。
- 单台的截止时间与全班互不影响：给一台加时不会改动全班截止时间，全班到点时也不会提前把这台解掉。
- 单台截止到了就清掉这台设备的网站控制，不会再补发策略。

## 手机端能管单台了

手机课堂页原来只能整班操作，现在每一行设备和巡视卡片上都有「单台管控 · 选时长」：

- 网站策略、锁定键鼠、解除限制、查看实时画面四个动作都可以只作用于这一台。
- 时长可选 10–120 分钟，也可以自定义；服务端会校验目标属于当前课堂，并按本地时区裁剪到当天午夜，不会出现"跨天还锁着"。

## 不再要求核对指纹

原来身份发生变化时会让老师核对一串指纹再点"核对并固定"，实际上没人会去比对这串字符，只会直接点确认——这一步既挡不住风险，又平白多一次点击。

- 教师端删掉了「核对并固定身份」按钮和核对码对话框，身份变化改为自动信任。
- 手机端与 Agent 通道握手时，用 Hello 携带的公钥验证本机随机数后再固定身份，仍然保留"确实持有私钥"这一条证明。
- 界面文案同步改成"将自动信任"，不再指向已经删除的按钮。

## 手机端能看到实时画面了

桌面屏幕墙能看到画面、手机端却拿不到，是因为两条路径取的源不同。现在手机取帧与桌面屏幕墙同源：走教师机本机 `127.0.0.1:11080` 的 Veyon WebAPI，认证一次后复用缓存连接，WebAPI 不可用时才回退 `veyon-cli` 截图。

取不到画面时，手机端会写清真实原因——认证被拒绝、主机不可达、WebAPI 未启用——而不是一律显示超时。

## 修掉的故障

- **锁键鼠后解不开、课堂状态报"回执时间无效"**：根因是跨机器比较绝对时间，两端时钟差几十秒就会让有效期判定失效。改为用"剩余有效期 = 截止 − 签发"锚定本机时间，并用签名状态测出两端时钟差来换算命令与回执时间；提示里会直接写出相差多少秒。
- **改名后学生机被判 untrusted**：同一把密钥只按座位名匹配，改名后旧名字对不上就被当成陌生设备。现在同一指纹允许对应多个座位名，Agent 通道和维护通道都会把所有匹配名称注册到同一连接。

## 学生端：断网逃课

- **网络开关加固**：Agent 启动时收紧"网络和 Internet"设置页与网络连接界面，普通账号无法从图形界面禁用网卡；管理员仍可通过注册表或服务手段恢复，换 Wi-Fi 口令不受影响。
- **断网锁键鼠**：连续 60 秒没有可用网络（有启用中的网卡、非自动专用地址、且有默认网关）且当前有生效的课堂策略时，本机锁键鼠并每 5 秒续租；网络恢复 5 秒内自动解除，最长 45 分钟硬上限。它只解除自己签发的锁，不会顶掉教师端下发的锁定。
- **离线游戏压制**：只要存在生效策略，扫雷、纸牌、空当接龙、麻将、植物大战僵尸、街机模拟器等单机游戏进程会被关闭。
- **卸载会恢复**：卸载时新增"解除网络开关加固"，只删除仍等于本产品写入值的项，管理员改过的值不动。

## 安装与升级

- 覆盖安装即可，学生配置包兼容范围仍是 `1.0.0`–`2.0.0`，现有 1.1.x / 1.2.x 学生机不会被判为不兼容。
- 学生端内置 Agent `0.4.75`。
- 本版安装器未做 Authenticode 代码签名，SmartScreen 会提示未知发布者，属预期。

## 建议的验证顺序

1. 教师端与学生端都升到 1.2.3 并重启。
2. 选中单台设备推送网站策略，把截止时间设为 15 分钟后，确认到点只解除这一台。
3. 手机扫码进课堂页，对同一台设备用「单台管控 · 选时长」试网站策略与键鼠锁定。
4. 手机看这台设备的实时画面，确认能出图；失败时确认错误信息写的是认证或连通性原因。
5. 改一台设备的座位名称后重新推送，确认不再出现"认证失败 / 不信任的 Agent"。
6. 学生机断网 90 秒，确认键鼠被锁；恢复网络后 5 秒内自动解锁。
7. 卸载学生端，确认"网络和 Internet"设置页恢复、网卡可正常启用禁用。
