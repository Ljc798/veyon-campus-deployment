# Veyon Campus 1.1.73

这一版只做一件事：把“学生端拒绝了这次更新请求”的真实原因，原样带到教师端界面上。

## 1. 教师端不再只显示 HTTP 409

更新前的“能力读取”如果被学生端拒绝，学生端会用 409 回一段说明（信任根不匹配、请求被判定重复、
时间戳超出允许窗口、协议版本不符等）。原来的代码只把状态码写进提示，正文被丢掉了：

```
维护未完成：读取学生更新能力返回 HTTP 409。
```

现在会把正文一起显示，并去掉控制字符、截断到 200 字符：

```
维护未完成：读取学生更新能力返回 HTTP 409：<学生端给出的原因>
```

## 2. 学生端把 409 也记进诊断

以前只有 500 一类的失败会写诊断记录，409 这类“签名校验未通过”什么都不留，事后无从追查。
现在每次拒绝都会写一条带诊断编号的记录，并把编号附在响应正文里：

```
<原因>；诊断编号 3f2a9c81d4e7。
```

这样即使教师端界面被截图或只保留了文字，也能在学生机上按编号查到原始异常。

## 3. 没有改变的东西

- 更新协议、签名、信任根、事务状态机一律没动——本版不改变任何判定结果，只改变“失败时说了多少”。
- 学生端仍是 1.1.73，可以从 1.1.71 / 1.1.72 直接升上来。
