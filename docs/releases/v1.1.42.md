# Veyon Campus 1.1.42

- 单地点机房隐藏校区和地点选择、当前地点设置；多地点配置仍可切换和维护。
- 修复教师端重启后无法恢复已保存座位图的问题。恢复时核对地点名称及完整电脑地址；匹配不唯一时保留用户当前选择，避免套用错误座位图。
- 修复课堂快捷管控使用重复地点档案时座位图无法显示姓名的问题，并在收到成功状态快照后清除过期的连接提示。

教师端和学生端安装包均为 Windows 10/11 x64。请先在可恢复的测试电脑上安装并验收，重点检查单地点/多地点界面、重启后的座位图、课堂设备姓名，以及教师端和学生端升级流程。自动构建与检查不能替代目标电脑上的实机验证。

安装程序未进行 Authenticode 签名；首次运行时 Windows 可能显示安全提示。
