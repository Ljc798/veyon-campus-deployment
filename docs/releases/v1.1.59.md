# Veyon Campus 1.1.59

## 修复

**1. 注册表目录快照现在算「完整读取」，不再锁住课堂与座位绑定。**

1.1.58 加入了「`veyon-cli` 无法启动时读 Veyon 注册表快照」的回退，但把结果标成了「部分读取」。而课堂开始/结束、座位绑定、策略推送都要求目录「完整可信」，于是出现一串看似无关的现象：

- 「结束课堂」按钮点了没有反应（按钮被禁用，不是流程拒绝）
- 「重试 Veyon 同步」永远停在「名单未能通过完整读取与身份核对」
- 座位图显示 17 台已绑定，剩下的电脑加不进 Veyon

数据源本来就是 Veyon 自己的目录存储（`config export` 也从这里导出），UUID、父子关系、Host 全都在，因此它应当被视为完整读取。现在回退成功时 `PartialRead=false`，上述功能同时解锁。

**2. 课堂进行中写 Veyon 现在会自动「暂停课堂 → 写入 → 恢复课堂」。**

以前在课堂进行中修改座位并同步，只会得到一句「请下课后重新添加电脑」，按钮形同虚设。现在点「重试 Veyon 同步」会：

1. 先探测 `veyon-cli` 是否真的能启动；
2. 能启动时自动结束当前课堂（记录会话），把地点和电脑写入 Veyon；
3. 无论成功或失败，都会把课堂重新开起来；
4. 结束课堂需要先满足的条件（倒计时、未完成的课堂任务、未解除的快捷管控）会给出具体原因，不再静默失败。

**3. 不会为了一个注定失败的写入而打断课堂。**

如果 `veyon-cli` 在这台电脑上起不来（R6031），会**在暂停课堂之前**返回，提示「课堂保持进行中，本机座位资料已保存；请先修复 Veyon 安装」，避免老师白停一次课。

## 仍然存在的限制

写回 Veyon 目录必须经过 `veyon-cli`。它在这台机器上崩溃时，新增地点或电脑无法完成——这不是本程序能绕开的，需要修复 Veyon 安装，或在 Veyon Configurator（GUI 正常）里手动补齐电脑；补齐后本程序按 Host 自动建立 UUID 绑定。
