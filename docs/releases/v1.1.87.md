# Veyon Campus 1.1.87

## 变更

**修复“课堂快捷管控整块变灰、点不动，且不给原因”。**

症状：教室页显示“课堂进行中”，学生电脑也在名单里，但「启用网站限制」「锁定键盘与鼠标」两个按钮是灰的；鼠标移上去没有高亮，点下去既不弹确认框，也没有任何提示。页面下方的「待恢复学生策略」会显示一句：

> 课堂持续会话已保存；旧版策略账本暂不可用。本机仍有过多个未完成的课堂策略恢复记录；请先检查并恢复旧记录。

原因有两层：

1. **课堂账本会残留“仍在进行”的记录。** `classroom-mode-state.json` 只允许同时存在一个进行中的课堂。上一节课结束时，如果那条账本没有被标记结束（结束路径被打断、或写入失败），它就永远是 `active`。下一节课开始时会向账本写入新记录，被“已经有两个进行中的课堂”挡下并抛错，新课堂的账本因此没有写进去——快捷管控整套能力随之不可用，而界面上只有那句含糊的“旧版策略账本暂不可用”。
2. **点击路径里有两处静默返回。** 读回课堂快照与当前课堂 ID 不一致、或会话已经切换时，处理器直接 `return`：不弹确认框、不写事件、不改状态，表现就是“这个按钮坏了”。

本版的处理：

- **开始课堂前自动清理残留账本。** 凡是标记为进行中、但当前课堂已经不是它的条目——没有遗留策略的直接删除，有遗留策略的改为“已结束”保留——都会被收敛，不再让一节课的残留卡死后面所有课。
- **所有中途退出都给出明确原因**：会话已失效、课堂已切换、本机课堂状态与当前课堂不一致、构建未启用快捷管控，各自有对应提示，不再静默返回。
- 两个按钮新增悬停提示：按钮不可用时，鼠标停留即显示具体被哪一项条件拦住。

## 注意

- 本版不改变策略签名、回执核验与“只解除本工具持有的策略”的所有权规则。
- 若机器上已经存在残留账本，升级后**开始一次课堂即会自愈**，无需手工删文件。
