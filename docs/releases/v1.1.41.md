# Veyon Campus 1.1.41

- 修复课堂快捷管控在重复应用、恢复、自动截止和离线补同步期间，旧任务或旧状态覆盖新操作的问题。每次操作持久化单调版本，并对过期回执、轮询结果和截止任务做版本核对；重试按退避时间执行。
- 学生端上线后主动连接教师端并同步课堂策略状态；教师端只处理已认证的学生连接，离线设备不再触发教师端高频重复探测。无法确认的状态继续显示为待同步或待核对。
- 修复学生端部署包的版本/策略清单一致性检查，并改进学生 Agent 通道和状态回执处理。
- 调整教师端机房地点与座位编辑入口，移除无用途的提示框，并修正课堂设备卡片展开区域的布局。

自动构建与发布检查通过后，仍需在目标教师机和学生机验证策略应用/恢复、学生上线补同步、课堂期间断网恢复及安装器升级。自动检查不能替代实机验收。
