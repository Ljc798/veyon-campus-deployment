# Veyon Campus 1.1.43

- 修复学生端更新请求已返回有效“已接受”签名回执、但阶段记录已确认命令预检失败时，教师端仍等待 5 分钟的问题。教师端会在等待终态期间检查签名阶段记录，确认失败且未进入下载或安装后立即停止等待并显示失败阶段。空回执和 HTTP 错误最多核对 15 秒；Agent 处理异常时会返回带诊断编号的 HTTP 错误，避免异常被误报为空的 HTTP 200 回执；需要核对的设备会保留“待核对”状态。
- 教师端逐台更新状态徽标保持单行显示，窄窗口下使用省略号避免换行。
- 导入部署配置后，默认勾选“更改管理员密码”；进入配置页前保持未勾选，避免无配置时误执行。

本版本重点用于复测教师端批量更新 Student Agent 的预检失败处理。构建和发布不代表目标学生机上的升级已实机验收。
