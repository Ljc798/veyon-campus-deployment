# Veyon Campus 1.2.0

1.2.0 把教师端课堂页从"设备清单"改成以**实时屏幕墙**为默认视图，并把 1.1.89 之后二十多个测试版里修掉的课堂管控问题一并收进稳定版。

升级后教师端课堂页默认看到的是每台学生机的真实画面，卡片上直接带键鼠锁定和网站策略两个操作；原来的座位图、设备列表仍在同一个分段开关里，三套视图共享同一份设备身份与座位投影，不会各算一套。

## 屏幕墙：默认视图

- 按座位顺序排列，卡片显示实时画面、电脑名、学生姓名、座位号与连接状态。
- 画面右上角原来的"放大"按钮去掉了；**双击卡片**或右键"查看实时屏幕"打开独立详情窗口，详情窗口复用同一条连接，不会为放大再认证一次。
- 取不到画面时明确显示原因（连接中、等待首帧、画面过期、离线、认证失败、WebAPI 未启用），不会用占位图冒充真实画面。
- 视图菜单可调每行列数、缩略图大小和紧凑模式；筛选行现在完整显示，不再横向溢出。
- 搜索支持姓名、电脑名、Host、座位号；状态筛选与排序对三套视图同时生效。

## 画面来源：本机 Veyon WebAPI

画面取自教师机本地 `http://127.0.0.1:11080` 的 Veyon WebAPI，由 `veyon-service` 加载，**不依赖 Veyon Master 运行**。实测在只有服务、没有 Master 进程的情况下画面正常刷新。

- 每台设备一条连接，认证一次、之后在同一连接上反复取帧。
- 全局并发 4 路取帧，可见卡片约 700ms/台、聚焦卡片 130ms/台，避免几十张卡片同时把服务打满。
- 启用方式：管理员运行 `scripts/enable-teacher-webapi.ps1`；`-Disable` 可回滚。脚本会同时建一条只放行 `127.0.0.1` 的入站规则。

> **安全边界**：WebAPI 没有 TLS，密钥认证要求把私钥内容放在请求体里，而服务本身监听在所有网卡上。挡住外部访问的只有那条回环防火墙规则。不要把 11080 开放到局域网，也不要把它当成远程访问接口。

## 键鼠锁定与网站策略：这一批修掉的真问题

1.1.89 之后课堂管控的多数故障都出在"锁上了但很快自己解开"，根因是几个叠加的缺陷：

- Guard 的租约线程每秒把仍在有效期的租约判成过期（1.1.109 修复）。
- 激活成功、续租失败的 epoch 竞态（1.1.107 修复）。
- v1.1.33 遗留的"网站策略与键鼠互斥"拦截，导致同时下发时其中一项被丢弃（1.1.108 修复）。
- `BlockInput=5` 的完整性级别不足以压住提权窗口（1.1.106 修复）。

此外：

- 锁定的目标从"整批"改成按单台，多选锁定仍可用。
- 支持自定义截止时间；课堂重启后自动恢复仍有效的限制，不再是"重启就全解"。
- 学生端 Agent 兜底启动 Input Guard，Guard 异常退出后能自己回来。
- 无法核验归属时明确显示"需核对"，不再默认当成已生效。

## 网站封锁

- 对封禁地址同时做 DNS 强制、TCP 重置与 UDP/QUIC 处理，补上了"网页打不开但视频还在播"的漏洞（1.1.95–1.1.100）。
- 已经建立的抖音连接改走进程层处理，不必等用户手动重开（1.1.101）。
- 常用网站白名单新增 `super-zxt-student.chuangke100.com`。

## 可见性

- 身份核对入口常驻，离线状态下也能固定设备身份（1.1.98–1.1.99）。
- 推送失败的原因不再被吞掉，行内直接写失败阶段（1.1.101）。
- Input Guard 状态无法核验时明确标注，不再显示成"成功"（1.1.102）。

## 安装与升级

- **教师端和学生端都要升到 1.2.0**。学生端 1.2.0 内置 Agent `0.4.68`；只升教师端时，新增的课堂状态和 Guard 行为看不到。
- 学生配置包的兼容范围仍按产品主版本计算（`1.0.0` 至 `2.0.0`），现有 1.1.x 学生机不会因为这次升版被判定为不兼容。
- 已有 `website-policy-presets.json` 的机器**不会**自动追加新白名单域名，需要在"策略与预设"里手动加一行；没有该文件的机器会使用新的默认列表。

## 建议的验证顺序

1. 教师端与学生端都升到 1.2.0，重启两端。
2. 开始课堂，确认右栏屏幕墙出现真实画面，卡片状态为"实时"。
3. 双击一张卡片，确认详情窗口出画面且可以关闭；关闭后墙上的画面继续刷新。
4. 对一台学生机点"键鼠锁定"，确认学生端输入被拦住，并保持 5 分钟以上不自动解除，再手动解除。
5. 对同一台设备推送网站策略，确认目标网站被拦、白名单站点仍能打开。
6. 打开"策略与预设"，确认白名单里出现 `super-zxt-student.chuangke100.com`（老机器需手动添加）。

## 说明

- 屏幕墙只读画面，不在墙内做远程桌面操作；详情窗口目前也是只读画面加两个策略入口。
- 每台卡片上同时保留右键菜单，包含定位座位、查看策略状态、设备诊断等原有入口。
- 屏幕广播/演示仍未实现，需要时继续用 Veyon Master。
