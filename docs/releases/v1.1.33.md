# Veyon Campus 1.1.33

## 教师端

- 统一课堂控制、设备健康、策略与消息界面，减少重复说明和嵌套边框。
- 课堂模式随教室配置保持可用，移除多余的课堂开启/结束操作。
- 网站限制与键鼠锁定分别操作；键鼠状态不可读取时不阻止网站限制。
- 网站状态区分未启用、等待上线、下发中、已写入待核对与浏览器确认生效。
- 未开机学生机保留网站待下发任务，上线后自动重试；键鼠操作不再覆盖该任务。
- 失败设备重选保留完整名单，成功设备仅取消勾选；健康页范围不再受网站策略勾选影响。
- 手机端统一配色，消息使用独立弹层，按学生保存输入草稿。

## 学生端

- 课堂助手以更紧凑的右下角窗口展示，精简无关课堂信息。
- 修复键鼠组件因单次管道连接异常退出的路径，并增加可定位异常的日志。
- 降低本机管道对端程序路径查询所需权限，保留原有安装位置与会话校验。
- 网站限制独立于键鼠状态；保留策略归属、签名校验及键鼠短租约恢复机制。

## 下载与升级

教师电脑安装 Teacher，学生电脑安装 Student；下载后可使用 SHA256SUMS 校验文件。
手机页面由教师端提供，升级教师端后重新打开手机页面即可。
键鼠组件修复需要升级学生端。课堂快捷管控仍按本次试点构建开放，真实锁定与恢复效果以目标电脑验证结果为准。
