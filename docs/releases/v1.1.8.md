## Veyon Campus 1.1.8

- Teachers can have one-to-one classroom conversations with students from the desktop and paired mobile controls. Messages show student names, support multiline keyboard input, delivery status, and retry without losing drafts.
- Classroom seating supports drag painting to assign groups of seats. Application policy setup adds common application selections and a classroom system baseline shortcut.
- Student updates now record durable transaction state, preserve the previous setup before installation, verify the new setup and Agent, and recover or roll back interrupted updates. Installer packaging includes a versioned update helper for this recovery flow.
- CI now creates unsigned, read-only file inventories for update planning. These inventories are diagnostic artifacts; supported distribution remains the signed full installer.
- Mobile teacher controls and user-facing copy have been refined.
