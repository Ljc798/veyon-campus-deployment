# Veyon Campus 1.1.11

- Classroom seat maps now keep each student's computer number attached to that seat when the Veyon computer list changes. Teachers can assign numbers to new seats, and printed seating charts show the configured computer numbers.
- Teacher and student installers coordinate with in-app updates so a manual install or uninstall cannot interrupt an active update. Process cleanup now handles protected or inaccessible processes safely, and update-helper cleanup failures are logged for diagnosis.
- Classroom sessions and mobile controls now resolve seats against each room's configured computer numbers, including non-consecutive numbering.
