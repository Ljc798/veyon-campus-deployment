# Veyon Campus 1.1.72

这一版是「教师端静默更新学生端」的验证基线：学生端版本号推进到 1.1.72，
用来在真实机器上复测 1.1.71 → 1.1.72 的一键更新链路（签名命令、局域网下载、
原子替换、版本读回）。

## 1. 版本推进

- StudentSetup / TeacherConsole 源码版本为 `1.1.72`，安装包按既有签名流程发布，
  签名公钥与发行渠道与 1.1.71 一致，因此 1.1.71 的教师端可以直接把 1.1.71 的学生端
  升到这一版，不需要先升级教师端。
- 更新仍是整包替换：教师端下载完整签名 StudentSetup，学生端在本地做「旧目录备份 →
  安装 → 版本读回 → 失败回滚」，不依赖逐版本补丁链，跨版本直跳同样成立。

## 2. 没有行为变化的部分

- 课堂控制、网站策略、配置同步的协议与 1.1.71 完全相同；本版不改变判定逻辑，
  便于把「更新链路」本身和「策略行为」分开观察。
- 维护事务、身份固定与导出报告的字段保持兼容，1.1.71 导出的报告仍可直接对比。

## 3. 验证建议

1. 在一台学生机安装 1.1.71 学生端，确认教师端能读到它的运行版本。
2. 教师端「设备与更新 → 一键静默更新全部学生端」，目标选择到该学生机。
3. 更新结束后核对：学生端版本读回为 `1.1.72`、事务状态为 `committed`、
   配置同步读回一致；若失败，导出报告里应能看到具体阶段与原因。
