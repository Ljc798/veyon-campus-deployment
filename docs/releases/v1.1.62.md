# Veyon Campus 1.1.62

## 变更

**修复“学生 Agent 永远更新不了”：被旧版本中断的更新事务会自动结束。**

旧版学生端在更新 Setup 时，如果把旧版安装目录保留下来、新版还没装上就中断了，事务会停在
`PreviousSetupPreserved`。此后每次点“更新/修复 Student Agent”，恢复任务都会让**事务里记录的那一版旧 Agent**
去执行回滚；而旧 Agent 的状态机里没有 `PreviousSetupPreserved → RollbackPending` 这条转换，
于是每次都抛“学生更新事务状态不能从 PreviousSetupPreserved 转为 RollbackPending”，
界面只会显示“仍处于 PreviousSetupPreserved，请稍后重试”，重试永远无效。

本版在 StudentSetup 里加了收敛逻辑：

- 事务停在 `PreviousSetupPreserved`，且**当前已安装的 StudentSetup 版本已经高于事务里的版本**（说明这台电脑后来装过更新的版本）、当前 Agent 不低于事务原版本、且 Agent 版本与配置指纹健康读回通过时，
  把这条旧事务标记为 `Superseded` 并清理它的恢复材料；
- 不卸载、不回滚、不改动现有安装，只清掉已经不可能执行的那条旧记录；
- 恢复任务里也加了同样的分支，将来旧任务重启后也能自行收敛。

**减少“安装成功后仍弹窗报 Maintenance 服务安装失败”的误报，并把真实原因写进日志。**

安装到最后一步时，`CurStepChanged` 在独立 Maintenance 服务启动失败时会 `RaiseException`，
弹出 `Runtime error … 无法安装或启动独立 Maintenance 后台服务。安装已停止`。本版：

- 安装/启动后用 `--verify-running` 复核（最多重试 12 秒，服务刚启动时会短暂处于 START_PENDING），
  服务实际在运行就不再误判为失败；
- 失败时在安装日志写出 `control=…, state=…` 两个退出码，能区分“注册失败 / 启动超时 / 权限不足”；
- 服务注册的可执行文件若已被上一轮失败安装删掉，控制命令回退到版本目录里的程序，
  避免卸载时出现“Maintenance 后台服务无法安全卸载”。

**仍然保留“服务起不来就停止安装”的判断**：上一轮把它降级为警告后，卸载流程出现
`Student uninstall smoke test failed (exit 1)` 回归（半注册的服务让卸载预检查拒绝继续），所以这次不动这个开关，
只消除误报并补齐诊断。

**恢复失败不再只说“请稍后重试”。**

失败提示现在会附带事务里的 `LastError` 和 `agent-startup.log` 的最后一条异常；两者都没有时，明确提示“恢复任务没有拿到更新锁，请重启后重试”。
恢复任务拿不到机器更新锁时也不再静默返回，会先写一条日志。

## 注意

- 这个修复属于 **StudentSetup 安装包自身**，需要重新安装 1.1.62 的 StudentSetup 才会生效；学生 Agent 版本仍为 0.4.58，未变化。
- 已经卡住的电脑，装完 1.1.62 再点一次“更新/修复 Student Agent”即可自动收敛；也可以按 `docs` 里的手工步骤先清掉旧事务。
- 网站黑白名单附带的“禁止 Edge 下载 / Edge 冲浪游戏 / Chrome 小恐龙”只在 **1.1.45 及以后的学生端**写入；Agent 仍为 0.4.4x 的机器重推名单不会出现这三条限制。
