# Veyon Campus 1.2.5

1.2.5 做两件事：教师端可以一键关掉学生的无线网卡、锁住任务栏上的网络入口；手机端单台的「锁定键鼠」不再必然失败。

## 变化

### 网络开关

- 教师端课堂设备卡片新增四个动作：**禁止修改网络设置**、**允许修改网络设置**、**关闭 WiFi**、**恢复 WiFi**。都走教师端签名指令，学生端验签后执行，回执带签名状态。
- 「禁止修改网络设置」把 `DisableControlCenter` 写到真正生效的位置（`HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\Explorer`，用户策略），并对每个已登录用户的配置单元写 `DisableControlCenter=1`、`HideSCANetwork=1`，任务栏和快速设置里的网络入口一并隐藏；同时清理旧版本写在从未生效的位置上的残留值。
- 「关闭 WiFi」直接停用无线网卡，默认 10 分钟后由学生端按自己的时钟自动恢复；即使这期间教师端关闭或断线，机器也一定会自己恢复。
- 旧版学生端不认识这条协议时会明确回「此 Student Agent 尚不支持网络开关命令，请先更新学生端」，不会静默失败。

### 手机端键鼠锁定

- 修掉一个只在手机上出现的失败：定时锁定必须带 30–600 秒的重启宽限，桌面端一直传 45 秒，手机端只发时长、宽限留在 0，于是每次签名都被判「InputGuard 命令版本、身份、动作、租约或有效期无效」。现在缺失或越界的宽限会被夹进合法区间，手机和桌面走同一套结果。
- 全班「限时锁定键鼠」本来就不走持久化租约，行为不变。

## 说明

- **教师端和学生端都要升到 1.2.5**：网络开关指令由学生端 Agent 执行，内置 Agent 版本为 0.4.76，旧 Agent（0.4.75 及更早）收到指令只会回「不支持」。
- 执行「关闭 WiFi」的机器在恢复前会短暂失联，这是预期行为；不要在学生正在提交作业时使用。
- 1.2.4 的身份自动更新、1.2.3 的卸载与网络加固修复都仍然有效，不需要回退。
