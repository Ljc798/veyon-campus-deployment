# Veyon Campus 1.1.76

修正 1.1.75 的诊断判定：**签名通过、只差身份固定**也算“学生端信任这个校区”。

## 为什么改

实测一台学生机：用 `智学前程-1019-3` 的密钥请求时，学生端回的是
“Agent 回执签名有效，但身份尚未由教师核对并固定”，而不是 409。
这说明学生端认的是这个校区；1.1.75 只把 `Succeeded=true` 当成命中，会把这种情况漏掉，
得出“没有任何校区匹配”的错误结论。

## 现在的判定

- 命中条件：签名回执有效（`Succeeded`）**或**取到了可核对的 Agent 身份（`IdentityCandidate`）。
- 命中一个且与当前不同：自动切换校区标识，并提示“请先在设备健康里核对并固定身份，
  再点一键静默更新”。
- 命中多个：全部列出，由你固定在学生端实际使用的那一个。

## 附：真实的 409 根因

学生 Agent 只认一个校区策略签名根。教师机上一旦存在多个校区标识（每个对应一把密钥），
用错校区的密钥签名，学生端就会用 409 回“没有任何当前或过渡期策略信任根验证通过”。
本版把“学生端到底认哪个校区”变成一键可见，不需要再猜。

学生端行为未变，1.1.71 起可直升。
