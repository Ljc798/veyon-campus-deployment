# Veyon Campus 1.1.78

界面精简与网站功能介绍，同时带入本地已完成的文档中心与策略修复。协议、签名、身份固定与更新事务逻辑均未改动。

## 1. 教师端：删掉重复文字

按「每个词都要有用」的原则，删除了 7 个视图里 26 行冗余文案与多余控件，主要是：

- 课堂概览 / 设备健康卡片里复述标题的第三行小字（保留「未确认的目标」「无回执不等于离线」等状态区分）；
- `Student Agent`、`InputGuard`、`Guard` 等实现黑话 ToolTip；
- 与输入框提示重复的 `Enter 发送 · Shift+Enter 换行`（合并进输入框占位文字）；
- 与按钮文字重复的「打开学生消息」ToolTip；
- 导航卡复述主标题的副标题、策略页「演示功能…验收」套话、Edge 实时同步铺垫说明、重复两遍的「先勾选确实需要限制的学生账户」；
- 座位图 100 余字操作手册与重复的预览说明，压缩成一行；「无编号座位不会生成电脑」这条结果规则保留。

安全边界一条没动：危险操作确认、失败原因、状态可信说明、版本与身份指纹、AppLocker 效果边界全部原样保留。没有改动任何绑定、事件、可见性条件或校验逻辑。

## 2. 网站：修好「你可以从这里开始」

关于页侧栏的图标方框压到了文字上。两个 CSS 原因：

- `.principle` 第一列只有 `35px`，而 `.feature-icon` 是 `47px`；
- `.principle span` 命中了图标元素自身（`<span class="feature-icon">`），把 `display: grid` 的居中覆盖掉了。

现在列宽改为 `47px`、间距 `16px`，并把说明文字选择器收窄为 `.principle > div > span` / `strong`，图标恢复居中，标题与说明字号提到 13px，不再挤在一起。

## 3. 网站：新增课堂管控能力

「工具介绍」页新增能力区块，首页加入口：

- 网站黑白名单（阻止名单 / 白名单 / 组合模式）；
- 阻止 Edge 下载文件，关闭 Edge 冲浪游戏与 Chrome 小恐龙；
- 软件运行限制与系统限制，解除时只撤销本工具写入的规则。

文案沿用教师端已经验证过的措辞：效果以逐台回执为准，未生效时重启学生浏览器并重新下发名单，不承诺即时生效或完全封禁。新增内容全部是静态字符串，没有把任何外部输入拼进页面 HTML。

## 4. 一并带入的本地改动

文档中心上线并可从教师端侧栏打开；修正策略页在旧域名升级无法保存时的可读性；清空本机配置时一并丢弃中断的学生更新事务；网站策略改为提示重启学生浏览器，不再承诺即时生效；配置包/预设存储与卸载、重置流程的若干修复。
