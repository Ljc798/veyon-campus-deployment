# Veyon Campus 1.1.77

本版为 2026-11 一轮问题的**正式修复版**：学生配置包、Veyon 地点、校区密钥、更新通道四条线一起收口。

## 1. 校区标识就是密钥的名字

学生 Agent 只信任一把“校区策略签名密钥”，它在生成学生配置包时写进包里的。
教师端的“校区标识”就是这把密钥的名字，**换一个标识就等于换一把密钥**，
而学生机不会自动认识新密钥——之后推策略、读状态、发更新全部被 409 拒绝：

```
没有任何当前或过渡期策略信任根验证通过。
```

## 2. 生成配置包时不再偷偷建新密钥

以前：填一个没见过的校区名 → 直接新建一把证书 → 学生机不认 → 全线 409。

现在：`ResolveEnrollmentCampus` 先看本机已有校区

- 本机**只有一个**签名校区：直接复用它生成配置包，界面提示“已复用本机唯一的校区标识 X，
  没有新建密钥”；
- 本机有**多个**校区、且你填的名字不在其中：拒绝生成并列出已有校区，
  要求先选定学生机实际使用的那一个；
- 本机一个都没有：仍是首次部署，允许新建。

## 3. 配套的两处改动

- 1.1.75 增加的“诊断学生端信任的校区”按钮，1.1.76 修正了判定（签名有效、仅缺身份固定也算命中）；
  本版沿用，可一键找出学生机认哪个校区。
- 生成配置包复用校区时，界面上的校区标识同步切换，避免包和界面用的不是同一把密钥。

## 4. 操作提示

- “学生机认哪个校区”由**学生机**决定，不由教师端决定。教师端可能存在多个历史校区标识，
  正确做法是先点“诊断学生端信任的校区”，让它告诉你学生机实际信任哪一个，再切过去；
  不要靠改校区名或新建证书去“碰”。
- 策略草稿（黑名单、模式）按校区标识分别存储，切换校区后需要确认名单仍在当前标识下。
- 需要换校区时，请先确认学生机能否用新密钥验签，再决定是否生成新包。
- 学生配置包为 schemaVersion 7 时包含 8 个文件（多一个教师连接根证书），
  必须配套 1.1.74 及以上的 StudentSetup；更早的安装器会报“文件数量不符合校区配置包格式”。
