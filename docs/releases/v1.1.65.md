# Veyon Campus 1.1.65

## 变更

**手机端去掉“教师端策略预设”，只留“网站名单”。**

手机页面原本并列两块：上半是“教师端策略预设”（下拉框常常是空的，还会带一段很长的说明），
下半才是真正要用的“网站名单”。教师电脑上没有保存过预设时，上面那块只会显示
“教师端尚无已保存预设”，按钮永远是灰的——手机端不需要这个概念，本版直接隐藏整块，
只保留：选择访问方式 → 确认名单与截止时间 → 应用/解除。

**首次推送不再被“没有策略版本”卡死。**

手机端应用网站限制前要求“每台电脑都已读到网站策略版本”，没读到就不发请求并提示“刷新状态”。
但一台从未被下发过网站策略的电脑本来就没有版本号，于是刷新多少次都点不动“应用阻止名单和例外”。
本版两处一起改：

- 手机端不再把“版本号为空”当作阻塞条件；
- 教师端在手机没带版本号时不再拒绝请求，而是用**刚刚重新读取的签名状态**生成 `expectedRevision` 写进签名策略，
  Agent 仍然只在版本一致时才落盘，冲突保护没有放松。

**手机上每个按钮旁边都能看到“为什么还不能点”。**

- 进入“限制”页或切换到批量模式时会自动刷新所选电脑状态，不用再展开“电脑状态”手动点；
- 应用按钮下面直接给出原因和“先刷新电脑状态”按钮：
  “学生身份需核对：请到教师端‘设备健康’点一次‘核对并固定身份’” / “有学生电脑没有回应” / “学生 Agent 版本过旧”；
- 访问方式、“下一步”等说明压到一行，去掉重复的长段落。

## 注意

- 本版只改教师端手机页面与教师端接口，学生 Agent 仍是 0.4.58，不需要重装学生端。
- 手机页面由教师电脑本地提供，更新教师端后刷新手机页面（或重新扫码进入）即可看到新界面。
- 包含 1.1.64 的课堂/设备通道直连回退与身份核对入口。
