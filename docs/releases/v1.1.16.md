# Veyon Campus 1.1.16

- Simplified classroom communication by removing the separate classroom location mapping controls.
- Improved device health readability with color-coded statuses, compact diagnostic alerts, and student computer rows that wrap safely on narrow layouts.
- Clarified the Veyon service and Edge policy actions with more direct labels and help text.
- Improved Student Agent update and repair so an existing valid local Agent configuration can be reused without first loading a campus package.
- Improved computer identity matching: existing Veyon names and numbers are preserved, while newly added computers continue from the highest existing number.
