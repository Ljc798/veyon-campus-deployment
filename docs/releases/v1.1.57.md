# Veyon Campus 1.1.57

## 本版本内容

- 版本推进到 1.1.57，用于验证「安装过一次之后即可持续静默更新」这条链路（1.1.56 → 1.1.57）。
- 学生 Agent 保持 0.4.58，不涉及 Agent 行为变化。

## 未包含（已撤回）

原计划在本版把「独立 Maintenance 服务安装失败」从致命错误降级为警告。该改动在安装器的卸载冒烟测试中引入了回归：

```
Student uninstall stopped: Maintenance Windows service could not be removed.
InitializeUninstall returned False; aborting.
```

回归出现在卸载路径而非安装路径（安装阶段服务注册与启动均正常，降级分支未被执行），因此整体撤回，待单独排查后再发布。当前版本安装器行为与 1.1.56 完全一致。

## 升级说明

- 1.1.56 的学生端可以直接通过教师端「一键静默更新全部学生端」升级到本版本，无需手动干预。
- 1.1.44 及更早、以及 1.1.48–1.1.55 的机器仍需先手动安装一次 1.1.56 或更新版本：前者在重命名安装目录前不停止自身进程，后者的更新前置校验存在 2 秒超时误判。
- 安装器可能仍会在「独立 Maintenance 服务」步骤弹出 `Runtime error (at 93:1505)`。该提示是误报：文件已经全部写入，学生端可正常使用与更新，点「确定」跳过即可。

自动发布流水线负责正式安装包构建、完整性校验（SHA-256）和发布检查。**本版本未做 Windows Authenticode 代码签名**，首次运行安装包时 SmartScreen 可能提示「未知发布者」，需要点「更多信息 → 仍要运行」，这是预期行为，不是安装包损坏。
