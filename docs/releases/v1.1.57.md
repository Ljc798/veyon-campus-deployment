# Veyon Campus 1.1.57

## 修复：安装器不再因独立 Maintenance 服务失败而中断整个安装

学生端安装器在 `ssPostInstall` 阶段会尝试注册并启动独立的 `VeyonCampusMaintenanceService`。此前这一步失败会直接抛异常终止安装：

```
Runtime error (at 93:1505):
无法安装或启动独立 Maintenance 后台服务。安装已停止；请查看安装日志并重试。
```

这个问题有误导性：**文件其实已经全部写入**，StudentSetup 已经可用，Agent 也已在运行，但安装器报“安装已停止”，用户会以为是安装包损坏。

事实上独立 Maintenance 服务只是可选通道。没有它时，学生端通过签名的 Legacy Student Agent 通道收发更新与策略，功能不受影响（`maintenanceVersion` 为 `null` 时教师端会自动选择 Legacy 通道）。

现在的行为：

- 服务注册/启动失败**不再中断安装**，改为记录退出码到安装日志，并在完成页追加一行提示：
  「独立 Maintenance 服务未就绪；学生端仍可通过签名 Agent 通道正常接收更新。」
- 新增 `MaintenanceServiceDegraded` 状态，阻止失败恢复流程在“降级成功”的情况下把刚安装好的服务文件删掉。

## 诊断改进

- 服务控制失败时写明确退出码：`Maintenance service control did not succeed (exit code N).`，便于定位是注册失败、启动失败还是超时。

## 升级说明

- 1.1.56 的学生端可以直接通过教师端「一键静默更新全部学生端」升级到本版本，无需手动干预。这是验证“安装过一次之后即可持续静默更新”的版本。
- 1.1.44 及更早、以及 1.1.48–1.1.55 的机器仍需先手动安装一次 1.1.56 或更新版本：前者在重命名安装目录前不停止自身进程，后者的更新前置校验存在 2 秒超时误判。

自动发布流水线负责正式安装包构建、完整性校验（SHA-256）和发布检查。**本版本未做 Windows Authenticode 代码签名**，首次运行安装包时 SmartScreen 可能提示「未知发布者」，需要点「更多信息 → 仍要运行」，这是预期行为，不是安装包损坏。
