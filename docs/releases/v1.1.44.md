# Veyon Campus 1.1.44

- 地点和座位图新增学生时，教师端改为读取 Veyon `networkobjects dump` 的对象目录，避免配置导出触发 CRT R6031；地点、座位、姓名的导入仍会先检查冲突并核对结果。
- 学生端更新恢复会校验旧 SYSTEM Agent 的恢复任务绑定；安装器卸载、更新及 Agent 修复会先尝试恢复未完成事务，降低更新中断后无法更新或卸载重装的概率。
- Student Setup 更新到 1.1.44，Student Agent 更新到 0.4.56，确保学生机可收到 Agent 修复代码。
- TeacherConsole 1.1.44 继续启用课堂快捷管控试点；课堂一对一聊天使用当前 Agent 的 `classroom-chat.v1` 能力。

本版本需要教师端和学生端都更新后再进行局域网课堂验收。安装包构建通过不代表目标学生机上的更新恢复、Veyon 连接、课堂控制和聊天已经实机验收；快捷管控仍按试点指南逐步验证。
