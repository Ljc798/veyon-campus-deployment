# Veyon Campus 1.1.34

本版发布教师端、学生端和手机页面的界面与交互更新。

- 统一课堂控制、设备健康、策略与消息界面，减少重复提示与嵌套边框。
- 网站限制与键鼠锁定分别操作；键鼠状态不可读取时不阻止网站限制。
- 展示网站未启用、等待上线、下发中、已写入待核对及浏览器确认生效等状态。
- 未开机学生机保留网站待下发任务，上线后自动重试，键鼠操作不会覆盖网站任务。
- 失败设备重选保留完整名单，成功设备仅取消勾选；健康页范围不再受网站策略勾选影响。
- 手机端统一蓝色配色，消息使用独立弹层，并按学生保留输入草稿。
- 学生课堂助手更紧凑，在右下角展示。
- 修复键鼠组件因单次管道连接异常退出的路径，增加异常日志并降低对端路径查询所需权限。
- 修正 Windows 发布流水线对成功检查输出的换行识别问题；保留所有检查与门禁。

教师电脑下载 Teacher，学生电脑下载 Student；使用 SHA256SUMS 校验下载文件。
升级教师端后重新打开手机页面即可更新手机界面；键鼠组件修复需要升级学生端。
课堂快捷管控仍按本次试点构建开放，真实锁定与恢复效果以目标电脑验证结果为准。

`v1.1.33` 为未发布安装包的候选源码标签；本版不覆盖该标签。
