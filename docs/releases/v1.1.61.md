# Veyon Campus 1.1.61

## 变更

**课堂快捷管控（网站限制 / 锁定键鼠）随所有正式版教师端一起提供。**

此前该能力由编译期开关 `VEYONCAMPUS_CLASSROOM_QUICK_CONTROL_PILOT` 控制，默认关闭，只有带 `-ClassroomQuickControlManualTest` 打的试点包含 `CLASSROOM-QUICK-CONTROL-PILOT.txt` 标识；发布流水线也只在 `v1.1.33` 到 `v1.1.45` 的 tag 上启用。所以从 1.1.46 起的所有正式版，课堂页都会显示：

> 当前版本未启用快捷管控试点。课堂名单、状态同步和手机策略仍可使用。

本版把 `VeyonCampusClassroomQuickControlPilot` 的默认值改为 `true`，并移除流水线里的 tag 白名单：

- 所有 TeacherConsole 构建默认带有该能力，不再需要单独的试点包；
- `scripts/package-windows-offline.ps1 -ClassroomQuickControlManualTest` 保留为本地显式开关；
- `ValidateClassroomQuickControlPilot` 由「非教师端角色直接报错」改为忽略，这样共享的默认值不会让 StudentSetup 构建失败（学生端本来就不含这个宏）。

课堂页现在可以使用：启用网站限制、锁定键鼠、恢复全部学生电脑、自动解除。

## 注意

- 课堂内的网站限制与键鼠锁定会**真实修改学生机状态**，每台都按签名回执核验；解除入口始终可用。
- 该能力在 1.1.46 之后的正式版里一直处于关闭状态，本次相当于重新启用，建议先在 1–2 台学生机上验证一轮再整间教室使用。
- 学生机不需要更新教师端以外的组件：课堂网站限制走既有网站策略通道，键鼠锁定走 InputGuard，1.1.56 之后的学生端已全部具备。

## 验证

- TeacherConsole 与 StudentSetup 分别编译，均 0 错误（默认值改动不会破坏学生端构建）。
- Core / App / Checks 编译 0 错误。
