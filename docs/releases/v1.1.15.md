# Veyon Campus 1.1.15

- Improved classroom seat-map editing with continuous add gestures, clear highlighting for newly added seats, safer removal of existing seats, and a cancel action that restores the layout from before editing.
- Seat maps now support moving a student to an empty seat even when that seat has no computer assigned. Classroom-to-student mappings are clearer, and target computers display four per row.
- Improved mobile controls: website block and allow lists can be edited on the phone and saved back to the teacher computer; the greeting uses the paired device name; status panels and expiry date/time fields fit narrow screens more reliably.
- Fixed installer/update coordination so manual install and in-app update flows can shut down and replace the running application safely.
