# 手机控制使用指南

手机端需与正在运行的教师控制台处于同一可互通的校园网络；教师控制台关闭或手机离开该网络后，手机无法操作。

## 首次连接

1. 在教师电脑打开正确校区的教师控制台，进入“手机控制”，点“启动服务”。点“生成连接二维码”，用手机相机扫码。教师控制台需要保持运行；活动课堂会自动启动服务。
   教师电脑和手机必须处于同一可互通的校园网。若教师控制台运行在虚拟机里，NAT 网络通常会挡住手机直连；请将虚拟网卡设为桥接，并确认手机能访问教师窗口显示的 LAN 地址。
2. 扫码后会打开连接说明页。点“下载安全证书”并按手机提示安装；安装前核对页面安全码与教师电脑“连接安全码”一致，不一致时不要继续。
3. iPhone 还要到“设置 → 通用 → 关于本机 → 证书信任设置”开启“完全信任”；Android 按手机提示允许安装。设置完成后，回到说明页点“打开安全连接”。
4. 手机上的 8 位连接码会自动填入；没有自动填入时，输入教师电脑显示的连接码。填写手机显示名称后点“申请连接”。
5. 教师在电脑的“等待确认的手机”列表核对名称，再点“允许所选手机连接”。得到允许后，手机就会连接成功。若请求被拒绝、过期或连接码已用，请让教师重新生成连接二维码。

### iPhone 页面无法打开时

如果手机无法打开连接页或安全连接，请依次检查手机和教师电脑是否处于可互通的校园网络、教师端手机控制服务是否运行、手机证书是否按连接页提示信任，以及校园网络或 Windows 防火墙是否阻止设备互通。仍有问题时，记录错误提示和教师端版本，联系技术支持。

## 查看和切换策略

首次操作每台学生电脑前，先在教师控制台的“读取并核对 Agent 身份”中逐台查看指纹，并与学生机部署记录核对后固定身份。首次信任或密钥变化须教师明确批准；密钥变化时先现场复核，不能直接沿用旧信任。

手机从教师电脑的 Veyon 机房目录读取目标，只能选择当前校区预先保存的网站、应用或长期系统策略。保存应用或系统预设前，先在教师端应用限制或系统限制页设置电脑范围并读取账户；清单按“电脑名 · 账户名”显示，默认不勾选，教师可逐项选择或明确全选。随后在手机控制窗口保存预设；保存区会显示可用电脑映射数量、前五个电脑名称、完整名称清单、账户选择覆盖数，并可展开核对已选账户名称。名称缺失时显示“未命名电脑”，不显示 IP；手机不会显示 SID。同校区、同类型和同名称的预设已存在时，无论从教师主界面还是手机控制窗口保存，教师确认后才会替换本地预设；教师主界面的组合策略确认会同时列出当前电脑范围和账户映射摘要。取消会保留原预设，已应用到学生电脑的策略不会因此更改。旧版只保存共用账户的预设仍可用于单台电脑；要对多台电脑使用，请在教师端重新保存。教师在保存系统预设前还要阅读软件安装限制的影响并确认。先选预设和电脑，再读取状态；“签名身份已验证”只在学生 Agent 签名、校区/目标身份和本次状态随机数都通过核验后显示，并包含 Agent 版本、状态采集时间、策略模式、版本和到期时间。系统状态逐项显示六种设置及版本；无法连接、未固定身份或验签失败时显示未知/需复核，不推断限制效果。

网站限制方案在手机上会直接说明操作：“阻止指定网站”会拦截名单中的网站；“只允许指定网站”会拦截其他普通网站；组合设置会阻止指定网站，并可放行例外名单中的网站。组合设置名单以外的网站仍可正常访问。

六项长期系统策略为锁定 Windows 默认壁纸、禁止修改日期/时间/时区、限制网络设置、限制软件安装、禁止账户管理及本人改密、限制 Control Panel/Settings（按桌面当前开关，默认关闭）。系统策略不会自动到期；手机启用前会列出具体项目并要求确认，解除会请求学生机恢复本工具原先保存且仍由本工具拥有的设置。手机不能编辑学生 SID、策略内容或密钥。Agent 接受回执不代表系统效果已经实机验证。

启用或解除前手机会再次要求确认。应用“阻止”预设先推送审核模式并读取逐台统计；教师阅读统计后还要再次确认才会发送阻止策略。策略、审核和清单回执须由已固定身份的 Agent 签名，并匹配本次随机数、校区和请求正文摘要；不匹配时显示需复核。成功回执只证明该 Agent 接受了本次请求，不代表浏览器页面或应用启动效果已完成实机验证。部分电脑未确认时，可在结果区只重试未确认的电脑。

## 课堂求助

活动课堂期间，教师桌面和已连接手机都会自动显示学生 Companion 发来的求助，并可直接回复。学生只需按“需要老师帮助”；电脑身份、课堂和网络地址由 Teacher 与 Student Agent 自动确定。收到教师回复后，学生在原按钮位置按“标记已解决”，教师桌面和手机会同步显示“已解决”。消息只在校园 LAN 和当前课堂内暂存，不进入 CloudBase，也不保存为聊天记录。

## 全班通知

活动课堂期间，教师可在桌面或已连接手机的“课堂互动”区域输入一条通知并发送。系统自动使用当前课堂目标，不要求再选电脑或网络；在线学生端会显示通知。通知最多 500 字符、两分钟后失效，不提供回复和历史记录。页面报告已提交的目标数，不代表学生已读。

通知可包含一个完整的 HTTP(S) 网址。学生端显示“打开课堂网址”后，由学生点击并通过电脑默认浏览器访问；已连接手机的通知卡片也可直接点击链接。多个网址或无效网址仍按普通文本显示，不会自动打开。详见[课堂共享链接指南](课堂共享链接使用指南.md)。

## 课堂屏幕巡视

活动课堂期间，打开手机底部的“看屏幕”。点“开始查看全部”后，页面会显示本堂课已关联的所有座位，最多 150 个；不需要逐台选择。卡片显示学生姓名或电脑名；资料缺失时显示座位号。手机只读取当前屏幕上可见的卡片，目标由当前课堂和座位关联确定。

普通查看提供“省流 / 标准 / 清晰”三档画质和 3、5、10、15、30、60 秒自动更新间隔，默认省流、每 10 秒。画面越清楚，用的流量越多；调整设置会重新读取座位画面。页面只读取手机当前可见卡片的单张画面，不录制或保存历史，也不是连续视频。

需要看单台电脑时，点对应座位卡片上的“看实时画面”。画面由教师端读取并发送到手机，约每 3 秒更新一次；不会在教师电脑上打开 Veyon 监看窗口。

点“停止查看屏幕”、离开“看屏幕”页面或手机切到后台时，手机会停止读取并通知教师电脑关闭画面。若手机断网，教师电脑会在 60 秒没有收到读取请求后自动关闭；结束课堂或座位关联变化时也会立即停止。此功能仍在试用阶段；还需在真实教师机、学生机、Android/iPhone 和校园网络上检查画面质量、连接和电脑负载。

接口字段及调用约束见[屏幕巡视 API 契约](../specs/classroom-screen-preview/api.md)。

## 手机策略范围

手机打开控制页后，如果活动课堂中的目标电脑与教师机 Veyon 清单逐台匹配，页面会默认选择本堂课电脑并收起范围列表。展开“更改电脑范围”后可自行调整。当前没有活动课堂，或目标与清单不能完整匹配时，系统不会代选电脑；请先核对范围再查看状态或启停限制。策略预设默认显示第一项，仍需教师确认启用或解除。

## 断开手机和停止服务

教师可在桌面窗口解除已连接手机、拒绝待确认请求、删除手机策略预设或停止服务。解除后，该手机不能继续控制教师电脑。手机也可以点“退出”清除本机保存的连接记录；退出不代替教师端解除连接。

手机控制仅在教师电脑所在的本地校园网络中使用。请遵循学校网络管理要求，不要把教师控制端直接暴露到公网。

手机控制记录保存在教师用户本机的 `%LOCALAPPDATA%/VeyonCampus/MobileControl`。教师根证书私钥保存在 Windows 当前用户证书存储关联的不可导出 CNG 密钥中；不要手动删除证书或密钥。根证书轮换后，所有手机都需要重新安装并信任新证书、重新配对。
