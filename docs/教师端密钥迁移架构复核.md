# 教师端密钥迁移架构复核

更新日期：2026-10-08。本页梳理教师端换机涉及的密钥类型、已确认的策略决策和仍待实现的可恢复边界；项目级完成状态仍以[开发路线与任务清单](开发路线与任务清单.md)为准。决策已确认不表示迁移功能或 Windows 验收已经完成。

## 架构结论

教师机身份由多种用途不同的密钥组成，不能用一个“备份教师密钥”的操作覆盖全部恢复需求。Veyon 校区身份密钥由 Veyon 管理；网站、应用和系统策略签名密钥由本项目的 Windows 用户证书/CNG 存储管理；手机控制 CA 用于手机 HTTPS 配对；学生 Agent 身份密钥则属于单台学生电脑。Developer Release 和 CloudBase 服务凭据也不属于教师机迁移包。

当前代码对网站、应用和系统策略 CNG 密钥均设置 `CngExportPolicies.None`。负责人已确认保留不可导出策略：换教师机时创建新的三类策略签名密钥，并通过受控学生端信任更新轮换公钥；不能靠复制证书文件、用户注册表或普通用户目录实现私钥恢复，也不把新密钥改为可导出。具体批量/逐台信任更新、失败恢复和 Windows 验收仍需设计与实现。

## 密钥清单

| 密钥 | 当前用途与存储 | 迁移边界 |
| --- | --- | --- |
| Veyon 校区身份密钥 | Veyon 的配置密钥目录保存校区公私钥；Teacher 通过 `VeyonTeacherKeyProvisioner` 复用已有密钥对，只导出公钥到学生配置包。 | Veyon CLI 提供 `authkeys export/import`，其中可指定 `campus/private`；项目没有加密封装、受保护临时导出和新机指纹读回流程。公开文档中提到的私钥导出文件不能直接当作加密备份。 |
| 网站策略签名密钥 | `CurrentUser\My` 证书库及当前用户注册表指纹；RSA CNG 密钥，3072 位，导出策略为 `None`。 | 不能恢复现有私钥。策略由该密钥签名；若决定重建，需要重新分发学生端信任并验证新公钥。 |
| 应用策略签名密钥 | 与网站密钥共用存储实现，但使用独立校区命名空间。 | 与网站密钥相同：私钥不可导出，公钥信任独立；换钥需要更新学生端配置包中的应用策略公钥。 |
| 学生机系统策略签名密钥 | 与网站密钥共用存储实现，使用另一独立命名空间及版本计数器。 | 私钥不可导出，不能借网站或应用策略密钥代签；换钥需要更新学生端系统策略信任。 |
| 手机控制 TLS 根证书 | 当前教师 Windows 用户证书库中的根证书；CNG 私钥不可导出。手机配对时信任桌面显示指纹对应的根证书。 | 换教师机可生成新根证书，但必须让已配对手机重新扫描/核对指纹并由教师批准配对；不需要把旧 CA 私钥复制到新机器。 |
| Student Agent 身份密钥 | 每台学生机的 Agent 本机存储，用于签名状态与回执。 | 是设备身份，不能放入教师迁移包，也不能把一台学生机的密钥复制到另一台学生机。 |
| Developer Release 私钥 | GitHub `production-release` 受保护 Environment secret，另有离线加密备份；属于发行签名。 | 按[第三方许可与发布依赖清单](发布依赖与第三方许可清单.md)管理，绝不纳入校区/教师迁移资料。 |
| CloudBase 服务密钥 | 仅用于服务端/受保护发布环境访问 CloudBase。 | 不进入教师机迁移资料；按服务端凭据轮换和发布环境流程维护。 |

## 已确认的首版迁移边界

1. **保留策略 CNG 私钥不可导出，并在换机时轮换信任。** 网站、应用、系统策略三类新教师私钥分别重新生成；通过受控流程把对应的新公钥信任更新到学生 Agent/配置状态，验证每类签名均可工作后，再退役旧教师机。不要把 `ExportPolicy` 从 `None` 改为可导出，也不要把三类信任合并。
2. **单独设计 Veyon 密钥的加密备份。** 从 Veyon CLI 导出私钥后，应用必须在受限临时位置处理，并在任何移除旧机之前验证新机导入结果、校区 KeyId 和公钥指纹。最终备份应使用认证加密并存入学校批准的加密介质；明文导出不得进入 ZIP、云端、日志或普通共享盘。Windows/NTFS 临时文件清理不能被描述为 SSD 上的安全擦除。
3. **手机 TLS 身份按重新配对恢复。** 新教师机创建新的 TLS 根证书，手机人工核对新指纹并重新配对；只有完成所有授权手机的重新配对后，才撤销旧根证书和旧设备。
4. **配置和密钥分开备份。** Veyon 配置、网络对象目录和教师账户私钥读取权限需要各自有可读回验证的恢复步骤。StudentSetup 的 DPAPI 状态快照不是教师私钥备份，也不能跨用户或电脑恢复。

## 当前代码缺口

`WebsitePolicyAgentInstaller.Install` 会检测已安装 Agent 的策略公钥变化：网站策略公钥或应用策略公钥变化会直接拒绝覆盖；系统策略公钥变化在学生机有活动系统策略时也会拒绝。Agent 配置每类只保存一个当前公钥，现有协议没有由旧信任根授权新公钥的轮换命令，也没有独立的本机管理员信任重置流程。因此，单纯生成新密钥并重新发布配置包不能完成换机。

轮换需分别保护网站、应用和系统策略的签名用途，不能用其中一种旧密钥代签其他用途的新公钥。还需保留学生机现有策略状态和版本、逐类读回新公钥指纹，并提供逐台结果和失败恢复。换钥授权/紧急恢复路径在设计确认前，不应修改公钥拒绝逻辑。

### 未选择的备选方案

单次加密归档 CNG 私钥需要让新密钥具备归档导出权限，并扩大私钥可被导出的能力；负责人已选择不可导出并轮换学生端信任，因此该方案不进入当前实现范围。后续如需重新评估，必须作为新的密钥策略决策单独审查，不能通过一般维护悄悄启用。
