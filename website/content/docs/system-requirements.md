官网当前下载页提供 Windows 10/11 64 位安装包。需要修改 Windows 系统设置的部署步骤应由学校授权的管理员账户执行。

电脑还可能受到域、组策略、移动设备管理或杀毒软件限制。即使系统版本符合，也不代表每项操作都能执行。遇到权限提示或管理策略提示时，先联系学校 IT，不要尝试绕过管理限制。

教师端还提供 macOS 构建，但 macOS 上可用的 Veyon 控制能力与 Windows 不完全相同；请先查看[教师端 macOS 能做什么](./mac-teacher.md)，并在现场核对当前版本。

## 运行前的检查

- 核对官网显示的安装包角色、版本和发布渠道。
- 确认学校允许安装与修改相关系统设置。
- 准备可恢复的测试电脑。不要首次就在上课或考试的电脑上试装。
- 记录系统版本、操作账户和完整提示文字，方便后续排查。
