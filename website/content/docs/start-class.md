开始课堂前先核对当前地点、学生名单和在线设备。人数或身份对不上时，先处理设备目录问题，不要直接向不确定的目标批量操作。

## 开始课堂前检查

1. 在课堂页面核对地点名称、电脑数量和学生姓名。
2. 对在线状态或身份存疑的设备，先到“设备与更新”读取状态。
3. 确认学生电脑都属于本次课堂范围，再使用页面的“开始课堂”操作。
4. 如果要推送网站限制，先检查名单和模式，再确认目标设备。
5. 课堂进行中查看逐台回执；离线设备应在恢复连接后重新读取状态。

## 开始课堂不等于已经限制

开始课堂与启用网站限制是不同操作。课堂状态显示正在进行，不代表任何限制已成功应用。需要恢复访问时按[下课恢复步骤](./end-class.md)逐台检查。
