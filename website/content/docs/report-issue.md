反馈时提供足以复现问题的信息，但不要公开真实学校、学生或设备的敏感资料。

## 反馈时请写明

请写明：

1. 使用教师端还是学生端，以及软件版本。
2. Windows 或 macOS 版本、操作发生在哪个页面。
3. 问题发生前做了什么、实际看到什么、预期是什么。
4. 完整错误文字、发生时间和是否重试过。
5. 若有截图或日志，先遮盖校区名称、学生姓名、电脑 IP、账户、指纹、公钥、令牌和密钥路径。

## 不要上传这些

不要上传校区配置包、证书、私钥、完整身份指纹或未脱敏的日志。你可以通过官网[问题反馈页面](/contact)查看项目提供的反馈方式。
