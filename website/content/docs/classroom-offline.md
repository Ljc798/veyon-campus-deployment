不要把离线期间发起的课堂操作当成已成功，也不要假设设备重新上线后会自动重放。教师端和学生端是否收到、执行和读回操作，应分别看状态。

## 重新上线后怎么处理

1. 先确认设备恢复网络并出现在正确地点。
2. 重新读取设备当前状态，检查现在是否已经有相关策略。
3. 根据最新结果决定是否发起新的操作。
4. 对新操作再次核对目标、有效期和逐台回执。

## 状态不清楚时怎么办

如果目标身份、当前策略版本或操作归属不清楚，先停止并交由管理员核实。重复推送可能让旧状态更难判断。
