如果你的 Windows 账户不能执行部署需要的系统操作，请联系学校 IT 或电脑管理员。不要尝试绕过管理员权限、域策略、组策略或学校的设备管理规则。

## 请管理员确认

管理员可以确认：

- 学校批准的部署账户和操作时间；
- 这台电脑是否受到域、MDM 或其他策略管理；
- 本次部署需要哪些操作，是否可以分步执行；
- 操作后如何验证并恢复电脑。

## 不要绕过管理员权限

即使可以输入其他管理员账户，也要先确认学校允许此操作，并确认配置资料来自本校授权教师。详见[安装前准备清单](./prepare-before-install.md)。
