打开官网的[下载软件页面](/download)，按电脑用途选择教师端或学生端安装包。教师电脑和学生电脑使用不同安装程序。

## 下载前后核对

1. 选择学校认可的下载渠道。
2. 核对页面显示的版本、文件名中的角色和 Windows 架构。
3. 下载完成后确认浏览器没有报告下载失败或文件被替换。
4. 首次安装先在可恢复的测试电脑上进行。

学生配置包不是安装程序。它应由本校授权教师生成或发布。不要使用他校配置，也不要通过聊天把私钥、证书或完整配置内容发给其他人。

当前页面的版本信息以网站同步结果为准。若下载页暂时不能读取最新信息，请稍后刷新或通过[问题反馈](/contact)报告页面提示；不要仅凭旧的截图判断版本。
