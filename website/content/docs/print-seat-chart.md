打印前先保存座位图，并核对电脑编号、学生姓名和座位位置。教师端可导出 HTML 座位表，再由默认浏览器打开打印。

## 操作顺序

1. 打开“地点与学生名单”，选择要打印的地点。
2. 检查座位顺序、行列、过道和学生姓名；未填写姓名的座位会按当前页面显示为空或未填写。
3. 保存座位图后，选择“打印座位表”并保存导出的 HTML 文件。
4. 在浏览器中预览版面，选择纸张方向、缩放和打印机，再打印或另存为 PDF。

纸张预览会受浏览器和打印机设置影响。若编号或姓名太小，可在打印预览中调整缩放或纸张方向，不要通过改动电脑编号解决排版问题。
