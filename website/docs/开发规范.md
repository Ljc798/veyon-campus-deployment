# 网站开发规范

本规范适用于 `website/` 下的产品网站与管理后台。网站独立于 `src/VeyonCampus.App` 中的 Windows 桌面程序开发和发布。

## 1. 目标与边界

- 页面介绍 Veyon Campus 的实际定位：面向校园机房的 Veyon 部署辅助工具。
- 网站可展示工具版本、使用文档、校区汇总指标和产品路线；不得暗示本地演示已经连接真实设备或云端服务。
- 当前网站原型是静态前端。后台身份认证、服务端 API、数据库、遥测采集、权限审计和线上发布均需独立设计和验收。
- App 版本 0.4.6 仍是 Windows 本地离线部署实验版。代码实现、自动检查和 Windows 实机验收需分别描述。

## 2. 技术约定

- 使用原生 HTML、CSS、JavaScript，避免为了静态页面引入不必要的运行时依赖。
- 所有站内页面采用同一域名和路径路由；链接使用以 `/` 开头的绝对站内路径，浏览器前进、后退和刷新均须可用。
- 页面结构语义化，表单控件具有可见标签；交互支持键盘操作和窄屏布局。
- CSS 设计变量集中在 `styles.css` 的 `:root` 中。品牌色优先使用深蓝 `#132E46`、青绿 `#187B70` 和浅色背景。
- 不从未经审核的第三方 CDN 加载脚本、字体或图片。新增依赖须记录用途、版本和许可证。

## 3. 页面与内容

- 公共页面负责说明产品、项目背景、使用步骤、反馈入口与隐私原则。
- 管理页面包含概览、校区、使用概况、趋势分析和设置；新增页面需要加入路由表、公共导航和本文件的路由清单。
- 文案以中文为主，版本号和技术名词保持与仓库文档一致。
- 任何统计数字、客户名称、校区名称、用户反馈或运行状态都必须明确区分真实来源与演示内容。演示数据不得作为实际用户或部署证明。
- 产品能力描述以根目录 `README.md` 与 `docs/README.md` 为准。未经桌面 App 实现和验收的能力应写成规划或待验收事项。

## 4. 数据与隐私

- 页面原型使用虚构的汇总数据，不包含真实个人信息。不得提交可识别个人的邮箱、姓名、设备名、IP、学校名单或密钥。
- 线上统计应采用明确告知、自愿启用、目的限定、最少收集、访问控制和可撤回设计；建议以校区和地区的汇总数据为默认视图。
- 地区应由用户主动选择或由校区管理员维护，不以隐藏的精确定位作为默认数据来源。不要采集课堂屏幕、浏览历史、文件内容或与统计目的无关的信息。
- 正式接入前需定义事件字段、去标识化方式、保存期限、导出与删除流程、管理员角色、审计记录及服务端访问策略。
- `localStorage` 只用于演示交互，不是身份认证、权限边界或真实数据存储方案。

## 5. 前端行为

- 路由变化后更新页面标题、选中导航状态，并支持浏览器历史记录。
- 搜索、筛选、区间切换、导出和表单操作需给出可见反馈；空结果需显示清晰的空状态。
- 表格内容应可读并允许窄屏滚动；颜色不能作为表达状态的唯一方式。
- 表单校验应在提交时告知具体问题，成功或失败均显示状态消息。
- 使用 `textContent` 或经过审慎处理的模板内容插入用户输入；不要把未经处理的输入直接拼接为 HTML。

## 6. 修改流程

1. 修改前确认改动属于网站原型，避免与 Avalonia 桌面端混淆。
2. 页面新增或改名时同步更新 `README.md` 路由表和本文件。
3. 运行 `python3 preview_server.py`，检查目标路由直达、刷新、浏览器前进后退、主要交互和窄屏布局。
4. 上线前核对演示标记、内容准确性、链接目标、隐私说明和静态托管的路由回退规则。
5. 服务端接入与生产发布应提供单独的配置、权限、数据迁移和回滚方案，不把本地演示实现直接当作生产后台。

## 7. 路由清单

| 路由 | 页面 | 主要用途 |
| --- | --- | --- |
| `/` | 首页 | 产品摘要与页面入口 |
| `/product` | 产品能力 | 介绍 App 的实际能力与边界 |
| `/about` | 关于项目 | 项目背景与原则 |
| `/docs` | 使用指南 | 文档入口和部署概览 |
| `/contact` | 联系与反馈 | 问题反馈入口 |
| `/privacy` | 隐私说明 | 原型现状与未来统计原则 |
| `/admin` | 后台总览 | 汇总运营指标 |
| `/admin/campuses` | 校区管理 | 校区和地区汇总 |
| `/admin/usage` | 使用概况 | 匿名终端和版本信息 |
| `/admin/analytics` | 趋势分析 | 区域、时间和版本趋势 |
| `/admin/settings` | 后台设置 | 演示偏好与隐私方案预览 |
